# knowledge/ — 공유 지식위키 (knot)

스킬(행동지시)과 **분리된** 사실·결정·에러노트 저장소. Claude·Codex·Gemini가 같은 평문 마크다운을 읽는다.

## 구조 (3계층)

- `raw/` — 원본 자료(아티클·회의록·대화로그). **불변**. 절대 수정·삭제 금지.
- `wiki/` — raw를 바탕으로 정리한 실행규칙·의사결정·프로젝트 맥락. 서로 `[[링크]]`로 연결.
- (인덱스) `index.md` — 전체 지도, `log.md` — 작업 타임라인.

## 저장 규칙

`rules.md`의 **저장 5필터**를 통과한 것만 `wiki/`로 승격한다. 1회성 답변·미검증 추측은 승격하지 않는다.

## 사용

- 저장: "이번 작업 내용 knowledge에 저장해줘" → 에이전트가 분류·문서화·인덱스 갱신.
- 참조: "knowledge 참조해서 지난 맥락 복원해줘" → index·log 추적 후 맥락 주입.
