# rules.md — 벤더중립 공통 행동원칙 (단일 정본 / Single Source of Truth)

> 이 파일이 **정본**이다. CLAUDE.md·AGENTS.md는 여기서 파생한다(중복 수기 금지 — 드리프트 방지).
> 평문 마크다운이라 Claude Code·Codex·Gemini 어느 에이전트로 읽어도 동일하게 해석된다.

## 카파시 4원칙 (폭주하는 AI의 브레이크)

1. **코딩 전에 먼저 생각하라.** 명령이 모호하면 추측하지 말고 멈춰 질문한다.
   (예: "회원가입 만들어줘" → 이메일/휴대폰? 비번 조건? 먼저 확인)
2. **단순함을 최우선으로.** 불필요한 확장성·추상화 금지. 200줄을 50줄로 줄일 수 있으면 다시 쓴다.
3. **수술하듯 꼭 필요한 곳만.** 시키지 않은 코드·주석·서식을 건드리지 않는다.
   개선점을 발견해도 멋대로 고치지 말고 먼저 보고한다.
4. **목표지향 실행.** "버그 고쳤음"이 아니라, 그 버그를 잡는 테스트를 먼저 짜고 통과할 때까지 고친다.
   성공 기준을 주면 AI가 스스로 검증·반복한다.

## 교차검증 (MultiAgent 체계)

- 만들기/고치기/검토 결과물은 `gemini`(관점)+`opus`(설계)+`codex`/`gpt`(코드) **3중 병렬 검수**. GPT/Codex 누락 금지.
- 검수는 항상 적대적(`-Review`)으로: 기본 "결함 있다" 가정, BLOCKER/MAJOR/MINOR 등급, 근거 없는 통과 금지.
- 자체검증 단독으로 "완료" 선언하지 않는다. 실제 실행 검증(build/HTTP 200/test) 근거로만 보고.
- 상세 운영: `C:\Users\PSH\MultiAgent` 체계를 따른다.

## 공유기억 (knowledge/ 위키)

- 사실·결정·에러노트는 `~/.agents/knowledge/`(평문 md)에 누적한다. 스킬(행동지시)과 **분리**한다.
- 저장(save) 5필터 — 아래 중 하나라도 충족할 때만 위키에 승격:
  1. 반복 재사용되는 정보인가
  2. 다른 에이전트/동료가 이어받으려면 반드시 읽어야 하는가
  3. 의사결정 근거·결정권자를 나중에 추적해야 하는가
  4. 실패한 방식이라 다시 시도하면 안 되는 리스크 정보인가
  5. 팀 전체가 맞춰야 하는 공통 규칙/가이드인가
- 원본(raw)은 불변. 가공(wiki)과 영역을 분리해 맥락 오염을 막는다.
