# 전시 발주 검산

출력소에 넘기면 되돌릴 수 없다. 넘기기 전에 두 가지를 본다.

1. **치수** — 발주 값이 사내 옥타 규칙에 맞는가
2. **일러 파일** — 글자깨기(Ctrl+Shift+O)가 안 된 라이브 텍스트가 남았는가

**이미지를 만들지 않는다.** 읽고 대조하고 목록을 낼 뿐이다.

## 언제 쓰나

- 발주파일을 시공 파트장님께 넘기기 직전
- 실행 건 전환 후 `★발주파일` 폴더를 정리했을 때
- 여러 차수로 나눠 발주하다 앞 차수와 치수가 어긋났는지 볼 때

**안 쓰는 경우**: 항목이 두세 개뿐이면 그냥 눈으로 본다.

## 전체 흐름 — 일러에서 시작한다

```
일러스트레이터에서 order_label.jsx 실행
   ├─ 아트보드마다 치수 라벨 (mm, ×10 축척)          ← 기존 artboard_size_label.jsx 기능
   ├─ 옥타 정규값이 아니면 라벨이 빨강 + ⚠ 표시
   └─ <문서명>_발주표.csv 저장
          ↓  마감·수량 칸만 손으로 채운다
   python order_check.py sizes "<csv>"      → 치수 검산 + 위반 목록
   python order_check.py ai "<★발주파일 폴더>" → 라이브 텍스트 검사
```

`order_label.jsx` 는 ASURA님이 쓰시던 `artboard_size_label.jsx` 의 확장판이다.
기존 동작(치수 라벨)은 그대로 두고 검증·CSV만 얹었다. 원본은 건드리지 않았다.

## 실행

```bash
# 치수 검산 (CSV: 구역,폭,세로,마감,수량,양면,적힌가로,적힌세로)
python scripts/order_check.py sizes "발주표.csv"

# 일러 파일 라이브 텍스트 검사 (폴더 또는 단일 .ai)
python scripts/order_check.py ai "X:\...\08 현장설치물\★발주파일"
```

문제가 있으면 **exit code 1** 이라 자동화에 그대로 물릴 수 있다.

### CSV 칸 설명
| 칸 | 넣는 값 |
|---|---|
| 구역 | 아트보드 이름 / 항목명 (예: 중회의장 로비백월) |
| 폭 | `3m` · `2m(+10)` · `0.5m` 또는 숫자. **불칼질·후렉스는 mm 실측값** |
| 세로 | mm |
| 마감 | `현수막 상하단 바미싱` · `현수막 둥글게 양면` · `현수막 불칼질` · `후렉스` |
| 수량 | 장수 |
| 양면 | 세로를 2배로 적을 때만 `Y` (아래 주의 참조) |
| 적힌가로/적힌세로 | 발주 PPT에 **실제로 적은** 값. 계산값과 다르면 잡아낸다 |

## 규칙 요약 (정본은 AUSURA wiki)

```
상하단 바미싱 / 둥글게 양면  →  옥타 발주표
불칼질 · 후렉스              →  옥타표 미적용. 실측 자유치수
```

**옥타 발주표**
| 폭 | 2.5m 이하 | 2.5m 초과 |
|---|---|---|
| 0.5m | 450 (3D·시공은 455) | 450 |
| 1m | 950 | 950 |
| 1.5m | 1,445 | 1,445 |
| 2m | 1,940 | **1,950** |
| 2.5m | 2,435 | 2,435 |
| 3m | 2,930 | **2,940** |
| 4m | 3,920 | **3,930** |
| 5m | 4,910 | **4,920** |

**가로 +10 은 셋 다 맞을 때만** — ① 폭 2m 이상 ② 세로 2480 이상 ③ 상하단 바미싱.
둥글게 양면은 안 붙는다.

## 주의 — 이 도구가 못 하는 것

- **아트보드 치수 ≠ 발주 치수인 경우가 많다.** 실제 `_출.ai` 는 한 아트보드에 여러 항목을
  나열해 둔 작업 판이라, 아트보드 크기를 그대로 발주값으로 믿으면 안 된다.
  `order_label.jsx` 의 라벨은 **항목당 아트보드 1개**로 그렸을 때만 맞다.
- **불칼질·후렉스 여유를 자동으로 더하지 않는다.** 입력값에 여유(한 변 100 / 한 면 20)가
  이미 들었는지 알 방법이 없다. 이중으로 붙으면 출력 후 못 되돌리므로 통과시키고 알리기만 한다.
- **양면 세로 2배는 기본이 꺼짐.** 실제 파일에 두 관행이 다 있다
  (`450 x 4960` 세로 2배 / `2930 x 2480` 2장 = 수량으로 표현).
- **금액은 공감 단가표(2024-12-27)뿐.** 출력소는 행사 장소에 따라 바뀌므로 다른 곳에 쓰면 틀린다.
- **±10mm 규칙은 실제 발주파일 3건 24케이스에서 역산한 것**이다. 사내 문서에 그렇게 적혀
  있지는 않다. 시공 파트장님께 한 번 확인받고, 확정되면 이 문단을 지운다.

## 범위 밖 — 다시 제안하지 말 것

- **발주 PPT 자동 조판**: 2026-08-31 ASURA님이 **"자동화 안 해도 될 듯"** 으로 접었다.
  어느 시안이 어느 항목인지 기계가 확신할 수 없어 반쯤만 만들어지는 게 이유였다.
  요청이 다시 오기 전까지 만들지 않는다.
- **요청서 자동 해독**: 요청이 카카오톡으로 오므로 요청서 파일만 봐서는 반쪽이다. 같은 날 제외.
