# 판넬·시안 그래픽 검수

출력·시공 넘기기 전에 시안 폴더 전체를 기준 문서와 대조한다.
**이미지를 만들지 않는다.** 읽고 비교하고 목록을 낼 뿐이다.

## 언제 쓰나

- 시안 폴더를 출력소·시공팀에 넘기기 직전
- 클라이언트 브랜드 가이드를 받아놓고 시안이 그걸 지켰는지 확인할 때
- 여러 명이 나눠 만든 판넬의 색·폰트가 서로 어긋나는지 볼 때

**안 쓰는 경우**: 시안이 한두 장뿐이면 그냥 눈으로 본다. 이 스킬은 폴더 단위(수십~수백 장)일 때 값어치가 있다.

## 사전 확인 (건너뛰지 말 것)

1. **기준 문서가 실제로 있는가.** 브랜드 가이드 PDF, 안전·법적 문구 시트, 시공 제원표 중 최소 하나. 기준 없이 "알아서 봐줘"는 이 스킬의 일이 아니다 — 기준이 없으면 사용자에게 무엇을 기준으로 볼지 먼저 묻는다.
2. **필수 항목과 허용 오차 항목을 구분해서 받는다.** 안전문구 누락은 무조건 반려지만 색상 몇 포인트 차이는 넘어갈 수 있다. 이 구분을 프롬프트에 넣어야 결과가 처리 순서대로 정렬돼 나온다.
3. **판독 한계를 알린다.** 이미지는 긴 변 기준 약 2,576px로 읽힌다. 원본이 그보다 크면 세부가 뭉개질 수 있으니, 8pt 미만 미세 문구는 확신도 낮음으로 취급하고 사람이 확인한다.

## 실행 프롬프트 골격

기준 문서와 시안 폴더를 같은 위치에 두고 아래 형태로 지시한다.
**그룹핑 기준과 항목별 반환 필드를 명시하는 것이 핵심이다** — 안 쓰면 산문으로 나와서 처리할 수 없다.

```
<시안 폴더>의 모든 PNG/JPG/PDF를 <기준문서1>, <기준문서2>와 대조해 검수한다.

[필수 — 하나라도 걸리면 반려]
- 안전·법적 문구 누락 또는 최소 크기 미달
- 로고 구버전 사용, 클리어스페이스 침범
- 승인되지 않은 문구·클레임

[허용 오차 — 참고로만]
- 지정 색과의 미세 편차
- 자간·행간 차이

판넬 규격은 <제원표>의 유효 인쇄 영역을 기준으로 하고,
재단선·안전여백을 넘어간 요소를 따로 잡는다.

위반 유형별로 묶어서 내라. 각 항목마다:
  파일명 / 문제 / 가이드 값 / 실제 값 / 확신도(상·중·하)
마지막에 전 항목 통과한 파일 수를 적고,
확신도가 낮은 항목은 '사람이 열어봐야 할 것' 블록으로 따로 뺀다.
```

## 전시 특화 점검 항목

일반 브랜드 감사에 없는, 전시 시공에서만 터지는 것들:

- **유효 인쇄 영역** — 옥타늄/맥시마 프레임에 물리는 폭만큼 그래픽이 먹힌다. 재단선 기준이 아니라 **프레임 물림 후 남는 면** 기준으로 본다.
- **로고·핵심 문구의 프레임 간섭** — 판 경계에 로고가 걸치면 조립 후 잘린다.
- **판 간 색 연속성** — 여러 판에 걸친 배경이 판마다 다른 값으로 나가면 시공 후 줄이 보인다.
- **플렉스(현수막) 대 판재** — 장력 인쇄물은 인쇄 후 늘어난다. 정밀 정렬이 필요한 요소가 플렉스 면에 있으면 경고한다.
- **바닥 접점 문구** — 카펫·바닥 마감에 가려지는 높이에 정보가 있는지.
- **해상도** — 실크기 대비 유효 DPI. 큰 판일수록 원본 픽셀이 모자라기 쉽다.

## 출력 형식

```
검수 대상: <n>개 파일 / 기준: <문서 목록>

■ 로고·락업 — <n>건
  - <파일명> · <문제> · 가이드 <값> / 실제 <값> · 확신도 상
■ 색상 — <n>건
■ 타이포그래피 — <n>건
■ 필수 문구 — <n>건
■ 판넬 규격·재단 — <n>건

통과: <n>개 파일이 전 항목 충족

사람이 열어봐야 할 것:
  - <파일명> · <왜 확신이 낮은지>
```

## 하지 말 것

- **이미지를 생성하지 않는다.** 수정본 만들기·리터치·업스케일 전부 이 스킬 밖이다. 고쳐야 할 것을 찾아 알려주는 데서 끝난다.
- **확신도를 부풀리지 않는다.** JPG 압축으로 색이 밀린 것과 실제로 틀린 색을 구분할 수 없으면 '중' 이하로 적고 그 이유를 쓴다.
- **기준 문서에 없는 것을 위반으로 올리지 않는다.** 취향 지적은 검수가 아니다.

## 검수 뒤

- 확신도 '상' 항목만 노션 할 일 DB에 등록하면 트래커에서 끝난다.
- 같은 프로젝트를 반복 검수한다면 기준 문서 경로를 프로젝트 폴더에 고정해두고 이 스킬을 다시 부르면 된다.
