# 아이소뷰 인물 배치 계약

## 고정 대상

원본 RGBA, 카메라, 벽체, 바닥, 간판, 외벽 LED, 내부 명화와 프레임은 보호 픽셀이다. 최종 출력은 허용 마스크 내부의 인물·접지 그림자·허용된 홀로그램 픽셀만 바뀔 수 있다.

## 배치 기준

- 옥타 부스의 실제 높이 2,500 mm를 화면에서 읽는다.
- 성인 1,700 mm의 화면상 높이 = 옥타 수직 화면 높이의 68%.
- 위에서 내려다본 시점에서는 머리/어깨가 보이고, 발은 바닥 접점에 맞춰 둔다.
- 인물은 길을 막지 않으며 벽 앞에 붙지 않는다. 벽을 관찰하는 인물은 해당 벽에서 약 0.6–1.0 m 떨어진 위치에 둔다.

## 금지

- 배경을 검정으로 합성하거나 알파를 삭제하는 것
- 전체 장면을 다시 그려 구조가 미세하게라도 달라지는 것
- 외벽 LED에 액자·명화·홀로그램을 추가하는 것
- 사람을 벽체 내부, 닫힌 중앙 공간, 통로 밖 또는 원래 없는 의자에 배치하는 것
