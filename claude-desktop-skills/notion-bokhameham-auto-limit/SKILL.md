## 목표
Notion 🔧 프로젝트 데이터베이스의 "A | 보관함" 그룹이 항상 최신 10개 항목만 보이도록 자동 유지한다.

## 배경
- Notion 데이터베이스: collection://49d9582e-1be9-836d-a874-075f6db29687 (🔧 프로젝트)
- PARA 속성(select): "A | 보관함" 값을 가진 항목이 보드에서 보관함 그룹으로 표시됨
- 보관함_표시 속성(checkbox): 해당 항목이 보관함 소속인지 추적 (true = 보관함 소속)
- PARA = null이면 보드에서 숨겨짐
- 규칙: 보관함 항목은 최신순으로 10개만 PARA = "A | 보관함" 상태를 유지하고, 나머지는 PARA = null로 설정

## 실행 절차

### Step 1: 현재 보관함 표시 항목 조회
notion-search 또는 notion-fetch로 collection://49d9582e-1be9-836d-a874-075f6db29687 데이터베이스에서 다음을 조회:
- PARA = "A | 보관함" 인 항목 전체 (현재 보드에 표시 중인 보관함 항목)
- 보관함_표시 = true이고 PARA = null인 항목 (이전에 숨겨진 보관함 항목)

### Step 2: 전체 보관함 소속 항목 병합 및 정렬
위 두 그룹을 합쳐서 "보관함 소속 전체 목록"을 만든다.
timestamp(최종 수정일) 기준 내림차순 정렬.

### Step 3: 상태 조정
- 1~10위 항목: PARA = "A | 보관함", 보관함_표시 = "__YES__" 로 설정 (이미 설정된 경우 스킵)
- 11위 이하 항목: PARA = null, 보관함_표시 = "__YES__" 로 설정 (이미 설정된 경우 스킵)

### Step 4: 변경 사항 보고
변경한 항목 수와 목록을 간략히 출력한다. 변경 없으면 "보관함 정상 (10개 이하)" 출력.

## 주의사항
- 보관함_표시 = false(또는 null)이고 PARA = null인 항목은 보관함 소속이 아니므로 건드리지 않는다
- 변경 시 최소한의 업데이트만 수행 (불필요한 API 호출 방지)
