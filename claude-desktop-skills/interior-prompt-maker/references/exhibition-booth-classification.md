# 전시부스 시공 분류기 — 옥타늄 / 맥시마 / 블럭

이 문서는 전시부스가 보이는 모든 `interior-prompt-maker` 요청에서 필수로 읽는다. 목표는 디자인 분위기를 추측하는 것이 아니라, 구조 원본 Image 1의 시공 증거를 구역별로 판정하여 프롬프트에 정확한 공법 언어 하나만 넣는 것이다.

## 목차

1. 입력 역할과 우선순위
2. 필수 구역 원장
3. 결정 순서
4. 공법별 표현 계약
5. 상호배타 조립 규칙
6. 최소 회귀 판정

## 1. 입력 역할과 우선순위

1. 사용자가 실제 시공 공법을 구역까지 선언했다면 그 선언이 최우선이다.
2. 선언이 없으면 구조 원본 Image 1만으로 판정한다. 특히 `블럭부스`는 국내 현장 용어로 쓰이는 범위가 넓으므로, 이름·색·발광·패널 수만으로 공법을 추정하지 않는다.
3. 시공 참고 사진은 공법 판정이 끝난 뒤에만, 확정된 같은 공법의 패널 두께감, 조인트 성격, 알루미늄 표면 반응, 일반 조명 장착 방식 같은 **시공감**을 보조한다.
4. 참고 사진의 공법, 색, 형상, 모듈 수, 평면, 곡률, 캐노피, 개구부, 가구, 브랜드, 그래픽을 원본에 이식하지 않는다.
5. 색상, 파란빛, 광택, 발광, 패널 수만으로 공법을 판정하지 않는다.

## 2. 필수 구역 원장

프롬프트 작성 전에 내부적으로 다음 원장을 만든다.

`zone_id | source_region | 부모 면 | 경계 근거 | classification_evidence | 판정 | 허용 앵커 | 금지 앵커 | 확신도 | reference_finish_notes`

구역은 보이는 항목만 사용한다: `주벽`, `개구부/포털`, `상부 파시아/캐노피`, `전면 강조빔`, `측·후면 골조`, `카운터/독립 가구`, `그래픽 면`.

판정값은 정확히 하나다: `octanorm`, `maxima`, `block`, `carpentry`, `other`, `undetermined`.

구역은 **공법이 동질인 최소 연속 면 또는 골격 단위**다. 물리적 이음, 프로파일 종류가 바뀌는 선, 면과 골격의 경계처럼 Image 1에서 관찰 가능한 전환점에서만 나눈다. 같은 픽셀 범위를 부모·자식 구역이 중복 점유하지 않는다. 하나의 벽이라도 상부 맥시마 빔과 하부 옥타 인필처럼 공법이 바뀌면 경계선에서 분리한다.

경계가 그래픽·가구·인파에 가려지면 가려진 구간을 추측해 자르지 않는다. 가림 전후의 연속성이 확인되는 범위만 한 구역으로 묶고, 가림 너머의 불확실한 범위는 별도 `undetermined` 구역으로 둔다.

`classification_evidence`에는 Image 1의 관찰과 위치만 기록한다. `reference_finish_notes`는 판정 완료 후 별도 기록하며 분류기로 되돌려 보내지 않는다.

확신도는 다음과 같이 고정한다.

- `high`: 사용자 선언이 충돌 없이 해당 구역을 지정했거나, Image 1에서 서로 독립적인 구조 단서가 2개 이상 일치한다.
- `medium`: 구조 문법 단서 1개만 뚜렷하고 나머지는 가려졌지만 반대 증거는 없다.
- `low`: 증거가 흐리거나 서로 충돌한다.

공법 고유 앵커는 `high`에서만 방출한다. `medium`과 `low`는 최종 판정을 `undetermined`로 정규화하고, 보이는 형상·경계만 보존하며 새 공법 디테일을 쓰지 않는다.

독립 구조 단서는 다음처럼 서로 다른 관찰 범주에서 센다. 같은 특징의 반복은 하나의 단서로만 계산한다.

- 옥타늄: `반복 포스트-인필 관계`, `인필의 프로파일 뒤 후퇴`, `수평 레일·베이스레일과 수직 포스트의 접합`.
- 맥시마: `사용자 선언 또는 maxima 계열과 일치하는 노출 압출 골격`, `개구부·파시아·포털을 잇는 구조 스팬`, `관찰 가능한 빔 깊이·단면 또는 빔-빔 접합`. 맥시마는 얇은 40 계열부터 깊은 80/120 계열까지 존재하므로, 굵기 하나만으로 판정하지 않는다.
- 블럭: `솔리드 면 모듈 반복`, `관찰 가능한 패널 측면 두께`, `면을 가로지르는 반복 함몰 조인트`, `연속 노출 골격 부재`.
- 목공: `현장 조성 솔리드 벽체 깊이`, `퍼티·도장된 연속 마감`, `플러시 모서리와 숨은 프레임`.

마지막 항목의 `연속 노출 골격 부재`는 블럭을 지지하는 양의 단서가 아니라 블럭 판정을 배제하는 반대 증거다. 양의 단서 2개 이상과 반대 증거 0개가 동시에 충족돼야 `high`다.

## 3. 결정 순서

각 구역을 아래 순서로 판정한다.

1. **옥타늄:** 프로파일 색과 절대 굵기가 아니라, 슬림한 알루미늄 수직 포스트와 수평 바가 **면 전체에 반복되는 post-and-infill 문법**을 만들고 별도 인필 패널·현수막·그래픽 면이 그 프로파일 뒤로 물러나 끼워져 있으면 `octanorm`. 가능한 시야에서는 이 관계가 2개 이상의 베이에서 반복되어야 한다.
2. **맥시마:** 사용자 선언이 있거나, 압출 골격이 **면 전체의 인필 격자가 아니라 개구부·포털·상부 파시아의 윤곽**을 적어도 두 개의 이어진 변에서 형성하고 구조 스팬으로 읽히면 `maxima`. maxima는 노출·패널 피복·패브릭 피복 모두 가능하므로, 원본에서 보이는 피복 상태를 유지한다. 40/80/120 계열의 절대 굵기, 색, 발광 여부만으로는 판정하지 않는다.
3. **블럭:** 구조의 정체성이 노출 골격이 아니라 면을 이루는 단단한 규격 패널 모듈이며, 가능한 시야에서 3개 이상의 연속 면 모듈에 실제 두께와 반복되는 좁은 함몰 조인트가 보이고 연속된 슬림 post-and-infill 격자나 개구부 둘레의 노출 박스빔 골격이 없으면 `block`.
4. **목공:** 노출 골격과 규칙적 탈착 조인트 없이 현장 조성된 솔리드 벽체 깊이, 퍼티·도장된 연속 마감면과 플러시 모서리가 함께 확인되면 `carpentry`. 프레임이 단순히 가려졌거나 연속 패브릭·텐션 원단의 프로파일 가장자리가 보이는 경우에는 목공으로 판정하지 않고 각각 `undetermined` 또는 `other`로 둔다.
5. 텐션패브릭, 트러스, 맞춤 철골 등 위 유형이 아니면 `other`.
6. 가림, 저해상도, 상충 증거로 확정할 수 없으면 `undetermined`. 새 구조 디테일을 발명하지 않는다.

서로 다른 증거군이 서로 다른 구역에 있으면 `혼합`으로 뭉개지 말고 구역별 판정을 유지한다. 같은 구역에서 증거가 충돌하면 임의 혼합하지 않고 `undetermined`로 둔다. 사용자가 공법을 선언한 구역은 CGI 외형이 애매하거나 달라도 그 시공 사실을 유지하며, 서로 충돌하는 사용자 선언이 같은 구역에 겹칠 때만 확인 전까지 `undetermined`로 둔다.

## 4. 공법별 표현 계약

### OCTANORM / 옥타늄

핵심은 **면 전체에 반복되는 노출 슬림 골격 + 골격 사이의 별도 인필**이다. 은색은 흔한 마감일 뿐 판정 조건이 아니다.

허용 앵커:

`the target-visible zone reads as an exposed slim anodized or source-matched wrapped-aluminum Octanorm post-and-rail grid, with separate infill or banner faces seated between the profiles, preserving the exact target geometry, spacing and visible base rails`

반드시 금지:

- 굵은 맥시마 박스빔으로 비대화
- 블럭부스식 단단한 전면 모듈과 반복 함몰 조인트 추가
- 골격을 감춘 이음매 없는 목공벽으로 변환
- 참고 사진의 부스 배치나 디자인 복제

### MAXIMA / 맥시마

핵심은 **개구부·파시아·포털을 형성하는 maxima 압출 골격**이다. 맥시마의 정체성은 면 패널이 아니라 구조 압출에 있으며, 노출·패널 피복·패브릭 피복은 원본에 보이는 상태만 허용한다. 깊고 굵은 부재는 일부 계열의 가능한 모습일 뿐 모든 맥시마의 정의가 아니다.

허용 앵커:

`the target-visible zone reads as a Maxima box-beam structural frame: thick rectangular aluminum beam members define the exact source openings, fascia or portal, with open spans and beam-to-beam joints retained`

원본에 보이는 피복 상태를 포함한 범용 앵커:

`the target-visible zone retains its source-confirmed Maxima extrusion structure at the exact source openings, fascia or portal, preserving only the observed exposed, panel-clad, or fabric-clad condition and the observed beam depth, spacing and joints`

반드시 금지:

- 슬림 옥타늄 포스트-인필 격자로 축소
- 면 전체를 블럭 패널 조인트로 분할
- 원본에 없는 포털, 캐노피, 곡선, 기둥 추가
- 파란색, 검은 라인, 발광, 또는 절대 부재 굵기만으로 맥시마 판정
- 원본에 자체발광 근거가 없는데 전체 빔을 네온처럼 발광

색상 래핑, 파란 부재, 내부발광, 국소 스필은 Image 1 또는 사용자 선언으로 확인된 정확한 부재에만 조건부로 표현한다. 맥시마 단독도 가능하며, 옥타늄 베이스가 확인된 경우에만 구역별 혼합으로 쓴다.

### BLOCK / 블럭

핵심은 **면을 형성하는 단단한 규격 모듈 + 실제 패널 두께 + 반복 조인트**다. 블럭의 정체성은 열린 골격이 아니라 조립된 솔리드 페이스에 있다.

허용 앵커:

`the target-visible zone reads as a rigid reusable block-panel assembly: solid-faced modules with target-visible thickness and narrow but clearly readable recessed joints repeat across only the source-confirmed surfaces`

반드시 금지:

- 슬림 옥타늄 포스트와 인필 격자 추가
- 열린 스팬을 감싸는 맥시마 박스빔 골격으로 변경
- 이음매 없는 목공벽으로 평탄화
- 참고 사진에서 본 곡면, 캐노피, 카운터, 체결점, 내부조명 추가
- 밝은 그래픽이나 반사를 내부발광으로 오판

곡면 세그먼트, 캐노피 하부, 카운터 모듈, 체결점, 내부발광은 각각 Image 1에서 실제로 확인되거나 사용자가 선언한 경우에만 독립적으로 추가한다.

## 5. 상호배타 조립 규칙

1. 한 구역에는 긍정 공법 앵커를 정확히 하나만 넣는다.
2. `hybrid`는 같은 구역의 어휘 혼합이 아니라 서로 다른 구역의 판정 조합이다.
3. 옥타 구역에 블럭 조인트나 맥시마 두께를 누출하지 않는다.
4. 맥시마 구역에 옥타 슬림 격자나 블럭 솔리드 페이스 리듬을 누출하지 않는다.
5. 블럭 구역에 옥타 노출 포스트나 맥시마 열린 박스빔 골격을 누출하지 않는다.
6. `other`와 `undetermined`에는 옥타·맥시마·블럭 고유 디테일을 넣지 않는다.
7. 최종 프롬프트는 판정된 공법명보다 먼저 그 공법을 증명하는 구조 특성을 적는다.
8. 금지 앵커는 검증 규칙이지 혼합 부스의 전역 NEGATIVE 문구가 아니다. 다른 구역에 실제 존재하는 공법을 전역에서 억제하지 않는다.
9. 각 `high` 구역의 `zone_id + source_region + positive anchor`가 최종 프롬프트에 한 번씩 있는지 확인한다. 누락·중복·경쟁 앵커가 있으면 출력 전에 다시 조립한다.
10. `carpentry`는 해당 구역에만 `a source-confirmed solid custom-built wall with continuous site-finished surfaces and flush corners`를 쓴다.
11. `other`는 관찰 가능한 재료·형상만 묘사하고 시스템 공법명을 쓰지 않는다.
12. `undetermined`는 `preserve the exact visible structure and boundaries of this source region without inferring a booth construction system or adding joints, profiles, beams or hidden supports`만 쓰며 공법 고유 앵커를 방출하지 않는다.

## 6. 재질·그래픽·바닥 분리 게이트

공법 판정은 골격의 판정일 뿐, 그래픽면·조명·바닥을 새로 설계할 권한이 아니다.

1. 같은 맥시마·옥타늄·블럭 구조라도 그래픽면은 원본의 `PVC flex / 패널 / 패브릭 / LED` 증거를 따로 확인한다. 그래픽의 파란색·밝은 반사·화이트 포인트만으로 현수막, 라이트박스, LED, 내부발광을 서로 바꾸지 않는다.
2. 검은 줄·은색 레일·패널 조인트·체결점·노출 케이블은 원본에 그 위치와 연속성이 실제로 보일 때만 유지한다. 재질감을 위해 새 줄이나 홈을 추가하지 않는다.
3. 원본 바닥이 노출 타일·콘크리트·마루이면 그 바닥은 연속된 원본 바닥으로 유지한다. 카펫·러너·이중바닥·테두리·단차는 원본 또는 사용자 선언이 있을 때만 표현한다.
4. 원본에 없는 부스 발광·파란 광원·광원 스필은 추가하지 않는다. 실제 발광면이 확인될 때도 반사와 스필은 인접 원본 면에만 국소적으로 표현한다.
5. 최종 합성에서는 원본 그래픽, 직선 프레임, 바닥 경계와 사인 접지점을 최상단 마스크로 복원하고, 50% 오버레이에서 불일치하면 반려한다.

## 7. 리서치 근거와 표현 한계

- OCTANORM의 `octaclassic`은 직립재·빔·시스템 그루브에 패널·유리·패브릭을 끼우는 재사용형 시스템이다. 따라서 원본에서 반복되는 post-and-infill 관계가 보일 때만 옥타늄 앵커를 사용한다.
- OCTANORM `maxima`는 40/80/120 깊이의 압출 시스템이며 노출, 패널, 패브릭, 유리 피복이 가능하다. 따라서 맥시마를 전역의 굵은 박스빔, 전역 발광 골조, 또는 항상 노출된 금속 격자로 일반화하지 않는다.
- `블럭부스`는 여기서 원본 또는 사용자 선언으로 확인된 규격 솔리드 모듈 조립을 뜻한다. 공급사·현장에 따라 명칭과 결합 방식이 달라질 수 있으므로, 확인되지 않은 모듈 치수·조인트·체결점·캐노피·내부조명을 발명하지 않는다.
- `목공부스`는 사용자 선언 또는 원본의 현장 조성 벽체·플러시 마감·숨은 골조 증거가 함께 있을 때만 사용한다. 단순히 프레임이 가려졌거나 텐션패브릭 면이라는 이유로 목공으로 판정하지 않는다.
- 확인 출처: OCTANORM `octaclassic`, `maxima`, `Exhibition Systems` 공식 제품 페이지 및 2026 기술 브로슈어. 공법 정의는 이 출처로 보정하되, 특정 제품 치수·색·부스 배치·그래픽은 Image 1에 이식하지 않는다.

최종 조립 형식은 다음과 같다.

`[zone_id/source_region]: [source-locked geometry] + [해당 구역의 positive anchor 1개 또는 안전 폴백] + [해당 구역에서 확인된 재료·조명만]`

프롬프트만 요청된 경우 `authorization=PROMPT_ONLY`를 유지하고 이미지 생성 도구 호출 수가 0인지 확인한다. 사용자가 이미지 생성까지 명시했더라도 `undetermined` 구역은 공법 추정 없이 안전 폴백으로 유지한다.

## 8. 최소 회귀 판정

- 슬림 은색 노출 격자 + 별도 백색 인필 → `octanorm`
- 굵은 박스빔 포털 + 열린 스팬 → `maxima`
- 단단한 반복 면 패널 + 실제 두께 + 함몰 조인트 → `block`
- 맥시마 전면 포털 + 옥타늄 측·후면 → 구역별 `maxima` + `octanorm`
- 매끈한 연속 도장벽 + 숨은 프레임 → `carpentry`
- 블럭 참고 사진 + 옥타 구조 원본 → 원본은 `octanorm`; 참고 사진의 블럭 형상은 이식 금지
- 맥시마 빔 사이에 솔리드 인필이 있으나 개구부 둘레 빔 단면과 열린 스팬이 확인됨 → 골격 구역은 `maxima`, 인필 면은 별도 구역 판정
- 연속 패브릭 면 + 텐션 프로파일 가장자리 → `other`, 목공 금지
- 색만 파랑/은색이고 구조 문법이 불명확 → `undetermined`
- maxima 선언 + 패널 또는 패브릭 피복 → `maxima`; 원본에서 보이는 피복 상태를 유지하고 노출 박스빔으로 강제하지 않음
- 노출 타일 바닥 + 카펫 증거 없음 → 타일 바닥 유지; 카펫·러너·단차 생성 금지
- 같은 구역에 충돌하는 사용자 선언 2개 → 확인 전 `undetermined`
