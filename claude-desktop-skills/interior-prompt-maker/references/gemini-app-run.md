# Gemini 데스크톱 앱 실행 경로 — 함정과 판정

> 정본 실측 기록: vault `AI-Sessions/wiki/errors/error-gemini-argon-virtual-monitor-2026-11-09.md` (2026-11-09~10).
> 코드: `C:\Users\PSH\dev\multi-model\gemini_app.ps1`(호출), `gemini_park.ps1`(가상 모니터 주차), `gemini_hidden_start.ps1`(플래그 재시작).

## 왜 이 경로인가
- gemini CLI 는 개인 계정을 인증 단계에서 거부한다(IneligibleTierError). 사용자 계정의 Gemini(Argon·이미지 편집)를 에이전트가 쓰는 길은 데스크톱 앱 조작뿐이다.
- 사용자 지시: "내 화면 방해 없이", "띄웠다 놨다 하지 마". 그래서 앱 창을 설정 4번(없으면 3번) 가상 모니터에 세워 두고 접근성(UIA)·창 메시지로만 조작한다.

## 스크립트가 알아서 하는 것
1. 앱이 백그라운드 억제 해제 플래그 없이 떠 있으면 플래그로 재시작(사용자가 앱을 쓰는 중이면 손대지 않고 실패).
2. 창을 설정 4번 모니터(`DISPLAY4`)에 세운다. 창 정렬 감시(`dev/ai-window-layout`)는 Gemini 를 아예 다루지 않는다(2026-11-10 ASURA님 "4번에 그냥 있게 해, 필요하면 알아서 땡겨 쓸테니"). 사용자가 끌어다 쓴 자리는 다음 자동 호출 때 다시 4번으로 간다.
3. 임시 채팅 → 첨부(파일 선택 창을 WM_SETTEXT·IDOK 로 채움) → 전송 → 답 대기 → '원본 크기 이미지 다운로드' → 저장 창(이름 칸 id 1001, 하위 탐색) → 파일 크기 3회 연속 같으면 완료.
4. 동작마다 포커스가 Gemini 로 넘어가면 사용자가 쓰던 창으로 되돌린다(앱이 UIA 동작을 받으면 스스로 맨 앞 창이 된다).

## 함정
- 포커스가 잠깐 넘어가는 그 순간 사용자가 치던 글자는 Gemini 로 샐 수 있다. 무거운 타이핑 중이면 돌리지 않는다.
- 저장 단계가 실패하면 생성은 이미 소모됐다. 재시도는 재생성이다.
- 앱 화면 문구가 바뀌면 깨진다(2026-11-10 '현재 Argon' → '현재 Gemini Argon'). 실패 시 `~/.agents/state/gemini_app_traces/` 의 화면 기록을 먼저 본다.
- 결과 우하단 반짝이 워터마크. 처리 방법은 아직 없다 → 비교 후보로만 쓴다.
- 프롬프트가 영어 단락만이면 이미지가 아니라 글로 답할 수 있다(미검증) → 한국어 첫 줄로 생성을 명시한다.

## 실제 렌더 시험 (2026-11-10, LED 몰입형 전시룸 `아트큐브LED합성/원본렌더/led_1.png` 2560×1440)
- `gemini_batch.ps1` 1장 195초 → `BATCH_DONE ok=1`. Gemini 원 출력 2730×1536(16:9) → 워터마크 제거 후 2560×1440 맞춤.
- 구도: 전역 이동 1.6px, 50% 오버레이 이중선 없음. LED 픽셀 격자·모듈 이음선, 바닥 반사 감쇠는 사진처럼 바뀜.
- **반려 1건**: 원본의 검은 빈 천장에 천장 그리드·트러스·덕트·케이블을 새로 그림(점검표 5번). `audit_realize` 배경차 5.33 → 원본 빈 영역 마스크(위 가장자리에 붙은 어두운 영역)로 복원해 0.00.
- LED 면 처리: 원본 영상의 저주파(그림·색, σ3) + Gemini 고주파(격자·이음선)로 다시 합치면 물고기·거품 자리가 원본 그대로 남는다. 작업 스크립트 `AI-작업기록/claude/2026-11-10_gemini-app-실사화시험/fix_led_1.py`.
- **`audit_realize` 의 그래픽 박스 항목은 LED 격자 면에 쓰지 않는다**: 원본 렌더의 격자와 결과 격자의 위상이 달라 구조차가 27~32 로 나온다(글자·로고용 기준 4). LED 면은 배경 불변(①)·실사화 변화(③) 항목과 육안 대조로 판정한다.
