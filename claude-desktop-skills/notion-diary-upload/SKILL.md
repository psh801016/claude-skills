# Notion 업무일지 업로드

## 핵심 원칙

**절대 새 페이지 생성 금지.** 전날 페이지 복제 → 속성 3개 동시 수정이 전부다.
이렇게 해야 인라인 DB 블록(오늘의 계획, 세부 업무 캘린더, 밀린 업무 등)이 구조째로 복사된다.

---

## 실행 순서

### 1단계: 가장 최근 업무일지 찾기

`notion-search`로 가장 최근 날짜 업무일지를 검색한다.

- 검색어: `"업무일지 5월"` 또는 `"05/28"` 형태로 오늘 전날부터 역순 검색
- 제목이 `"05/28:"`, `"05/27:"` 처럼 날짜:형식인 페이지가 업무일지
- 없으면 그 전날, 그 전전날 순으로 찾는다

### 2단계: 전날 페이지 내용 확인

`notion-fetch`로 찾은 페이지를 읽는다.

properties에서 **`다이어리`** 값 전체를 확인한다.
예시 형태:
```
05.28 (목)<br>1. 프로젝트A : 제안디자인<br>2. 프로젝트B : 실행디자인<br>...
```

이 번호 붙은 항목 리스트 전체를 그대로 가져가야 한다.

### 3단계: 복제

`notion-duplicate-page`로 찾은 페이지를 복제한다. 반환된 새 페이지 ID를 기억한다.

⚠️ 복제는 **비동기**로 진행되어 즉시 채워지지 않을 수 있다. 4단계 전에 `notion-fetch`로 **새 페이지(복제본) ID**를 다시 열어 `다이어리` 속성과 인라인 DB 블록이 실제로 복사됐는지 확인한다. 아직 비어 있으면 잠시 후 다시 fetch 한다. 절대 원본이 아닌 **복제본**을 대상으로 작업한다.

### 4단계: 속성 3개를 한 번의 호출로 동시 업데이트 ⚠️

`notion-update-page` (command: `update_properties`)를 **복제본 페이지 ID(page_id)** 에 대해 **단 한 번** 호출하면서 아래 3가지를 **모두** 포함한다. 하나라도 빠지면 안 된다.

```
date:날짜:start  →  오늘 날짜 (예: "2026-05-29")
date:날짜:is_datetime  →  0
캘린더           →  오늘 날짜 제목 (예: "05/29:")
다이어리         →  날짜 헤더만 교체, 번호 항목 전체 유지
```

**`다이어리` 수정 규칙:**
- 첫 줄 날짜만 교체: `05.28 (목)` → `05.29 (금)`
- 요일은 오늘 날짜에 맞게 계산 (월/화/수/목/금/토/일)
- 번호 붙은 항목들은 **한 글자도 건드리지 않고** 그대로 유지
- `<br>` 구분자 구조도 그대로 유지

### 5단계: 완료 보고

업데이트 완료 후 Notion 링크를 사용자에게 전달한다.

---

## 자주 하는 실수 (하지 말 것)

- `다이어리` 속성을 빠뜨리고 날짜/캘린더만 업데이트 → 다이어리가 전날 그대로 남음
- 3개를 여러 번의 update_properties 호출로 나눠서 실행 → 실수 확률 높아짐
- `다이어리` 날짜 헤더만 쓰고 번호 항목을 비움 → 내용 전체 날아감
- `notion-create-pages` 사용 → 구조 전부 빠짐
