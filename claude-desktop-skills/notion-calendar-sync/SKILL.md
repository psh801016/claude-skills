---

## 목표
노션 할 일 DB에서 프로젝트가 연결되어 있지만 "목표날짜"가 비어 있는 항목을 찾아, 연결된 프로젝트의 "마감일"을 자동으로 채워 넣는다.

## 배경 정보
- **할 일 DB** (data source): `collection://4709582e-1be9-8332-903b-87ce7db219fb`
- **프로젝트 DB** (data source): `collection://49d9582e-1be9-836d-a874-075f6db29687`
- 할 일의 **"목표날짜"** 필드에 날짜가 있어야 캘린더(세부 업무 뷰)에 표시됨
- 할 일의 **"프로젝트"** 필드는 프로젝트 DB와의 relation
- 프로젝트의 **"마감일"** 필드가 행사일/납기일 기준

## 실행 절차

### Step 1: 목표날짜 없는 할 일 검색
Notion MCP `notion-search` 도구를 사용해 할 일 DB에서 항목들을 검색한다.
검색어: "할 일" (query_type: internal)
page_size: 25

### Step 2: 각 항목 확인
검색된 항목 중 `notion-fetch`로 각 페이지를 열어 다음 조건을 확인한다:
- `date:목표날짜:start`가 비어 있음 (null 또는 미설정)
- `프로젝트` relation에 연결된 프로젝트 URL이 1개 이상 있음
- 상태(상태)가 "완료" 또는 "취소"가 아님

### Step 3: 프로젝트 마감일 가져오기
조건을 만족하는 항목마다:
1. `프로젝트` 필드에서 연결된 프로젝트 페이지 URL 추출
2. `notion-fetch`로 해당 프로젝트 페이지 열기
3. 프로젝트의 `date:마감일:start` 및 `date:마감일:end` 값 확인

### Step 4: 목표날짜 업데이트
프로젝트에 마감일이 있으면 `notion-update-page`로 할 일 항목의 목표날짜를 설정:
- command: `update_properties`
- `date:목표날짜:start`: 프로젝트의 `date:마감일:start` 값
- `date:목표날짜:end`: 프로젝트의 `date:마감일:end` 값 (있을 경우만)
- `date:목표날짜:is_datetime`: 0

### Step 5: 완료 보고
업데이트한 항목 수와 이름을 간략히 출력한다. 변경 없으면 "모든 할 일에 목표날짜가 설정되어 있습니다."라고 출력.

## 주의사항
- 이미 목표날짜가 설정된 항목은 건드리지 않는다
- 프로젝트에 마감일이 없는 경우 해당 할 일은 건너뛴다
- 상태가 "완료" 또는 "취소"인 항목은 건너뛴다
- `보관함_표시`가 true인 프로젝트 항목도 처리한다 (보관 여부와 무관하게 할 일에 날짜가 필요할 수 있음)
