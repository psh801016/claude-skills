# 전방 방사형 빔 품질 참고

## 기준 자산

- 승인 결과 이미지: `../assets/forward-beam-quality-reference.png`
- 이 자산은 사용자가 승인한 **빛의 깊이감, 전방 원근감, 헤이즈 질감, 빔 시인성, 홀 노출 균형**만 판단하는 품질 참고다.
- 이 자산의 빔 개수, 색, 위치, 대칭 배열, 고보, 행사명 또는 공간 구성을 다음 작업에 고정 복제하지 않는다.

## 매 작업 생성 원칙

1. Image 1에서 카메라, 구도, 구조, 무대, 가구, 그래픽, 재질을 잠근다.
2. Image 2가 있으면 현재 빛의 개수, 실제 발광점, 방향, 팬 형태, 교차, 원근 확장, 색, 밝기, 헤이즈와 끝점을 새로 분석한다. 없으면 Image 1의 실제 등기구와 현재 요청에서 정한다.
3. Image 2의 빛 형태를 Image 1의 실제 기존 조명 위치에 맞춰 이식한다.
4. 결과의 광학적 완성도만 승인 이미지 수준으로 만든다.
5. 고보는 기본 OFF다. 사용자가 현재 요청에서 별도로 고보를 요구한 경우에만 추가한다.
6. 고보가 요청되면 행사명, 모양, 위치, 색, 투명도 등 사용자가 그 요청에서 지정한 내용만 사용한다.
7. 사용자가 메인 조명 프롬프트와 빛 전용 프롬프트를 요구하면 서로 독립된 복사 블록 두 개로 출력한다.
8. 빛 전용 플레이트는 순수 검정 위에 공중 빔·헤이즈·입자와 빔이 의자·테이블보·카펫·통로·바닥·무대·벽에 남긴 조명 성분만 보인다.
9. 빛 전용 플레이트에서 LED 화면 자체의 콘텐츠·행사명·글자·로고·패널 발광·LED 발광의 화면 반사는 제거한다. **LED 앞 공기를 통과하는 빔·헤이즈·글로우는 유지한다.** 화면 전체 사각형을 검정으로 덮지 않는다.
10. 고보가 요청된 빛 전용 플레이트에는 고보 필드뿐 아니라 실제 광원에서 벽까지 이어지는 희미한 체적 투사 콘도 포함한다.

## 승인 결과를 만든 프롬프트에서 재사용할 품질 특성

- 빔은 광원에서 좁게 시작하고 실제 진행 방향을 따라 길고 연속적인 3차원 광축으로 이어진다.
- 카메라 쪽으로 진행하는 빔은 관객 위를 지나며 가까워질수록 넓어지고 상단 또는 외곽 프레임 밖으로 계속된다.
- 빔마다 발광 코어, 중간 농도의 헤이즈, 미세 입자, 부드러운 가장자리와 자연스러운 감쇠가 보인다.
- 밝기를 낮춰도 빔의 전체 경로와 원근 형태는 사라지지 않는다.
- 홀은 콘서트장처럼 새까맣게 죽이지 않고 천장, 벽, 객석, 테이블보, 카펫 디테일을 통제된 암부 안에 남긴다.
- 진행자와 연사가 서는 무대 전면은 밝은 스팟 풀이 점유하지 않는 열린 공간으로 보존한다.
- 완성 장면에서는 LED 반사광과 색광 스필을 실제 표면에서 물리적으로 반응시키고 원본 그래픽을 바꾸지 않는다.
- 빛 전용 플레이트에서는 LED 자체와 그 발광 성분을 0으로 만들고, LED 앞 공기의 빔/헤이즈와 빔·요청된 고보가 만든 표면 조명 성분을 남긴다.

## 금지

- 아래 품질 참고를 고정 조명 프리셋으로 사용하지 않는다.
- Image 2를 보지 않고 승인 이미지의 방사형 빔을 자동 생성하지 않는다.
- 사용자가 고보를 말하지 않았는데 승인 이미지에 있다는 이유로 고보를 넣지 않는다.
- 이전 작업의 행사명이나 고보 문구를 다음 작업으로 승계하지 않는다.
- 밝기 조절 요청을 빔 삭제나 방향 변경으로 해석하지 않는다.
- 빛 전용 플레이트에 LED 화면 자체, 스크린 그래픽, 행사명, 글자, 로고 또는 LED 자체의 화면 잔광을 남기지 않는다. 이를 근거로 앞 공기의 조명을 삭제하지 않는다.
- 공중 빔만 남기고 의자·테이블보·바닥·카펫의 실제 수광 흔적을 삭제하지 않는다.
