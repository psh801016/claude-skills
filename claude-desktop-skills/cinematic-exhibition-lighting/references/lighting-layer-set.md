# 조명 레이어 세트 — 제작 레이어와 전방 공기를 분리한다

본문의 단일 조명판 계약이 정본이다. 이 문서는 성분을 따로 조절하거나 그래픽·인물 앞뒤로 합성할 때 읽는다. 사용자가 요청하지 않은 4장 납품을 자동으로 늘리지 않는다.

## 실제 제작 레이어

| 레이어 | 포함할 성분 | 합성 위치 |
|---|---|---|
| L1 BEAM | 실제 광원에서 이어지는 빔과 코어 | 복원한 그래픽 위의 공기 공간; 실제 차광만 적용 |
| L2 HAZE | 빔 주변의 부드러운 공기 산란·헤이즈 | 그래픽·인물 앞 공간; 글자/LED 사각형 마스크로 지우지 않음 |
| L3 SPOT POOL | 실제 착지면 안의 수광 반응 | 베이스 표면; 테이블/카펫/무대 경계와 차광을 따름 |
| L4 COLOR WASH | 선택된 합성본에 있는 국부 워시와 반사광 | 해당 표면; 구조·그래픽 자체를 다시 그리지 않음 |

L1/L2는 카메라 투영에서 LED 화면과 겹쳐도 된다. 화면을 직접 비추는 조명, 화면 자체의 발광, 앞 공기에 있는 빛을 구분한다. 조명판에는 LED 콘텐츠·글자·로고·LED 자체 발광을 넣지 않지만 **그 앞을 통과하는 L1/L2는 남긴다.**

블랙 배경 플레이트는 빔뿐 아니라 같은 선택본에 보이는 L3/L4 반응도 포함한다. 가구 실루엣이나 바탕 재질은 제외하되 실제로 빛이 닿는 상판/의자 림의 수광 반응을 통째로 삭제하지 않는다.

## 조명 샌드위치 — 인물 스킬과의 공통 연결

베이스 → 반사·L3/L4 → 원본 그래픽 복원 → 인물 그림자·인물/색보정 → L1/L2.
실제 조명 경로를 막는 사람·물체의 차광만 앞 공기 효과에 적용한다. 뒤에 있는 LED 화면을 앞 공기의 차광체처럼 마스킹하지 않는다.

## 생성·추출 경계

- 프롬프트 단계에서는 현재 원본·참고이미지·요청을 기준으로 필요한 성분만 기술한다. 고정 빔 개수·대칭 팬·혼합색·스파클 기본값은 없다.
- 이미지 생성은 사용자가 명시적으로 요청한 때만 실행한다. 합성에 사용한 각 레이어를 보존하고, 한 장 조명판은 **그 레이어에서** 만든다.
- 이미 선택된 완성본의 조명만 뽑을 때는 개별 L1~L4를 새로 생성하지 않는다. 실제 제작 레이어 또는 검증 가능한 추출만 사용한다. 근거 없는 수학적 재구성도 그대로 추출했다고 부르지 않는다.
- 사용자가 누락 효과를 추가하라고 하면 기존 선택본을 보존하고 요청 영역만 수정한다. 수정 레이어를 저장하고 완성본·조명판을 함께 갱신한다.

## 블렌드와 주변 노출

Add와 Screen은 서로 다른 연산이다. 실제 사용한 한 가지 모드와 불투명도/색공간을 기록하고 동일 모드로 재현한다. 검정 플레이트에서 검정은 빛 0이지 어둡게 하는 마스크가 아니다. 주변을 낮추는 것은 베이스 노출에서 처리하고 그 베이스를 보존한다.

## 검증

실행 순서·JSON·검증 명령은 [워크플로 및 출력 계약](workflow-and-output-contract.md)을 따른다. LED 앞 빔/헤이즈가 존재할 때 그 영역이 검정이면 실패다. 가구 반응 누락, 화면 테두리에서 잘린 빛, 글자/구조 잔여물을 각각 검사한다. 수치 검사와 시각 검사 결과를 구분해서 보고한다.
