# 사람 합성 (person-layer-maker) — 2026-11-05 개편

**목표 = 실제 행사 사진처럼 보이는 사람.** 배경·디자인물(포토월·데스크·글자)은 원본 픽셀 그대로, 사람과 발밑 그림자만 더한다.
구 방식(Higgsfield·포토샵 수작업·경로 A/B/C 설명·마커 오버레이)은 `references/legacy-manual-workflow.md` — 마커 오버레이·포토샵 레이어가 필요할 때만 읽는다.

## 현행 파이프라인 (기본 — 이 순서로, 목표 15분)

0. **생성 허용**: `~/.claude/media_gen_standing.json` 이 켜져 있으면 묻지 않고 생성한다(2026-11-05 사용자 지시). Magnific 은 쓰기 전 예상 크레딧 한 줄만 보고.
1. **장면 이야기 한 줄** — 무슨 순간인지(연설·안내·등록·대화)와 **초점 하나**(포디움 연사·안내원·데스크). 모든 사람의 몸·얼굴·시선이 초점을 향하거나 서로 대화 쌍. 사람마다 동작(끄덕임·박수·프로그램 들기·손 모으기). **폰·사진 촬영 금지**(사용자 반려 "포디움 연사에 집중해야 한다니까 왜 사진 찍고 난리여"), 카메라 응시 금지, 근경 흐린 행인 금지.
2. **인원·자리** — 디자인물이 주인공이면 4~7명, 주 그래픽(타이틀·로고·슬로건) 앞은 비운다. 사람은 **테이블 앞(발이 보이는 자리)** 을 우선한다 — 테이블 뒤 사람은 다리가 잘려 떠 보이기 쉽다. 한쪽이 비면 1~2명만 더한다("우측이 너무 비어 보여").
3. **치수 막대 → 확인받기** — 실치수 아는 수직 요소 2개(발주 크기 − 불칼질: 예 포토월 보이는 높이 3,000, 데스크 앞판 1,050)를 서로 다른 깊이에서 재서 `scripts/scale_bars.py` 로 1.7m 막대를 원본 위에 그려 보여주고 "이 크기 맞습니까?" 한 줄. 사람 손이 계산을 이긴다.
4. **생성 = Magnific Nano Banana 2.1 편집, 2K, 2장(약 1분·130크레딧)** — 입력: 현재 이미지 + 흰 바탕 막대 PNG. 프롬프트 뼈대는 아래. GPT 는 4~6분·1672px 라 사람 생성에 쓰지 않는다(GPT 는 배경 교체 전용 — `venue-photo-variation` rebg). 두 장 중 초점·방향이 맞는 것을 고른다(포디움을 옮기거나 테이블을 지운 후보는 버림).
5. **AI 3단계 (2026-11-06 확정 — "AI 3단계로 줄이기")** — 렌더(흰 배경) 한 장에서 시작:
   - ① **생성 1회**: 렌더 위에 키 막대를 직접 그린 가이드(`scale_bars.py` → 렌더에 합성)를 Magnific NB 2.1 2K 2장으로. 프롬프트에 '배경 = 같은 카메라 2점 투시 홀 + 사람 = 막대 자리'를 한 번에. Magnific 은 막대 길이를 무시하고 기준의 1.05~1.13배로 그린다(막대를 1.7·1.5·1.36m 로 바꿔도 같음, 실측 8장).
   - ② **크기**: `check_scale.py --k --yh` 로 사람별 비율 → 손 확대로 후보 고름 → ±5% 넘으면 같은 사진에서 사람만 지운 판(Magnific '사람 제거' 편집 1회, 정합) → `extract_people.py --auto-boxes`(people_ids.png) → `rescale_people.py --ids` (크기 맞는 사람도 다시 붙임, 붙인 위치는 `*_people.png` 로 저장).
   - ③ **부스 통째 고정(기본, 2026-11-06 확정)**: `lock_booth.py --src 렌더 --alpha 부스알파 --cand AI사진 --people 사람마스크 --light-sigma 14` — 부스는 렌더 한 장 그대로(전역 정렬만), 조명·노이즈만 AI 사진에서. 경계는 부스 외곽선·사람 윤곽선뿐이라 면 중간 이음매가 생기지 않는다. 사람 마스크는 사람마다 박스 분할로 빠짐없이. (구) 인쇄물 조각 복원 `restore_graphics.py --gmask 인쇄물마스크 --people *_people.png ∪ u2net_human_seg` — 마스크는 **인쇄물 면(간판·패널·그림 벽·카운터 인쇄면)만 통째로**. 블럭·프레임·카펫·천장 같은 구조물은 절대 넣지 않는다(넣으면 CG 와 사진이 조각보로 섞임). 경계는 자동으로 부드럽게 섞고, `*_review.jpg`(부스 6칸 100%)를 반드시 보고 낸다.
   - 옛 방식(오려 붙이기·compose_keep_design·GPT 실사화 8단계)은 느리고 흠이 많아 기본에서 뺐다. 크레딧: 생성 130 + 사람 제거 65.
6. **눈으로 확인** — `check_feet.jpg`(사람별 아랫단 확대)에서 발이 바닥·가림막에 닿는지, 옷단 아래로 카펫이 보이지 않는지(공중부양) 본다. 수치 검사로는 못 잡는다(2026-11-05 실측 5건 중 2건 놓침 — 꽃·테이블이 옷단을 가려 '지지'로 보임). 떠 있는 사람은 **빼거나 재생성**한다(dy 로 내려 숨기면 키가 줄어 어색).
7. **납품** — `C:\Users\PSH\Downloads` 에만, 같은 파일명으로 덮어쓰기(프로젝트 폴더 금지). 해상도가 필요하면 마지막에 Magnific Precision photo 2배 업스케일(약 90크레딧).

## 상시 고도화 루프 (2026-11-06 사용자 지시 "앞으로 이런 식으로 계속 고도화시켜")

반려가 올 때마다 그 자리에서 다음 넷을 한 세트로 끝낸다 — 이미지만 고치고 넘어가지 않는다.
1. 보내준 조각의 **정확한 위치**를 찾는다(템플릿 매칭) → 단계별 결과(원본·배경·후보·최종)를 같은 자리에서 나란히 놓고 **어느 단계에서 생겼는지** 확인.
2. 그 단계의 스크립트를 고친다(모든 경로가 지나는 한 곳). **같은 종류 흠이 두 번 연속 새로 나오면 땜질을 멈추고 구조를 바꾼다**(예: 오려 붙이기 → 생성 사진 통째 + 디자인물만 원본).
3. 그 흠을 다시 잡는 회귀 테스트 1건(실제 납품 파일 좌표로) + 아래 점검표 한 줄.
4. 볼트 `feedback/` 노트·`log.md` 한 줄, `check_skills.py` → `sync.ps1` 전파.
고친 뒤엔 '부스 안·사람 밖 변경' 위치를 색으로 찍어 의도한 곳(사람·그림자·반사)만 바뀌었는지 확인하고 납품한다.

## ★ as-built 실사 규칙 — 전시·행사 장면이면 필수

배경이 **전시부스·행사장·등록데스크·게이트·포토존·백월**이면 인물 프롬프트를 쓰기 전에 읽는다:

```
C:\Users\PSH\.agents\skills\interior-prompt-maker\references\as-built-reality.md
```

**사본을 만들지 않는다 — 이 경로 하나만 본다.** 어느 실사화 스킬로 들어오든 같은 파일이다.

인물 합성에서 특히 걸리는 것:

1. **스케일 앵커가 실사에 있다.** 연회의자 등받이 상단 ≈950 · 테이블 상판 ≈720 ·
   등록 백월 ≈2,480 · 옥타 폴 2,480(+어저스터 20 = 2,500) · 카운터·상담테이블 1,000.
   막대를 그릴 때 **이 기준물을 먼저 찾는다**(`scripts/scale_bars.py`).
2. **발광 부재 앞에 서는 인물은 색이 물든다.** 맥시마 프레임 앞이면 인물의 접지면·옆면에
   시안-블루가 얹히고, 바닥 카펫의 원래 색도 보라로 돌아가 있다. 인물만 중성색으로 두면 붕 뜬다.
3. **인물이 백월 앞에 서면 백월에 큰 그림자가 얹힌다.** 깨끗한 백월은 렌더 냄새다.
4. **등록데스크는 위에서 오는 확산광**이라 그림자가 발밑으로 짧게 떨어진다.
   무대 백월(하단 업라이트)의 그림자 방향과 반대이니 섞지 않는다.
5. **배경 구조를 인물이 가린다고 지우지 않는다** — 폴 이음선·나사 자국·걸레받이 밴드는
   인물 레이어 뒤에 그대로 살아 있어야 한다.

## 전시 조명 연동

- 행사장 조명이 포함된 장면에 사람을 넣을 때는 `cinematic-exhibition-lighting`에서 사용자가 선택한 합성본을 조명 정본으로 삼는다. 인물 스킬은 그 조명의 방향·색온도·바닥 반응만 사람에게 맞추고, 광원 수·빛줄기·간접광 배치를 새로 만들거나 바꾸지 않는다.
- 조명과 인물을 함께 이미지로 요청해도 조명 출력 계약은 조명 스킬이 맡는다: 최종 합성본과 같은 구도의 인물 없는 라이트 플레이트를 각각 유지한다. 인물 레이어·그림자는 합성본에만 더하며 라이트 플레이트에는 사람, 그림자, 의자, 테이블을 넣지 않는다.
- 사람 합성 후에도 무대·스크린·천장·벽·테이블에 이미 확정된 조명 반응은 보호한다. 인물의 접지 그림자와 바로 인접한 약한 스필만 추가 변경으로 허용한다.
