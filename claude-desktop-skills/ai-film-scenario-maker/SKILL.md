# AI 영상 시나리오 메이커

## 이 스킬이 하는 일

소재 한 줄을 받아 AI 영상 모델로 실제 만들 수 있는 시나리오 패키지를 낸다. 이야기를 먼저 확정하고, 그다음 컷으로 쪼개고, 마지막에 프롬프트로 바꾼다. 영상 생성은 하지 않는다.

핵심 원리 세 가지:

1. 감동은 사건이 아니라 재해석에서 나온다. 앞에서 무심히 본 장면의 의미가 뒤에서 바뀔 때 마음이 움직인다.
2. 짧은 영상은 하나만 담는다. 인물 하나, 원하는 것 하나, 가로막는 것 하나.
3. 말하지 않고 보여 준다. 감정을 설명하는 대사는 행동과 사물로 바꾼다.

## 시작 전 확인

소재를 받지 못하면 ASURA님 업무(전시·부스·행사 시공)는 소재로 쓰지 않고 일상 소재(가족·이웃·동네)로 정한다(2026-11-12 반려 "전시말고"). 행사 오프닝은 사용자가 행사명을 줄 때만 쓴다.

아래 네 가지 중 빠진 것이 있으면 가장 중요한 하나만 묻고, 나머지는 합리적으로 정한 뒤 무엇을 정했는지 첫 줄에 밝힌다.

- 소재 또는 브랜드·행사명
- 길이: 15초 / 30초 / 60초 / 3분
- 쓰임: 감동 단편 / 브랜드·기관 홍보 / 행사 오프닝 / 숏폼(릴스·스레드)
- 보고 난 뒤 남길 감정 한 가지

## 절차

### 1단계. 감정 목표 한 문장

"이 영상을 본 사람이 ___ 을 느끼고 ___ 을 떠올린다" 형식으로 쓴다. 두 가지 감정을 넣지 않는다.

### 2단계. 결말의 숨은 진실부터 정한다

관객이 마지막에 알게 될 사실 하나를 먼저 쓴다. 중간 장면은 전부 이 진실에서 거꾸로 짠다. 숨은 진실 후보를 3개 내고, 가장 '앞 장면을 다시 보게 만드는' 것을 고른 이유를 한 줄로 적는다.

### 3단계. 구조를 고른다

| 쓰임 | 구조 | 뼈대 |
|---|---|---|
| 감동 단편, 브랜드 필름 | 기승전결 반전형 | 기(일상) → 승(반복되는 작은 행동) → 전(숨은 진실 공개) → 결(같은 장면을 다른 눈으로 다시 봄) |
| 인물의 변화가 중심 | 스토리 스파인 | 옛날에 ___ → 매일 ___ → 어느 날 ___ → 그래서 ___ → 그래서 ___ → 마침내 ___ |
| 행사 오프닝, 기관 홍보 | 문제-전환-비전 | 지금의 불편·질문 → 전환점(기술·사람·사건) → 달라진 장면 → 행사명·슬로건 |
| 숏폼 | 훅-약속-전개-한 방 | 0~3초 훅 → 3~5초 무엇을 보게 될지 → 전개 → 마지막 한 컷 |

### 4단계. 인물과 사물

- 인물: 평범하고 실재할 법한 사람. 성공보다 애쓰는 모습을 보여 준다. 원하는 것과 가로막는 것을 각각 한 줄.
- 사물 모티프 1개: 세 번 등장시킨다. 첫 번째는 무심하게, 두 번째는 살짝 걸리게, 세 번째에 진실과 함께.
- 관계는 하나만: 부모와 자식, 노부부, 스승과 제자, 동료, 낯선 사람 중 택일.

### 5단계. 비트시트

길이별 비트 수: 15초 3~4개, 30초 5~6개, 60초 8~12개, 3분 20~30개. 각 비트에 시간 구간, 화면에서 벌어지는 일, 관객이 느끼는 것, 감정 강도(1~5)를 적는다. 감정 강도가 계속 오르기만 하면 안 된다. 정점 직전에 한 번 가라앉힌다.

### 6단계. AI 제작 제약을 통과시킨다

- 한 컷에 주체 하나, 동작 하나, 카메라 위치 하나. 전환이 있으면 컷을 나눈다.
- 컷 길이 3~8초.
- 한 컷에 인물 2명 이하.
- 장소 1~2곳.
- 손 클로즈업, 화면 속 글자·간판·로고가 읽혀야 하는 컷은 피한다. 꼭 필요하면 '후반 합성' 표시를 단다.
- 대사는 최소. 립싱크가 필요한 컷은 표시한다.
- 행사명·로고·슬로건은 감정 정점 뒤 마지막 컷에만.

제약에 걸려 비트를 바꿨으면 무엇을 왜 바꿨는지 적는다.

### 7단계. 샷리스트와 프롬프트 초안

컷마다 아래 항목을 채운다. 프롬프트는 주체 → 동작 → 배경 → 카메라 → 빛 순서로 쓴다. 광원은 하나만 명시한다.

```
컷 번호 / 시간
이야기에서 맡은 역할
화면 (주체, 동작, 배경)
카메라 (크기, 움직임)
빛 (주 광원 하나, 방향)
연속성 (의상, 소품, 시선 방향, 시간대)
소리 (현장음, 음악 진입 여부, 대사)
영상 프롬프트 초안 (영문)
후반 합성 필요 여부
```

## 산출물 순서

1. 정한 것과 가정한 것 (첫 줄)
2. 로그라인 한 문장: 누가, 무엇을 원하고, 무엇이 막고, 마지막에 무엇이 드러나는가
3. 숨은 진실과 사물 모티프
4. 비트시트 표
5. 샷리스트 표
6. 내레이션·자막 원고 (있을 때만, 마지막 한 줄 위주)
7. 음악·소리 큐: 음악은 어디서 들어오고 어디서 빠지는가
8. 반려 점검표 결과

내레이션 분량은 원고를 실제 속도로 소리 내어 읽은 시간으로 맞춘다. 글자 수로 추정하지 않는다.

## 반려 점검표

산출물을 내기 전에 항목마다 예/아니오로 채워 붙인다. 하나라도 '아니오'면 고친 뒤 낸다.

| # | 항목 | 통과 조건 |
|---|---|---|
| 1 | 한 문장 요약 | 줄거리를 한 문장으로 말할 수 있다 |
| 2 | 재해석 | 마지막 진실이 앞 장면의 의미를 바꾼다. 그냥 새 사건이 아니다 |
| 3 | 설명 대사 | 감정을 말로 설명하는 대사가 없다 |
| 4 | 사물 모티프 | 같은 사물이 세 번 나오고 세 번째에 의미가 바뀐다 |
| 5 | 값싼 눈물 | 죽음·불치병·사고에만 기대지 않는다 |
| 6 | 하나만 | 인물·목표·장애물이 각각 하나다 |
| 7 | 컷 단위 | 모든 컷이 주체 하나, 동작 하나, 카메라 하나다 |
| 8 | 제작 가능 | 글자·손·3인 이상 컷에 후반 합성 표시가 있다 |
| 9 | 브랜드 위치 | 로고·행사명이 감정 정점보다 뒤에 있다 |
| 10 | 첫 3초 | 숏폼이면 첫 컷이 설명이 아니라 움직임이나 질문으로 시작한다 |
| 11 | 업무 소재 | 소재를 받지 못했을 때 ASURA님 업무(전시·부스·행사 시공)를 소재로 쓰지 않았다. 일상 소재로 정했다 |
| 12 | 장소 수 | 장소가 1~2곳이다(회상 장면도 한 곳으로 센다) |

## 하지 않는 것

- 영상·이미지를 생성하지 않는다. 프롬프트 초안까지만 낸다.
- 기존 영화·광고·캐릭터의 줄거리나 장면을 베끼지 않는다. 구조만 참고한다.
- 실존 인물을 주인공으로 쓰지 않는다.
- 확인하지 못한 사실(기관 실적, 수치)을 원고에 넣지 않는다. 필요한 자리는 빈칸으로 두고 표시한다.

## 고칠 때

사용자가 반려한 사유는 이 문서의 반려 점검표에 항목으로 추가한다. 같은 시나리오를 고칠 때는 처음 낸 산출물 위에 덮어쓴다.
