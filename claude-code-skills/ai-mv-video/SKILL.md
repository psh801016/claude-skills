# AI 실사 뮤직비디오 (ai-mv-video)

## 1. 기획 — 콘티 전에 정할 것 (사용자에게 한 번에 묻기, 기본값 제시)
- 레퍼런스 영상은 watch 스킬로 프레임을 본 뒤 "왜 실사처럼 보이나"를 3줄로 적고 시작(인물 클로즈업 위주·움직임 작음·2~4초 컷).
- **캐스팅**: 성별·나이(기본 20대 초반)·인원. **음악**: 사용자 계정 Suno 권장(제미나이 Lyria는 촌스럽다 반려). 곡은 자르지 말고 통째로 쓴다(이음새·정적이 "끊김"으로 들림).
- 공간 투어(와이드+큰 카메라 무빙)는 AI 영상 최약점 — 인물이 주인공, 공간은 배경.

## 2. 배우·의상 고정 (생략 금지 — 생략하면 컷마다 번호·바지가 바뀐다)
- 배우마다 **얼굴 기준 1장 + 전신 의상표 1장(앞·뒤)**. 개인 GPT(`codex exec -m <models_cache priority 1>`)로 만들고 프롬프트에 `./경로.png` 를 적어 열어보게 한다(`-i` 금지).
- 얼굴: "실제 인디 영화 배우, 깨끗한 피부·옅은 화장, 가까이서만 보이는 피부결, 여드름·잡티·플라스틱 피부 둘 다 금지". 무표정·입 다문 기준 사진(웃는 기준 사진은 모든 컷을 웃게 만든다).
- **실제 인물(사용자 본인) 닮음**(2026-11-11 반려 "너무 살쪘어, 현실감 있게 똑같이 안 나와"): 캐릭터 시트를 한 장으로 통째 생성하면 얼굴이 작아 일반 미남으로 수렴하고, 얼굴형을 글로 묘사("둥근·도톰한 볼")하면 과장돼 살찐다. → 얼굴이 크게 보이는 컷은 **원본 사진을 편집**(옷·배경·소품만 교체, 얼굴·각도 유지)해 만들고 시트에 PIL 로 끼운다. 얼굴 형용사는 쓰지 말고 "원본과 동일, 마르게·살찌게·미화 금지"만.
- **레퍼런스 영상 의상·머리·안경**(2026-11-11 반려 "듀스 뮤비 의상이 아니네", "안경 쓰면 바보 같아", "헤어 멋지게"): 의상을 글로 지어내지 말고 원본 영상 프레임(ffmpeg 1280px)을 의상 참고로 프롬프트에 경로로 준다("얼굴·피부·문신은 베끼지 마" 명시). 랩형 스포츠 선글라스 금지 — 얼굴형에 맞는 얇은 테 선글라스. 머리는 본인 머리 그대로보다 영상 톤의 스타일(예: 슬릭백 언더컷)을 고정 문장으로. 시트는 칸별 생성 → PIL 조립(전신은 같은 키·같은 회색 바탕·가장자리 흐림).
- **전신 컷 얼굴·체형**(2026-11-11 반려 "바지 쫄쫄이냐", "전신 얼굴 이상", "코가 이상해 나 같지 않아", "헤어 느끼해"): 전신은 얼굴이 작아 일반 얼굴로 나온다 → 머리 영역을 잘라 1024로 키워 원본 얼굴 기준으로 보정한 뒤 타원 마스크로 되붙인다. 보정 프롬프트엔 코를 구체적으로(콧대 곧음·코끝 둥글고 도톰·콧볼 넓음, '얇고 뾰족한 코 금지') — 생성 모델은 콧대를 높이고 뾰족하게 만든다. 머리는 광택 슬릭백·포마드 금지(느끼함), 무광 텍스처 크롭이 무난. 레퍼런스 의상의 실루엣(와이드 바지·오버핏)까지 문장에 넣는다. 전신은 85mm·허리 높이 카메라·7.5~8등신 룩북 비율.
- 의상 문장을 모든 컷 프롬프트에 그대로 복사: 예 `plain navy mesh jersey with NO number, light-blue baggy jeans, white sneakers`. 번호·로고는 기본 "없음".

## 3. 스틸 → 검수 → 영상 (컷마다, 일괄 생성 금지)
- 스틸 프롬프트: "35mm 인디 뮤비 필름 스틸, 실제 조명(형광등·네온·가로등), 카메라를 거의 안 봄, 연출 안 된 순간". 금지어: cinematic·대칭·완벽한 피부. 컷마다 표정 지정, 함박웃음은 전체 1컷.
- **스틸 검수**: 960px 이상으로 얼굴·손(좌우·5손가락)·성별·의상(번호·바지·안쪽 옷·신발)을 예/아니오. 하나라도 아니오면 영상으로 넘기지 않는다.
- 영상 생성 후 `python scripts/qa_frames.py <clip> <out> --step 0.5` 로 0.5초 간격 전수 확인(`QA_FRAMES_OK`). 드론·기중기 같은 물체, 클립 안 컷 분할·같은 동작 반복, 번호 재등장 확인.

## 4. 카메라 무빙 (모델별 실제 능력)
| 모델(Magnific) | 5초 크레딧 | 카메라 제어 | 쓰는 곳 |
|---|---|---|---|
| Kling 2.5 1080p | 325 | 파라미터 없음, 프롬프트 무빙 약함 | 클로즈업·고정·느린 푸시인 |
| Seedance 2.0 Mini 720p | 700 (9초 1,260) | `cameraMotion` 52종 | 오빗·트럭·핸드헬드 |
| Seedance 2.0 / 2.5 1080p | 3,500 / 3,950 | 52종 | 쓰기 전 반드시 승인 |
- 함정: `craneUp`→화면에 **기중기**, `fpvDrone`→**드론 물체**가 그려짐. 대신 `pedestalUp`·`tiltUp`·`pushIn`·`handheld`·`orbitRight`·`truckLeft/Right`.
- `truck` 를 피사체와 같은 속도로 하면 정지처럼 보인다 → 달리기는 `handheld` + "카메라보다 빨리 화면 밖으로".
- 정면으로 달려오는 컷은 프레임마다 얼굴이 바뀐다 → 측면.
- Seedance 9초 이상은 클립 안에서 여러 컷·빠른 드론 스윙으로 나뉘며 동작을 반복하고(점프 3번) 소품이 갑자기 사라진다(모자). Kling 엔딩도 점프를 반복했다 → 엔딩은 **최고점 한 프레임 정지 + 플래시 + 느린 줌인 + 페이드**가 깔끔(크레딧 0, 2026-11-11 채택).
- Seedance는 의상 디테일을 바꾼다(버킷햇→캡 등) — 의상이 중요한 컷은 Kling 우선.
- Seedance는 프롬프트로 막아도 저지 번호를 다시 그린다 → 생성 후 검수, 지울 땐 `video_modify` 자동(Grok, 5초 400). 실패하면 스틸에서 지우고 Kling 재생성(325)이 가장 싸다. Kling4/Aleph2 수정은 4초 1,320~2,340.
- 장면별 기본: 클로즈업=아주 느린 푸시인 / 대화·휴식=고정 / 춤=오빗 / 탈것=트럭 / 질주=핸드헬드 / 새벽 풍경=틸트업·푸시인 / 포토부스=표정 다른 스틸 3장을 박자마다 교체+플래시.
- `noMusic` 과 `withSoundEffects:false` 는 같이 못 쓴다(소리 없이 → `withSoundEffects:false` 만).

## 5. 음악·편집
- 곡 구조 실측(50ms RMS)으로 정적·드롭·브레이크 시각을 먼저 잰다. 정적은 검은 화면, 브레이크는 조용한 컷으로 살린다.
- 컷 경계는 `round(t*24)` 프레임 수로 `-frames:v` 지정(`-t` 반복은 반올림 누적으로 0.12초 밀림).
- 5초 클립을 늘리는 슬로모(minterpolate blend)는 잔상(움직이는 카메라에서 해가 2개) → 길이가 필요하면 길게 생성하거나 `setpts=1.5*PTS`(섞지 않음)만.
- 720p 클립은 lanczos 1080p 업스케일로 해상도만 맞춘다. 톤·그레인은 아래 5-1 필름룩 하나로 통일(따로 `noise` 걸지 않기).
- 완성본은 컷마다 4시점 960px(`--cuts` 경계) 검수 후 **처음 납품 파일에 덮어쓴다**. 30MB 넘으면 폰용 720p 별도.

## 5-1. 필름룩 후반 (AI 티 줄이기 — 모든 영상 완성본에 기본 적용, 크레딧 0)
- **모드 고르기(2026-11-12 사용자 "선명하게 나와야하는것들은?")**: 레트로·필름·감성 무드 → 기본 필름룩. 전시·제품·글자·로고가 보이는 것, 요즘 톤 선명한 뮤비·광고 → **영상은 `python scripts/sharp_finish.py in.mp4 out.mp4`**(밝기 깜빡임 보정·움직임 적응 시간축 평균·큰 경계만 헤일로 제거·하이라이트 롤오프, 노이즈 기본 0 — 플라스틱 면 컷만 `--noise 0.004`; p12 실측 깜빡임 −49%·끓음 −27%, 가는 글자 획 유지), 사진은 `film_look.py --clean`(고운 그레인 2). 애매하면 선명형. 근거·실측표: `wiki/reference/ai-sharp-clean-deai-method-and-test-2026-11-12.md` 5절.
- 인코딩은 항상 `-bf 0`(B프레임이 4프레임마다 밝기를 출렁여 깜빡임 2배 — 두 스크립트에 이미 들어 있음, 직접 ffmpeg 로 다시 인코딩할 때도 붙인다).
- 편집 완성 뒤 마지막 단계로 `python scripts/film_look.py 완성.mp4 완성_필름룩.mp4` (ffmpeg 만, 소리 그대로). 원본보다 화질 좋은 `_원본` 이 있으면 그걸 입력으로.
- 순서 고정: 약한 블러 0.6 → 톤 커브(검정 0.04 들어올림·하이라이트 0.95) → 채도 0.86 → 섀도 청록/하이라이트 웜 → 시간축 그레인(루마 8, 색 2).
- 납품 전 처리 전/후 얼굴 확대 비교 1장을 보여준다. 결과는 새 파일로 저장하고 원본은 덮지 않는다.
- 후반으로 못 고치는 것: 텍스처 끓음·밝기 깜빡임·손·글자·물체 사라짐 → 그 컷은 재생성(크레딧 견적 먼저).
- **값 이력(사용자 판정이 나올 때마다 한 줄 추가, 기본값도 갱신)**:
  - 2026-11-12 p12 테스트 그레인 11 → 하늘에서 거침 → 사용자 "그레인 줄여서 전체 적용" → 기본 8.
  - 2026-11-12 공유용은 2패스 16Mbps(60초 → 121MB). 보관용 crf16 은 그레인 때문에 393MB.
  - 사진(실사화·합성 마무리)도 같은 스크립트, 그레인 기본 4 — venue-photo-variation 5절·person-layer-maker 에서 호출. 2026-11-12 사용자 "선택으로 두기" → 사진은 기본 적용 아님, 요청·제안 시에만.
- 리서치·남은 과제: `wiki/reference/ai-video-remove-ai-look-research-2026-11-12.md`, 인계문 `conversations/handoffs/HANDOFF-ai-video-deai-pipeline-2026-11-12.md`. Topaz·Resolve 미설치라 LUT 는 curves 대체.

| 14 | 실제 인물이면 원본 사진 편집으로 얼굴 컷을 만들고 원본과 나란히 대조했나 |

| 18 | 완성본에 5-1 필름룩을 걸었고 전/후 얼굴 확대 비교를 보여줬는가(값은 이력 최신 기본값) |
