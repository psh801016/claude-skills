# AI 작업일지 SNS 게시 (ai-worklog-sns)

계정 @nana80psh (스레드·인스타 같은 계정). 운영 노트·수치·조사 출처: `G:\내 드라이브\AUSURA\AI-Sessions\wiki\playbooks\sns-ai-작업일지-운영.md`

모호하면 묻는 질문은 하나만: "어떤 작업을 올릴까요?" — 답이 없으면 AI-작업기록에서 비포/애프터가 가장 또렷한 최근 작업 1건을 골라 후보로 보여준다.

## 1. 출력 규격 (항상 이 순서·이 제목, 생략 금지)
1. **반려 점검표** — 아래 표를 예/아니오로 채운다.
2. **글** — 스레드용(500자 이하, 해시태그 없음) / 인스타용(같은 글 + 해시태그 7개 이하) / 블로그용(같은 톤, 조금 길게).
3. **이미지** — 파일 경로 목록(최대 6장, 순서대로).
4. **릴스** — `REEL_OK` 경로 또는 "이번엔 없음 + 사유".
5. **견적** — 이번 게시 팩에 쓴 크레딧 합계(0 포함).

## 2. 고르기·이미지
- 원본은 `G:\내 드라이브\AI-작업기록\` 전체에서 고른다(오늘 것만 보지 않는다). 사진처럼 보이는 결과만. 회색 매스·작은 도면만 있는 장은 과정 컷으로만 쓴다.
- 이미지는 적게: 비포/애프터 1~2쌍, 많아도 6장. **순서는 쌍마다 완성 → 3D**(완성 사진으로 시선을 잡고 "이게 3D였다"로 반전. 첫 장이 썸네일이라 3D·도면이 첫 장이면 계정이 어둡게 보인다 — 2026-11-11 CSK 편, 사용자 "합성한 걸 먼저"). 같은 프로젝트 사진은 한 글에 모아 올린다(나중에 추가 불가 → 재게시했음). 한 프로젝트로 처음부터 끝까지 이어지게(도면과 완성이 다른 프로젝트면 반려).
- 행사명·고객사 로고·호텔명은 모자이크(PIL 픽셀화). 작은 제목 글씨도 확대해서 확인.
- 합성본이 붙인 티가 나면 Magnific `gpt-2-6`(variant sunburst) i2i 로 재실사화 — 쓰기 전 `simulate_cost` 견적을 한 줄 보고. 결과는 원본과 50% 겹쳐 구도 확인.

## 3. 글 톤
- **정보가 있는 글이 기본**(2026-11-11 사용자 "단순 눈요기 말고 정보도, 가벼운 사람으로 보이기 싫다" + 실측: 단계·수치가 있는 모델링 글 905조회·반응 최고, 한 줄 테스트 글은 반응 거의 없음). 무엇을·어떤 순서로·결과 수치·한계/판단을 실무자 톤으로. 금지는 그대로: 자랑조·퀴즈형·호객·과장. '도구명 금지'는 완화 — 필요한 만큼만(남이 따라할 수 있는 수준), 모델 버전·크레딧 나열은 피함. '테스트' 한 줄은 정말 시험작일 때만.
- 혼자 남기는 기록체(~했다). "보여드릴게요" 같은 독자 호명 금지.
- 메시지: 내 손으로 한 게 없다 · 전부 AI 자동 · 팀으로 일주일 → 혼자 몇 시간. 도구명·모델명·검증 방법·치수 같은 디테일 금지.
- 첫 줄 `[AI 작업일지 #NN] <주제>` 형식은 사용자가 시리즈명을 확정하면 붙인다.
- 문체는 실무자 문단형: 줄을 잘게 끊지 않고 2~3문장 한 문단, "~이랑"·"전부 ~했다" 같은 쉬운 나열 대신 실무 어휘(제안 단계·연출물·동선·시선·완성도). 짧은 줄바꿈 나열은 "초딩 글"로 반려(2026-11-11, 채택 예: "제안 단계에서 공간 전체를 모델링할 필요가 없어졌다. …").
- 시험작·테스트물은 한 줄로 짧게 "AI로 ~ 테스트." — 서술 늘어놓기·"내 손으로 한 장면도 없다" 같은 자랑조 금지(2026-11-11 MV 게시, 사용자 "너무 서술하지마", "자랑하듯 쓰지 말라고").
- 끝맺음은 담담한 서술 한 줄로. "넘겨 보면~", "보이나?", "어떤 게 더 좋아?" 같은 퀴즈·호객형 질문은 유치하다고 반려(2026-11-11).

## 4. 릴스 (크레딧 0이 기본)
- **영상은 허락받고 만든다**(2026-11-11 "야 영상 이제 허락받고 만들어"): AI 생성뿐 아니라 ffmpeg 편집 영상(릴스·메이킹)도 사용자가 그 영상을 만들라고 한 경우에만. 크레딧 0이어도 같음.
- **형식을 바꿀 땐 먼저 묻는다**(2026-11-11 "누가 맘대로 영상 만들래!!!"): 반려를 받으면 이미지→영상처럼 형식을 내 판단으로 바꾸지 말고, 고칠 방향 2~3개를 한 줄씩 제시해 고르게 한다. 크레딧이 0이어도 마찬가지.
- **같은 작업 우려먹기 금지**(2026-11-11 "메이킹 올리잖아, 중복돼서 우려먹는 것 같아"): 한 작업은 본편+메이킹까지. 숫자 체험기 같은 3번째 글은 새 작업을 만든 뒤 그 작업으로 쓴다.
- **메이킹 편은 결과 스틸 나열 금지**(2026-11-11 "그냥 스틸컷 올린 거 같은디") — 바뀌는 과정이 보여야 한다: 시행착오 버전을 박자마다 플래시 → 콘티 → 정지 스틸이 와이프되며 영상으로 살아나는 쌍(ffmpeg xfade wiperight) → 완성 컷. 예: `reel_csk/making_reel.py`.
```
python "C:\Users\PSH\.agents\skills\ai-worklog-sns\scripts\reel_wipe.py" --clay <흰모델.png> --photo <실사.png> --flash <도면1> <도면2> --cx 0.5 --out <릴스.mp4>
```
- 같은 각도의 흰 모델→실사 와이프 반전 1번이 핵심. 7~15초. 글자는 가운데 한 줄 두 번.
- 음악은 넣지 않는다(인스타 앱에서 유행 음원을 사용자가 붙임).
- AI 영상 생성은 기본 금지. 사용자가 요청할 때만, `simulate_cost` 견적(5초 기준 Kling 2.5 1080p 325 / Seedance 2.5 1080p 3,950)을 먼저 보여주고 승인 후.
- 사용자가 마음에 드는 릴스 레퍼런스를 주면 그 형식을 우선한다.

## 5. 게시
- **스레드**(claude-in-chrome): 새 스레드 → 글 입력 → 숨은 file-input 에 이미지 업로드 → 주제 태그 `AI 활용` 1개 → 게시 → 프로필에서 1회만 올라갔는지 확인. 수정은 게시 후 15분 이내만.
- **영상 게시**: 브라우저 업로드는 10MB 제한 → `ffmpeg -vf scale=1280:720 -b:v 1150k`(2-pass, 오디오 96k)로 1분 ≈ 9.4MB. 인스타 영상은 '새 릴스'가 되고 **Facebook 공유 토글이 기본 켜짐·클릭이 되돌아감** → JS 로 `[role=dialog] [role=switch]` 의 aria-checked 를 확인해 끄고, 공유 직전 다시 확인. 'Facebook 공유를 중단하시겠어요?' 창이 뜨면 '이 릴스 공유 안 함'(모든 릴스 중단은 설정 변경이라 사용자 확인). AI 영상은 'AI 레이블 추가' 켬.
- **페이스북 자동 공유는 꺼 둠**(2026-11-11 사용자 지시 "페북에 중복으로 안 올라가게"): Meta 계정센터 → 크로스 프로필 환경 → 내 스토리·릴스·게시물 → nana80psh → '내 Instagram 게시물' 끔(스토리는 켜짐 유지). 원인: 인스타 글을 지우고 다시 올려도 페북 복사본은 남아 중복이 쌓임. 다시 켜지지 않았는지 게시 때 확인.
- **예약 게시**: 인스타는 캡션 화면 '콘텐츠 예약' 토글 → 날짜·시간(Hours/Minutes/AM PM 스핀버튼) → 상단 '예약'. 영상 커버는 '커버 사진' 틀을 드래그해 고름(첫 프레임이 검정이면 꼭). 스레드는 작성창 ⋯ → '예약...' → 날짜·hh·mm → 완료 → '예약' 버튼, 확인은 작성창 위 임시저장 아이콘 → '임시 저장본'. **스레드는 AI 레이블을 켜면 '예약...'이 비활성** → 예약 글은 레이블 없이(2026-11-11 실측).
- **유튜브**(채널 ASURA, studio.youtube.com): 우상단 업로드 아이콘 → 숨은 file-input 업로드(10MB 이하본) → 제목·설명(테스트물은 한 줄) → '아니요, 아동용이 아닙니다' → 고급 설정 표시 → **'AI 사용: 예'**(실사 인물 AI 영상은 표시 의무) → 다음×3 → 저작권 검사 통과 확인 → 공개 → 게시.
- **10MB 넘는 영상(원본 화질)**: 파일을 127.0.0.1 로컬 서버(CORS + Access-Control-Allow-Private-Network)로 띄우고, 업로드 창에서 JS로 `fetch → File → DataTransfer → input.files` 넣고 change 이벤트(2026-11-11 유튜브 1080p 177MB 성공). 끝나면 서버 종료. **올린 영상 파일은 유튜브·인스타·스레드 모두 교체 불가** → 새로 올리고 예전 것은 비공개(삭제는 사용자 확인).
- **인스타**(claude-in-chrome): 만들기 → 게시물 → 숨은 file-input 업로드 → 자르기 '원본' → 다음 → (창이 넓어진 뒤) 다음 → 캡션 → **'Threads에도 공유' 끄기** → 공유하기 → 게시물 수가 1 늘었는지 확인. 웹엔 '프로필 고정' 메뉴 없음(앱에서).
- **네이버 블로그**: 크롬 확장·내장 브라우저 모두 안전제한 차단. 본문을 `Set-Clipboard` 로 클립보드에 넣고 이미지 폴더를 탐색기로 연 뒤, 사용자에게 붙여넣기 순서를 번호로 안내.
- 게시는 사용자가 "올려"라고 한 그 건만. 게시 후 `log.md` 한 줄.
- **계정 결 유지**: 작업일지와 톤이 다른 글(테스트·홍보·존댓말 해시태그 글)은 ⋯ → '보관'(삭제 아님). 주제 태그는 "AI 활용", 프로필 관심사는 Architecture Threads + AI Threads.
- **댓글엔 꼭 답글**(사용자 확인 후): 짧은 공감 한 줄. 크레딧·견적 같은 이야기는 금지가 아니라 상황에 맞게 — 상대 말에 그대로 맞장구치는 정도로만, 노하우 설명으로 흐르지 않게(2026-11-11 사용자 정정).
