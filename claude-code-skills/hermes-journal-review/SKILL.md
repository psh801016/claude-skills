# 에이전트 저널 검토 — 제안 전용

Claude Code · Codex · Antigravity 세 런타임이 남긴 저널을 읽고, **하네스와 규칙을
어떻게 고치면 좋을지 제안서를 쓴다.** 고치지는 않는다.

## 절대 규칙 (★ ASURA님 지시 2026-08-13)

- **제안만 한다.** `rules.md`, `~/.claude/settings.json`, `~/.codex/hooks.json`,
  `~/.gemini/config/plugins/**`, 훅 스크립트를 **직접 수정하지 않는다.**
  AI가 자기 규칙을 자기가 고치면 통제를 벗어난다. 반영은 사람이 결정한다.
- **근거 없는 제안 금지.** 모든 제안에 저널의 어느 기록을 근거로 하는지 적는다.
  기록이 적으면 "표본 부족"이라고 쓰고 제안하지 않는다.
- **저널은 읽기 전용.** 원본 줄을 지우거나 고치지 않는다.

## 절차

**1) 요약을 뽑는다.** 원본을 통째로 읽지 말 것 — 토큰만 먹는다.

```
python <이 스킬 폴더>/scripts/summarize.py
```

경로는 자동 판별한다(도커 안 `/opt/data/agent-journal/`, 호스트 `~/.hermes/agent-journal/`).

**2) 이상징후를 읽는다.** 요약이 아래를 표시해 준다.

| 신호 | 뜻 | 제안 방향 |
|---|---|---|
| 한 세션이 3회 이상 압축 | 복사본의 복사본 → 맥락 열화·할루시네이션 위험 | 그 작업 유형은 세션을 더 일찍 나누자고 제안 |
| 자동압축 비중이 높음 | 의도적 압축을 못 하고 밀려서 당하고 있음 | 압축 지시문 보강 또는 작업 분할 제안 |
| 특정 작업폴더에 압축 집중 | 그 작업이 컨텍스트를 크게 먹음 | 해당 작업용 규칙·스킬 정비 제안 |
| Antigravity 오류 종료 | 도구·권한·프롬프트 문제 | `transcript` 를 열어 원인 확인 후 제안 |
| 깨진 기록 | 훅 계약이 바뀌었을 수 있음 | 훅 스크립트 점검을 **경고**로 보고 |
| 사용자가 직접 준 압축 지시 | 기본 지시문이 부족하다는 신호 | 반복되는 요구를 기본 지시문에 넣자고 제안 |

**3) 필요할 때만 원인을 판다.** Antigravity 기록의 `transcript` 경로에 그 대화의
전체 기록이 있다. 오류나 이상 패턴이 있을 때만 열어본다. 정상 기록은 열지 않는다.

**4) 제안서를 쓴다.** 저널과 같은 폴더에 날짜별로 남긴다.

```
<저널 폴더>/proposals/YYYY-MM-DD.md
```

서식:

```markdown
# 저널 검토 제안 — YYYY-MM-DD
표본: N건 (기간: ~ )

## 제안 1: <한 줄 요약>
- 근거: <저널의 어떤 기록 몇 건>
- 지금 상태: <현재 규칙/설정이 어떻게 되어 있는지>
- 제안: <무엇을 어떻게 바꾸자>
- 위험: <바꿨을 때 부작용>
- 판단 필요: ASURA님

## 제안 없음 항목
- <살펴봤지만 문제 없던 것들. 표본 부족도 여기.>
```

**5) 보고한다.** 제안서 경로와 제안 개수만 짧게 알린다. 제안 본문을 통째로
읊지 않는다. 급한 경고(깨진 기록·오류 급증)가 있으면 그것만 한 줄로 덧붙인다.

## 하지 말 것

- 표본이 10건도 안 되는데 경향을 단정하는 것
- "최적화했습니다" 같은 완료 보고 — 이 스킬은 아무것도 고치지 않는다
- 정상 기록의 transcript 를 전부 열어보는 것 (토큰 낭비)
- 저널에 없는 내용을 추측으로 채우는 것
