## 1. 시트 양식
- 바탕 회색(K25) 또는 흰색. **맨 위 구역 이름 크게**(무대 / 등록데스크 / 포토존 / 게이트 / 카페테리아 / 콘솔가림막).
- 판 위 라벨 3~4줄, 왼쪽 정렬(가운데 정렬도 씀): `품목(좌/우·상단/하단)` / `재질 / 마감` / `WxHmm`(소문자 x) / `nEA`. 특수 마감(상하단 **20mm** 바미싱)은 **빨간 글자**.
- 같은 구역 판은 **한 시트에 같은 축척으로 나란히**. 좌·우 쌍은 '(좌) 1EA (우) 1EA'로 둘 다 그린다(디자인이 다르니까). 같은 디자인 날개는 한 번에 nEA.
- 파일: `발주\원본\<구역>.ai·jpg` → 컨펌 후 `발주\출력\<구역>_출.ai·jpg`. 품목이 늘면 `_추가_출`.
- 재질 기본값: **현수막 / 상하단 바미싱**(대부분). 목공 백월은 '현수막 불칼질 / 장폭출력'. 기둥 감는 날개(450×4960·6500)는 '현수막 둥글게 양면'.

## 2. 치수 관례(실제 발주 수치)
- 백월: 1940×2480 / 1950×2480 / 2930×2480 / 2940×2480 / 3930×2480. 목공 무대 백월 2200×4200 / 2640×4200 / 1940×3980.
- 날개: **450**(기본) / 700(목공) / 950. 높이 2480 / 3230 / 4200 / 4960(둥글게 양면).
- 등록데스크: 상단 간판 **×500**(또는 ×430), 하단 **×1000**(또는 ×930·×950). 폭 1940 / 2930 / 3920 / 3930.
- 게이트 간판 1940×750 / 2930×680·750 / 3920×680·750. 콘솔가림막 2930×1000 + 950×1000. 타이틀 입간판 950×2480.
- **둥글게 양면** = 한 장에 두 면. 위쪽 절반을 180° 뒤집어 놓는다(기둥 위로 넘겨 양면이 바로 읽히게). 시트에서 위 절반이 거꾸로 보이는 게 정상.

## 3. 판 종류별 디자인 — 이 꼴 그대로
### 무대 백월(좌·우 한 쌍, 가운데 LED)
- 두 판 **같은 배경**. **좌 = 연도+행사명(타이틀)**, **우 = 슬로건/부제**(국방·GO15·보건의날·PEMNA·핵테온 전부). 슬로건은 다른 색(분홍·그라데이션).
- 글은 **위 1/3**, 그래픽(도시·파도·격자 바닥·지구본)은 **아래 1/3**, 가운데는 비워 둔다(LED 옆이라 비는 게 정상).
- 로고: 폭 ≤2000 판은 **위 좌·우 모서리에 한 줄씩**(주최 왼쪽·주관 오른쪽), 넓은 판은 타이틀 밑 한 줄.
- 작년 KOBC(2025) 옥타백월 1940×2480: BMFW 로고 + 'Busan Maritime Finance Week' + 로고 4개 한 줄 → 아래 절반 다리·도시·차트 그래픽.

### 날개
- **450 날개 = 배경 그라데이션 + 행사명 세로(90° 회전, 위→아래)**, 흐리게(25~40%) 또는 작게 또렷이. 글자 하나만, 장식 없음.
- **950·700 날개 = 가로로 둔 로고/행사명을 가운데~위 1/3에, 흐리게(2025 KOBC LED날개: BMFW 로고 30%)** 또는 3줄 쌓은 행사명(국토교통). 세로 회전은 450에서만.
- 그냥 **단색 그라데이션만**인 날개도 많다(국방 무대날개·PEMNA·핵테온 무대윙). 글자 넣기 애매하면 비운다.

### 등록데스크
- **상단 간판(×500)**: 남색 띠 + 흰 굵은 글자. 구역을 `|`로 나눈다(사전등록 | 현장등록, 등록 | 안내, 관계자 및 참가사 | 안내). 영문 소제목 작게 밑에(Pre-registration). 2025 KOBC는 **영문만**('Registration', 'VIP · Panelist · Speaker').
- **하단(×1000)**: 메인 배경 + 가운데 행사 타이틀 + 그 밑 주최 로고 작게. 2025 KOBC는 **로고판 / 슬로건판을 번갈아 반복**(2930은 3칸, 3920은 4칸).
- 뒤 백월(×2480)이 있으면 키비주얼 그대로(국토교통은 글자 없이 그래픽만, GO15는 'Registration Desk' 크게).
- 날개 450×4960 둥글게 양면.

### 포토존(3930·2930×2480)
- 키비주얼 그대로. 타이틀 위 가운데(또는 왼쪽 위 크게 — 2025 KOBC), 날짜·장소 한 줄, 로고는 모서리 또는 타이틀 밑. 그래픽 아래 절반. 사람 서는 높이(1,700 아래)에 글자 없음.
- 날개 450×2480 세로 글자.

### 게이트·구역 간판(×680~750)
- 남색 띠 위에 행사명 작게 한 줄 → **흰 둥근 틀(또는 모서리 깎은 틀) 안에 구역명 크게**(환담장·메인무대·기업전시·Networking Lounge·서브 세미나실). 틀 색은 흰 바탕+남색 글자 또는 남색 바탕+흰 글자.

### 콘솔가림막
- **검정 바탕 + 은은한 패턴** + 왼쪽 위 MEC&WIP 로고(또는 오른쪽 위 행사명 작게). 2930×1000 + 950×1000. 키비주얼 쓰지 않는다.

### 타이틀 입간판(950×2480)
- 키비주얼 세로 크롭 + 가운데 높이에 타이틀 또는 슬로건(두 버전 번갈아). 밝은 판·어두운 판 교대도 씀(국토교통 상담관 1~10).

### 카페테리아·라운지 같은 부속 공간
- 행사 키비주얼을 쓰지 않고 **그 공간 콘셉트 색**(카페 = 갈색 줄무늬·컵 아이콘, 노랑 브랜드 등)으로 따로. 행사명은 날개에만 흐리게.

### 스카시·켈지(2025 KOBC)
- 백색고무스카시 20T 평판인쇄 + 투명아크릴 1650×700×5T + 포맥스 1650×300×300T + 켈지 1650×300(또는 500). 정면·측면 두 그림 + 빨간 지시선.

## 4. 공통 디자인 원칙(45장에서 한 번도 어긋나지 않은 것)
1. **키비주얼을 자르고 옮길 뿐 다시 그리지 않는다.** 배경 그라데이션·그래픽·타이틀 조각을 그대로 쓴다.
2. **타이틀 블록은 위 1/3, 그래픽은 아래 1/3, 가운데 여백.** 판을 글자로 채우지 않는다.
3. **로고는 작게**: 모서리 한 줄 또는 타이틀 밑 한 줄, 판 폭의 10~15%.
4. **한 판에 글자 덩어리 하나**(타이틀 또는 슬로건 또는 구역명). 둘을 넣으면 좌·우 판으로 나눈다.
5. 글꼴은 키비주얼 글꼴 + G마켓 산스/Pretendard 굵게. 흰 글자 기본, 강조만 하늘색·분홍.
6. 날개는 글자 하나(세로) 아니면 빈 그라데이션.
7. 구역 안내는 띠+흰 글자 또는 틀 안 글자. 흩뿌린 작은 글자·물결선 장식 없음.
8. 사진(도시 야경 등)은 아래 절반에 깔고 위로 갈수록 배경색으로 녹인다.

## 5. 이번(2026 KOBC) 작업에서 이 정본과 달랐던 점 → 다음부터
- 950 날개에 세로 글자 → **가로 로고 흐리게**가 사내 꼴(450만 세로).
- 등록 하단을 한 장 포스터처럼 → 2025는 **로고판/슬로건판 반복**. 같은 행사는 작년 꼴을 먼저 따른다.
- 콘솔가림막은 **검정+패턴+MEC&WIP 로고**, 키비주얼 금지.
- 좌·우 무대 백월은 **타이틀 / 슬로건으로 역할을 나눈다**(같은 걸 두 번 넣지 않는다).

## 6. 사용자 v2(2026-11-04 KOBC 등록)가 내 B안보다 나은 이유 — 보여 주기 전 '빼기 점검'
비교 그림: `examples/kobc_reg_myB_vs_user_v2.jpg`(위 = 내 B안, 아래 = 사용자 v2). 사용자 평 "내가 고친 게 훨씬 깔끔하고 멋진데 왜 학습이 안 되냐". 나는 규칙(위치·치수)만 배우고 **더하는 쪽**으로 갔고, 사용자는 **빼는 쪽**으로 갔다.
1. **배경은 판 전체 한 장의 그라데이션**(남색 위 → 밝은 하늘 아래). 단색 머리띠 상자·하단 하늘색 띠 같은 **면 덩어리를 깔지 않는다**. 구역 구분은 가는 세로선 + 끝이 사라지는 가는 가로 헤어라인이면 충분.
2. **판마다 역할 하나**: 백월 = 안내(구역 3개 + 슬로건 한 줄), 앞판 = 행사 정체성(BMFW 로고), 날개 = 행사명 세로, 옆가림막 = 그래픽만. **같은 타이틀을 여러 판에 반복하지 않는다**(B안은 BMFW를 백월·앞판·옆판·날개 4번 넣었다).
3. **슬로건은 한 줄, 가운데, 안내 바로 밑 부제 크기.** 두 줄로 크게 키워 타이틀과 겨루게 하지 않는다.
4. **그래픽은 물체가 아니라 바탕결**: 지구본 원판(딱딱한 원 테두리)·차트를 따로 세우지 말고, 세계지도 평면 + 항로선 + 도시·크레인·배를 **50% 투명도**로 아래 절반에 판 끝까지 길게 깐다(수평선 구도).
5. **넓은 판(7200×1250)은 가로 로고 조합**: BMFW 워드마크 + 'BUSAN MARITIME / FINANCE WEEK' 두 줄을 옆에 붙이고 로고 줄은 그 밑 가운데. 위·아래로 쌓은 조합은 세로가 넉넉한 판에서만.
6. **작은 판(옆가림막 1200×1250)은 글자 없이** 그래픽 흐림만 — 굳이 로고·REGISTRATION을 넣지 않는다.
7. **날개 = BMFW 워드마크 → 영문 풀네임 두 줄을 길이 방향으로 이어 세로, 50%, 판 한가운데**, 배경은 백월과 같은 그라데이션(머리띠 상자 없음).
8. 점검 질문(보여 주기 전 판마다): 이 면 덩어리·글자·그래픽을 **지우면 더 나빠지나?** 안 나빠지면 지운다. 다른 판에 이미 있는 글자면 지운다.
