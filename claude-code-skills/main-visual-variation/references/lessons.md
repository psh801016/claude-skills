## 2026-10-22·23 — 충남 2026 청년정책 대토론회 (첫 실전)
- 10-22 일러 강제 종료로 저장 안 한 문서가 날아감 → run.ps1 ABORT 가드. 사용자가 드래그·대화상자 중이면 COM 읽기가 2분 넘게 멈춤(10-23 실측).
- 10-23 ASURA님 지시(절대 규칙의 출처): "그거 우리가 하는거 아니라고"(두 번) → 우리 몫은 `01 3D` 만 / "베리에이션에선 날짜 빼라" / "불칼질 날개는 같은거 아녀?" → 같은 판 합쳐 수량 / "모서리만 ㄱ ㄴ 이런식으로" → 여유 표시 / "포토존이랑 무대 백월만 그렇다고" → 글자 1,800 위 규칙은 그 둘만 / "map 폴더에 png로 각 해당 이름으로 뽑아 놔야" / "너무 아래로 쏠렸어"(입구백월 사진 판) / "지금은 그냥 led가 하나에 판같잖아"(LED 연사 판).
- 불칼질 여유: 20mm·100 으로 만들었다가 둘 다 반려, 요청서 "상하좌우 20" = 200mm 가 정답.
- 발주 시트 라벨 타이포 정본(`wiki/reference/order-sheet-typography.md`) 참조만 — 기존 라벨은 "지금이 맞다, 상황마다 사이즈 변동".

## 2026-10-26 — INWEPF 2026 (부스 간판·켈지·날개·데스크 앞판·LED)
- 부스 간판을 둥근 판으로 만들어 "왜 둥글어 저거 아니잖아" → 부산 2026 `메인무대게이트.ai` 실측(모서리 45° 따기·위 가운데 홈·청록 테두리·꺾쇠). 규칙 "참고 이미지를 받으면 그 원본 파일부터 찾아 연다".
- 켈지를 간판 모양으로 바꿨다가 "켈지는 원래께 맞어" → 이미 맞다고 한 부분은 같이 바꾸지 않는다. 한 줄 33mm 는 작다고 반려.
- 모음 발주 시트를 만들었다가 "이건 필요 없고" → "확정" 다음은 3D 맵 PNG 만, 시트는 지시가 있을 때만. "발주용으로 네임 사이즈 해서 만들어서 검토 받아" → `_발주.ai`.
- "맥스 맵으로 사용할꺼니깐 스크린인가 그걸로 각각 뽑아서" → 맵 PNG 기본 = Export for Screens(`map_screens.jsx`).
- 데스크 앞판 950×950 으로 받았다가 "높이가 750". 부스 날개 45% 는 흐리다고 반려 → 85·80%. "남색으로 맞춰" → 함정 11(RGB 소스 남색 보정).
- Python 경로 `\02 소스` 의 `\02` 가 제어문자로 바뀌어 파일을 못 열었다(두 번) → 함정 10. PowerShell 한글 경로 함정 9.
- 부스명 확정 → 이름마다 파일 하나, 켈지 4→3(함정 8).

## 2026-10-27 — 환황해 포럼 2026 (메인 교체 `swap_visual.jsx` 첫 실전, 5차 반려)
- 1차: 소용돌이 묶음 경계가 판 밖까지 퍼져 그 높이에 맞추니 원이 판 밖으로 커짐 / 한 줄 슬로건 자리에 두 줄을 넣어 제목과 겹침 / map 만 고치고 발주\원본 을 빠뜨려 "예전 그대로".
- 2차 "열어보니 그대로": 작은 제목(현수막·데스크·포토존 가로형)도 잡아야 / 원 불투명도는 예전 10~30% 가 아니라 메인처럼 100 / 새 원에 가운데 지도 조각 포함(빠지면 원 안이 빔) / 대지마다 발주 사이즈 라벨 / 이미 새 원이 든 파일은 labelOnly.
- 3차 "포토존은 옥타 4m 두개", "현수막 상하단 바미싱 … 좌측 상단", "글씨 안짤리게 … 멋지게": `photozone8m.split:2`, 라벨 4줄 왼쪽 위, `polish()` + `references/design-quality.md` 신설.
- 4차 "클리핑 마스크를 하던가", "디자인 이게 최선이냐", "여기 위에 포토존 여기다가 정리해": 바탕 밖 원은 클립, 포토존 `inPlace:true`, 큰 원을 이음매 가운데 90% 높이, 제목 왼판 위·슬로건 오른판 위(머리선 1.8m 위).
- 5차 "메인비주얼 배경이 흰색 아니야? 통일성 … 지도가 너무 강해 텍스트가 묻혀": `whiteBg`, `softenBehindText` 50%(35% 는 너무 흐림, ASURA님 등록데스크 50% 와 통일), ASURA님 파일도 같은 규칙, 모음 대지는 `isSheet` 로 가림.
- ExtendScript 전역 변수 `name` 을 쓰면 파일 경로가 깨져 열지 못했다.
- 래스터효과 72ppi 가 1/10 시트에서 실물 7ppi 로 굳어 LED 원 둘레 글로우가 달라짐(PNG 화소 0.26%) → 300 고정, test_skill.py 검사(함정 12). 하드 부족 → 백업 7일 자동 정리(CleanupBackups).

## 2026-10-29 — 교통문화 이벤트.ai 캘리그라피 "하단줄 맞춰서 · 물결 지우고 · 그림자 제거"
- 일러에 이벤트.ai 가 열린 상태로 요청 → 창 제목(Get-Process MainWindowTitle)으로만 확인하고 닫아 달라고 요청. COM 은 안 건드림.
- 구조: 캘리 묶음 = [글자+흰 외곽 묶음, 물결 래스터]. 그림자·흰 외곽은 묶음/조각 효과라 스크립트로 못 끔 → 새 묶음으로 옮기고 옛 묶음 삭제, 흰 외곽은 글자 사본 + 흰 선 44pt 로 재생성(옛 흰 조각엔 번짐 효과가 있어 흐릿).
- "하단줄" 해석: 처음엔 남색 바에 맞춤으로 봤으나 사용자 "켈리그라피 텍스트가 일열로 써지게 지금 상단으로 붙어있잖아" → 글자 밑선 맞춤. 1차로 '캘' ㄹ 꼬리 끝(-301)에 리그라피 바닥을 맞췄다가 "텍스트 이상함, 잘 어울어지게 글씨좀 맞춰" → ㄹ 몸통 밑선(-268)에 리그라피를 같은 양(25pt) 함께 내림.
- map 이벤트_01.jpg 같이 갱신. `map_jpg.py` 에 bash 경로(/x/…)를 넘겨 기존 폴더를 못 찾고 조용히 1px 큰 그대로 저장 → 기존 폴더 없으면 MAP_JPG_FAIL 로 고침.
- 3차 "글씨 크기를 좀더 맞춰봐 아직 우측 하단이 비어 보여" → 리그라피만 128% 키움(왼쪽 위 기준, 아래·오른쪽을 채움). 흰 외곽까지 바 폭에 넣으면 글씨가 원본보다 작아져서, 남색 글자 폭 = 바 폭·외곽은 원본처럼 바 밖으로 넘치게.
- "하단에 이것도 추가해서 텍스트"(참고 캡처) → 바 안에 '이름을 알려주시면 캘리그라피로 예쁘게 작성해드립니다!' — 흰색 G마켓 산스 Bold(문서 라벨과 같은 계열), '캘리그라피'만 노랑(0,15,90,0), 바 폭 86%·높이 50% 안에 맞춤.
