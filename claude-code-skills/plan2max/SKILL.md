## ★ 절대 규칙 — 사용자 Max 보호
- **3dsmax.exe 가 떠 있으면 그 Max 는 ASURA님 작업창이다.** 장면을 바꾸는 호출(렌더·파일 열기·리셋·저장)을 절대 보내지 않는다. 읽기 조회도 꼭 필요할 때만. `max_inspect.py` 는 Max 가 떠 있으면 스스로 멈춘다(`ensure_max` 가드, 풀지 말 것). 검수는 **Max 를 모두 닫은 뒤** 3dsmaxbatch 로만.
- **"고도화해라·학습해라·직접 고치지 마라·내가 작업 중이다"** 가 들리면 그 작업은 **코드·스킬·문서만** 고친다. 납품 .max·소스 폴더 파일·떠 있는 Max·검수 렌더 어느 것도 건드리지 않는다. 시험은 `dev\plan2max\_out_*` 복사본으로만, 시험용 Max 빌드(3dsmaxbatch)도 사용자 Max 가 떠 있으면 미룬다(같은 PC 에서 Max 두 개는 느려지고 플러그인 충돌 가능).
- 보고 첫 줄은 "무엇을 건드렸는지/안 건드렸는지"(파일 수정 시각으로 증명).

산출물은 모두 3ds Max `.max` 기본. 근거 없는 형상은 지어내지 않고 보고한다.

## 기본 산출물 = 3ds Max
- **`.max` 가 납품물.** 보고·전달은 `.max` + Max 로그(objects·layers·with_material·size). Blender 는 FBX 중간 변환·검토 렌더용(`.blend` 는 따로 안 내도 됨, 사용자가 블렌더를 말하면 같이).
- Max 빌드 실패를 성공처럼 넘기지 않는다(`*_maxlog.json` 없음 = 실패).
- **재질 VRayMtl · 렌더러 V-Ray CPU 저장.** `plan2max\build_max.py`·`site-massing\build_max.py`·`mynerd-distill\build_model.py` 세 빌더가 자동으로 하며 로그 `"mat": "vray"` 로 확인. V-Ray 가 없으면 Physical 로 두고 `"mat": "physical"` 을 보고에 적는다.
- solids.json 덩어리에 선택 항목 `layer`·`rgb`(0~255)·`emit`(LED·라인조명 발광) — 행사 조성물(무대·LED·백월·데스크)을 도면 벽과 섞어 세울 때. 예: `G:\내 드라이브\AI-작업기록\claude\2026-10-15_교통문화발전대회_3D\gen_solids.py`.
- **납품 `.max` 는 사용자가 준 작업 소스 폴더(도면이 있던 폴더, 예: `X:\[행사명]\실행\10 3D`)에.** 수정도 그 파일에 덮어쓰고, 폴더의 남의 파일은 건드리지 않는다. `.blend · render_iso.png · overlay.png · solids.json`·생성 스크립트는 `G:\내 드라이브\AI-작업기록\claude\<YYYY-MM-DD>_<주제>\`.

## 실행 순서 (묻지 말고 끝까지)
0. **자료 전수 확인 — 건너뛰면 안 된다** (rules.md '자료 전수 확인')
   - 폴더의 **모든 파일**을 연다: PPT·PDF 전 페이지(치수·높이·무대·스크린·배치), 사진, 도면.
   - 원본 도면을 **모든 레이어 그대로 흰 바탕에 구역별 확대**(한 장 20m 안팎)로 렌더해 직접 읽는다. 엔진 overlay·벽 레이어 추출만 보고 판단하지 않는다.
   - 응답에 **요소 체크리스트**: 벽·기둥·문(양개·여닫이·셔터)·문 위 벽·창·커튼월·무대(돌출 포함)·무빙월·계단·승강기·가구(테이블·의자 수)·실명·천장고(실명표 CH)·바닥레벨(FL)·특기 문구.
   - 완성 후 항목마다 도면과 겹친 대조 이미지로 '들어감/못 넣음+사유'. 대조 안 한 항목이 있으면 완료가 아니다.
1. **판독** — 출력 폴더 `C:\Users\PSH\dev\plan2max\_out_<도면이름>`
   ```
   python C:\Users\PSH\dev\plan2max\plan_model.py "<도면.dwg|dxf>" -o <출력> [--sheet N] [--h 2.6 --sill 0.9 --head 2.1]
   ```
   DWG 는 accoreconsole 로 자동 변환. 장표가 여럿이면 목록이 찍힌다 — 기본 마지막 장, 사용자가 말한 장은 `--sheet`. 층고·창대·창 위를 말하면 `--h --sill --head`(m).
2. **눈으로 확인** — `<출력>\overlay.png` 를 Read 로 본다(빨강 벽·파랑 창·초록 문 위 벽). 콘솔 `[확인]` 줄과 `solids.json` 의 `meta.door_skipped` 도.
3. **3ds Max** — `python C:\Users\PSH\dev\plan2max\build_max.py <출력>\solids.json` → `solids.max` (`_log.json` 의 ok). build_max 가 먼저 **wallnet 정리**를 거친다. `WALLNET_FAIL` 이면 Max 를 부르지 않고 멈춘다 — 고치고 다시. `--raw` 는 디버그 전용.
4. **Blender** — `"C:\Program Files\Blender Foundation\Blender 5.1\blender.exe" --background --python C:\Users\PSH\dev\plan2max\build_blender.py -- <출력>\solids.json` → `plan_model.blend`, `render_iso.png`. 렌더를 Read 로 보고 말한다.
5. **근접 검수** — 아래 'Max 안 접합부 근접 검수'. 시트를 보고 틈·엇갈림·곡선이 있으면 고친 뒤 다시.
6. **저장·보고** — 소스 폴더에 `.max`, 작업기록에 나머지. 보고: 창·문 개수, 외곽 크기(m), 못 만든 문과 까닭, **가정한 높이**.

"맥스만" / "블렌더만" 이면 그 단계만. 코드를 고쳤으면 `python C:\Users\PSH\dev\plan2max\test_plan.py` PASS.

## 벽 정리 wallnet — Max 로 보내기 전 모든 경로 공통
- 요구 수준 = **벽·기둥·창(틀+유리)·무대 외곽까지 깨끗하게 모델링된 상태**. 행사 부속(부스·LED 등)은 사용자 몫.
- 도구: `python C:\Users\PSH\dev\plan2max\wallnet.py <solids.json> [out.json]` (검사만 `--check`). build_max CLI 가 자동으로 부른다. DXF·이미지·손 배치 어느 경로의 solids.json 이든 지난다.
- 규칙(순서): ① layer 에 SHAFT·CORE 가 든 s_wall 꽉 찬 상자 → 두께 0.2 테두리 벽(구조 모델 s_wall 은 제외) ② 면 맞춤 — 축 변마다 **8cm 안 + 옆 0.3m 안에 실제로 맞닿은** 벽·기둥 면 중 긴 면으로(도면 전체 좌표 묶기 금지) ③ 바닥부터 선 벽을 높이별 한 덩어리로 합침(1mm 격자), 0.6m 미만 틈 메움(문·창·문 위 벽 자리는 안 메움), 문 위 벽 자리는 그 높이를 넘는 바닥 벽에서 뺌, 높은 벽 자리는 낮은 벽에서 뺌, 덩어리 안 8cm 미만 계단 제거 ④ 틀 없는 유리(사선 포함) → 창틀(문설주·멀리언 50, 1.5m 이하 칸, 아래·위틀 50, 깊이 = 그 자리 벽 두께) + 5mm 유리.
- 검사 실패 조건: 같은 높이 겹친 벽 / 꽉 찬 샤프트 / 틀 없는 유리 / 벽에 묻힌 문·유리. 8cm 미만 꺾임·0.6m 틈은 참고 수치(문·창 바로 옆은 일부러 안 건드림 — 남은 자리는 max_inspect 로).
- 참고 수치 "문틀 옆 코너 여유 10cm 미만": 문 끝 0.1m 안에 벽 두께 밖으로 뻗는 직교 벽·기둥이 있으면 문이 모서리에 박힌 것. 실패 조건은 아니고 0 이 아니면 자리와 함께 보고. 새 문을 배치할 때는 **문틀 옆에 100~150mm 벽을 남긴다**.
- 회귀: `python C:\Users\PSH\dev\plan2max\test_wallnet.py` → `TEST_WALLNET_OK` (`tests\inwepf_2f_solids.json`).

## Max 안에서 접합부 근접 검수 — 납품 전 필수
- 원칙: 기하 생성은 코드(DXF→shapely), 검증은 사용자가 쓰는 **3ds Max 안에서** "쓰고 → 렌더 보고 → 비교 → 고치기".
- 도구: `python C:\Users\PSH\dev\plan2max\max_inspect.py <solids.json> <모델.max> [출력폴더] [--n 24]` → `inspect/inspect_sheet.png`. 결함 자리(창틀 끝-벽 틈 큰 순·창 L자 모서리·문·바닥 외곽 이상 꼭짓점)를 골라 Max(**3dsmaxbatch 메시지펌프 루프만, 창 없음 — 사용자 Max 가 떠 있으면 실행 거부**)에서 V-Ray(돔 x6·GI 끔·프로그레시브 5초 캡) 근접 렌더를 한 장으로 묶는다. 씬 저장 안 함. 12장 ≈ 5~6분.

## 이미지 평면도 경로 — 밑그림 깔고 따라 그리고 겹쳐 본다
- 좌표를 눈대중으로 추정해 상자를 놓지 않는다(INWEPF 실패 원인).
- 필수 순서: ① 평면 이미지를 **아는 치수 두 개**(외곽 가로·세로)로 축척 잡아 m 좌표계에 깐다 ② 벽·창·문 좌표는 이미지 픽셀에서 **선을 따라 읽는다**(가능하면 `drawing-to-3d-walls` 경로 E 의 plan.json, 치수 표기가 있으면 그 값 우선) ③ solids 를 이미지 위에 겹친 `overlay.png` 를 Read 로 보고 어긋난 벽·빠진 창을 고친 뒤 다시 겹친다 ④ wallnet → build_max.
- 가구 평면·배치도가 있으면 테이블·의자·옷장은 **자리표시 상자**로 먼저(공간감 검증용). 천장 단차·커튼 박스·욕실 벽 두께 같은 세부는 AI 가 단순화하는 곳 — 체크리스트에 따로 적어 대조.
- 완공 사진은 재질·문틀 간섭 검수에만. 형상은 도면이 정본.

코드 정본: `C:\Users\PSH\dev\plan2max\_out_grandballroom\gb_model.py` (+ `test_gb.py` 회귀, `gb_cam.py` Max 아이소 카메라·재검증)

**범위**
- 날개 전체: 볼룸만 자르면 외벽이 중간에서 끊긴다. 도면 외곽(남측 후방·동측 유리 연결통로)까지, 다른 동(타워)·건물 밖 캐노피만 뺀다. 잘라낸 경계는 보고에.
- 도면 외곽 안 같은 층 블록을 '다른 동'으로 단정해 빼지 않는다. 레이어 체계가 달라도(다른 설계사) 실명표·커튼월이 이어지면 같은 층 — 레이어 목록·글자(실명표 CH)부터 읽고 매핑 추가.

**벽**
- 구조(WALL-1·WALL-2·FIN·CON): 평행 두 줄 60~700(상한 705 — 정확히 700 이 부동소수 오차로 짝 못 짓는다). 마감·칸막이(I-FIN, 600 이상 선): 60~500, 겹침 500 이상(선반 랙 600·계단 1.2m 제외).
- 정리(지글거림 금지): 띠 → 축 맞춘 직사각형 → 같은 벽(두께 방향 절반 이상 겹침)끼리 묶고 두께는 길이 40% 넘는 띠로만 → 2m 넘는 벽에 붙은 600 미만 돌기·열린 문짝 판(80 미만)·기둥 상자 안 조각 제거 → 면 좌표 40mm 정렬 → 직교 벽 150 이내 삐침 자르기 → 1mm 격자 합치기 + 200 closing.
- 한 줄 벽(한쪽 면만 그린 구조선 0.5m+, 또는 벽에 붙은 0.12m+ 귀퉁이): 짝 없으면 가까운 벽 쪽으로 150 두께.
- 두꺼운 짧은 벽: 같은 줄 묶음에서 길고 얇은 마감 띠가 두께를 정하면 짧고 두꺼운 코어 벽이 사라진다 → 정리 결과에 절반 넘게 빠진 축 띠(150+, 1m+)는 되살림(동쪽 블록만 적용).
- 사선 벽·사선 커튼월: regularize 는 축 벽만 → 사선 띠는 회전 직사각형으로 따로 합치고, 사선 커튼월은 회전해 축 맞춘 뒤 같은 창 만들기 후 되돌림. 테스트는 도면 사선 벽선 위 사선 모서리만 허용.
- 마지막 축 정리: 1~3cm 기운 모서리는 축에 맞추고, 2cm 안 어긋난 면은 **모든 벽·상부벽·유리·문짝 공통 표 하나**로 긴 면 값에 합친다(벽마다 따로 하면 상부벽과 옆 벽이 6mm 어긋남). 반올림으로 꼬인 폴리곤은 buffer(0). 유리는 전역 좌표 맞춤에서 제외.

**기둥**
- COL·COL-S 선은 벽 짝에서 뺀다(기둥 변이 벽으로 잡혀 '+' 모양). 기둥은 기호 외곽 상자, 겹친 기호는 합친 외곽 하나. 기둥 선은 1mm 반올림 후 면 만들기(모서리 어긋나면 기둥 통째 누락).

**문**
- 문 위 벽(상부벽) = opening(): 양개문 = 경첩~경첩, 외짝 = 경첩~닫힌 문짝 끝(문짝 가운데 빈 공간 + 경첩 뒤 문설주 벽인 쪽, 호 끝각 10° 안 축 맞춤). 문 가운데에서 양쪽 벽 면까지 재고, 같은 줄 벽 단면을 직각 벽 900 안까지 넘어가 찾는다. 도면 문 폭은 항상 열림. 모든 벽 출력 **뒤에** 실제 출력된 벽 기준으로 한 번 더 붙이고(300 안 늘려 닿게), 아무것도 안 닿는 끝엔 100mm 문틀 기둥. 문 줄 ±350 안 벽 전체 두께를 비우고 그 위에 세움. 문짝 끝 너머 450 안 벽까지 문설주로 채움.
- 문 = 문틀 + 문짝: 문설주 틀 50 양옆 + 상부틀 50, 깊이 = 벽 두께(300 넘으면 200), 문짝 40 은 틀 안 3mm 띄움·문 높이 2.7m·문 줄 가운데. 겹쳐 그린 같은 문 호는 하나로. Max 레이어 A-DOORFRAME.
- 화장실: 벽체만(칸막이·칸 문짝 안 넣음, SHOW_TOILET=False). 칸막이(25~59mm 띠, 위생기구 1.2m 안)는 벽 후보에서 먼저 뺀다.
- 전실(프리펑션→양개문→볼룸): 양 끝 문 없는 두 줄 상부선 = 열림 + 상부벽(문 높이~천장). 판정은 DWG 표기 + 고객 PPT 평면 개구부 두 출처.
- 문 전수 검사 `door_audit.py`: 문마다 '문 위 벽 있음' 또는 도면 근거(f-s 셔터 선 위·화장실 칸·커튼월 줄 함체 문)가 있어야 PASS. 함체(0.4×1.17m 두 줄 선 상자)는 모델에 넣는다.

**창·유리**
- 유리는 두 줄 6~14mm 간격(WIN·WID·GLAZ·ETC) → 짝 간격 하한 4mm. 창 띠 두 줄 간격을 통째로 유리로 세우지 않는다(153mm 유리가 됐음).
- 창 = 창틀 + 유리: 창 띠(창틀 깊이) 안에 세로 멀리언 50(도면 멀리언 표시 WID1·CURTAINWALL-MULL·난간 기둥 = 띠를 가로지르는 짧은 선 위치), 아래틀·위틀 100, 그 사이 유리 **5mm**(난간 12mm, 손스침 50). 도면 표시 없이 1.8m 넘는 칸만 1.5m 이하로 나눔(가정, 개수 보고). 루버(LOUVER-GRILL)는 유리 대신 루버 칸. Max 레이어 A-WINFRAME.
- 같은 줄 창은 한 띠로: 두께 방향 절반 이상 겹치고 틈 250 이하·틈에 벽 없으면 합쳐 틀 깊이 통일(도면 멀리언 상자 70mm 자리마다 끊기지 않게). 긴 줄에 붙은 1m 이하 두꺼운 토막은 긴 줄 깊이로 흡수, 띠 밖은 벽 이음 마감. 창 줄 끝 250 안에 벽이 있으면 창틀을 벽 면까지, L자로 만나는 가로·세로 창 줄은 서로 상대 띠 바깥 면까지, 창 줄 끝 600 안 벽까지 창틀을 늘려 모델 자체를 닫는다. 자름 위치 30mm 안은 하나로.
- 커튼월 줄(CURTAINWALL-TRANSOM·WIN 60 안) 위 FIN-3·FIN-4 0.3m+ 선 = 고정 유리 → 벽 아님. 에스컬레이터 개구부(OPEN X 50㎡+) 둘레 WIN 은 유리 난간 1.1m, 바닥판에서 개구부 뺌. 난간은 개구부 600 안 + 도면 난간선(I-HANDRAIL·난간)이 있을 때만.
- 작은 부재는 정리 필터를 거치지 않게: clean() 의 0.01㎡ 필터가 문틀 50×150·난간 기둥 50×100 을 지운다 → 틀·유리·문짝 사각형은 그대로 출력. 3D 근접 렌더로 틀이 실제 보이는지 확인.

**바닥**
- 바닥 = 외곽선 안쪽 전체 − 개구부. 벽·틀·유리·문 발자국을 0.6m 둥근 닫기는 **틈 찾기에만** 쓰고, 틈마다 닿는 면 두 개씩 '막이'를 넣는다 — 마주 보는 면은 겹치는 범위 직사각형, 꺾이는 모서리는 둘을 감싸는 직사각형, 사선 부재가 끼면 볼록 껍질. 밖 = 범위 테두리에서 외곽선·막이를 안 넘고 이어진 곳. 30mm 각진 닫기로 머리카락 틈만 먼저 막는다. 닫기 결과를 바닥 경계로 쓰지 않는다(둥근 곡선이 남음) — `test_gb` 가 바닥 곡선 0 검사. 각진(mitre) 닫기 금지(사선에서 경계가 엉뚱해지고 재료를 더해도 결과가 줄어듦).
- 'OPEN' 글자 자리처럼 X표 없이 개구부와 이어진 빈 공간은 도면 선으로 경계를 잡아 개구부에 넣는다. test_gb 에 실내·밖·개구부 확인 지점을 둔다.

**도면 표기 확인**
- '상부 외벽선'(위층 투영) = 벽 아님, f-s = 방화셔터(쪽문은 문 위 벽 불필요), 점선 사각형 = 상부 표시, 가구선 무대(I-FL-FUR(M))는 돌출 포함 전체 크기.
- 최종 품질 `wall_quality.py`: 모델 벽면 90%+ 가 도면 선 위, 벽 밖 미일치는 토막마다 문틀선·모델 경계 끝·벽 끝 마구리로 분류돼 설명 안 되는 것 0. 사선 도면선(계단 절단선·계단참 모서리)은 벽 아님으로 분류하되 목록 출력. 미일치 위치는 원본 겹침 시트로 하나씩.

**실패한 방식 — 다시 하지 말 것**: 선종류 점선(HID)으로 벽 거르기(I-FIN 은 거의 전부 HID 라 커튼월·실벽까지 지워짐) / 모든 선 짝을 띠로 합치기(지글·덩어리) / 10mm 닿기로 벽 엮기(옆 벽까지 사슬) / 같은 줄 두께 중앙값 통일(150 벽 → 690) / 면 정렬 80mm(기둥 옆 벽 두꺼워짐) / 엔진 door_lintel + 틈 메우기 혼용(세로·비스듬 인방) / closing·다리 놓기로 상부벽 만들기 / 사각형 맞닿음으로 단면 재기.

### 일하는 원칙
1. **엔진은 덧붙여 고친다** — 원작 규칙은 두고 표식 `MN_<모듈>_<이름>_V1` 주석 + 고치기 전 사본 `raw\*_before_*.py` + 회귀 테스트(`test_01geonchuk.py` 에 사고 배경 주석). 원작 판정 기준(관문 70%, 줄눈 제외)은 바꾸지 않는다.
2. **렌더 눈대중으로 하나씩 찾지 말고 도면과 겹쳐 잰다** — 아래 '검사 도구' 먼저.
3. **입면은 앞에 있는 모든 것을 한 장에 겹쳐 그린다** — 동 입면의 '모델에 없는 선'은 시선 방향 저층부·단지 요소일 수 있다. 동 평면에 없으면 **그 가로 구간을 따라 시선 방향 끝까지** 저층부 평면·배치도를 뒤진다.
4. **근거는 두 출처** — 입면 + 평면(또는 단면·표기). 한 출처뿐이면 세우지 않거나 '추정' 묶음·flag·테스트로 분리하고 보고에 그 면 %가 추정 덕분임을 쓴다.
5. **결과가 갑자기 바뀌면 대조 실험** — `raw\*_before_*.py` 로 엔진 한 판만 되돌려 같은 단계만 다시.
6. **shapely 각진 버퍼(join_style=2)엔 `mitre_limit=1.5`** — 기본 5배라 예각에서 가시·쐐기. 선 묶음 닫기 → 채운 외곽에서 깎기(폭 0 꼬리).
7. 높이·레벨은 **그 건물 자기 표기**로 — 동은 동단면도 '지상N층·EL' 짝(DONGSECT), 저층부는 판매시설·주민공동시설 입면 짝(PODIUM_LV). 남의 높이를 빌리면 1m씩 틀어진다.

- 대지 전체가 데크 높이 → 저층부 지붕 안만 데크, 밖은 지반(GROUND2). 2층 평면 빈 사각형 = 1층 복층 → 데크 = 저층부 모든 층 합집합(PODIUM_V2). 토심 윗면은 지반 아래 20(GROUND2_V2).
- 조경 0㎡ → 조경선 레이어 이름(`_DS-base`, DSLAND). 잔디/포장이 통째로 뒤집힘 → 남은 큰 칸(BIGCELL: 1,000㎡ 넘으면 포장 무늬 선 자리만 포장).
- 도로 밖 쐐기 → RINGCORNER(mitre). 곡선 경계 부채꼴 → 제약 삼각분할 RINGCDT.
- 저층부 밖 바깥 계단·외부 승강기 → EXTSTAIR(저층부 외곽 밖 300 간격 디딤판 8줄+ 묶음, 끝 위치 400 안끼리 묶음; 높이는 2층 장 'DN' 쪽이 2층 EL, 단 수로 나눠 지면까지; 'ELEV' 표기 탑).

**동 몸체**
- 2층 커튼월(상가) → CURTAIN_V2(유리 칸 나눔. 통짜 덩어리는 일치율을 깎아 폐기). 1층도 정확 모드 실패면 커튼월 외곽(G1CURTAIN), 30㎡ 넘는 둘째 덩어리는 떨어진 덩어리로 넘겨 원작 입면 확인(CURTAIN_X).
- 1층 코어 덩어리 가시 → 실 구멍 되돌릴 때 mitre(G1SPIKE). 커튼월 외곽 폭 0 꼬리 → 채운 외곽에서 깎기(CURTAIN_SPUR).
- 기준층 평면 한 장인데 입면 창 난간이 층마다 엇갈림 → 입면 난간 상자 + 같은 층 평면 창(유리 'win_glass', 창살별 조각 합산) 두 근거로 층별 난간(ELEVRAIL).

**지붕**
- 허공 옥탑 → 지붕층 장 옆에 따로 그린 옥탑층 평면: 최상층 위 80%만(ROOFON_V2). 다른 파일 장 맞춤 0.8 미만 안 씀(XFILEALIGN). 코아 장 사본 → 동 지붕층 덩어리 안만·큰 덩어리 안 작은 것 뺌(ROOFDEDUP_V2·V3).
- 둘레 전체 난간 → 지붕층 평면에 난간 선이 있으면 그 자리만 난간, 나머지는 같은 높이 파라펫(PLANRAIL). 외벽 2m 밖 난간 선은 아래층 발코니가 비친 선.

### 실패한 방식 — 다시 하지 말 것
- **벽 이음을 두 개씩 짝지어 고치기**(`wall_joins.py`): 겹침·계단·틈이 계속 남았다. 벽은 한 덩어리로 합치고 개구부를 빼는 wallnet 방식만.
- **면 맞춤을 도면 전체 좌표값으로 묶기**: 멀리 있는 벽 면이 문 옆 벽 끝을 끌어당긴다. 맞닿은 이웃 면끼리만.
- 커튼월 통짜 덩어리(V1) / 커튼월 유리 높이를 입면 창 세로선으로(CURTAIN_H).
- 가시를 '부풀렸다 줄이기'·꼭짓점 지우기·문/창 사선 선 빼기로 깎기(곡면 유리 로비가 통째로 빠짐) → 근본 원인은 mitre.
- 꼬리를 채우기 전 선 묶음에서 깎기(얇은 벽 선이 같이 사라짐).
- 입면 한 장만으로 덩어리·부재 세우기(ELEVONLY) — 관문은 넘어도 근거 없는 형상. 껐고 다시 켜지 않는다.
- 줄눈을 비교에서 빼기(원작 기준 변경), '경사로' 레이어를 차량 출입구로, 1층 벽선·기준층 윤곽 FFT 배치.
