# 건축가처럼 읽고 세우기 — 평면도 → 3D 의 사고 순서

> 사용자(2026-11-10): "건축에서 하는 방식을 이해하라는 거야. 넌 PDF 받으면 엉망으로 대충 그린다. 건축은 그렇게 안 한다."
> 로카우스 5층 반려 수십 번의 공통 원인: **선을 보고 형상을 만들었지, 건물을 이해하고 세우지 않았다.**
> 선 문법·기호·레이어 지식은 `drawing-to-3d-walls/references/건축도면_이해_체계.md` (반드시 같이 읽는다).

## 0. 핵심 차이 — 선 추적 vs 건물 이해
| 내가 하던 것 (반려) | 건축가가 하는 것 |
|---|---|
| 굵은 선 쌍을 찾아 다각형으로 채움 → 벽 | "이 건물의 벽은 어떤 종류가 어디서 어디까지 가나"를 먼저 정함. 벽 = **종류 + 중심선 시작·끝** |
| 벽 끝 사이 틈 = 문 | 문 = **기호(문짝+호)** 하나하나. 문은 벽에 꽂히고 그 자리만 뚫린다. 벽은 문 위로 계속된다 |
| 조각을 합치고 메우고 깎음 → 틈·돌기·사선 | 벽은 처음부터 이어진 한 개체. 만나는 곳은 L/T/+ 접합 규칙으로 정리 |
| 점선 = 그때그때 추측 | 범례·문맥으로 선종류 의미를 **도면 전체에 한 번** 정하고 끝까지 같은 뜻으로 |
| 반복 모듈도 하나씩 따로 판독 | 반복(AD 박스 줄, 화장실 칸)은 하나를 정확히 읽고 **같은 규칙으로 배열**, 양 끝 예외만 따로 |
| 완성 후 사용자가 틀린 곳 지적 | 각 단계 끝에 스스로 대조(개수 N/N, 실 닫힘)하고 못 한 것만 보고 |

## 1. 읽는 순서 (모델 만들기 전, '판독 노트'를 먼저 쓴다)
판독 노트 = 작업 폴더 `reading_notes.md`. 이 노트 없이 형상 생성 금지.

1. **도면 정보**: 축척(1:200 등)·방위·표제란·범례·특기사항. 범례에 선종류(점선·일점쇄선) 뜻이 있으면 그대로 적는다.
2. **통심선(그리드)**: X1…/Y1… 버블과 간격 치수. 기둥은 그리드 교점에, 외벽·코어벽은 그리드에 맞춰 선다. 그리드가 없으면 기둥 중심으로 그리드를 역으로 만든다.
3. **구조**: 기둥(회색 채움·해치) 크기·위치, 코어(계단·승강기·샤프트) 벽 = RC 두꺼운 벽. 구조는 움직이지 않는 뼈대 — 나머지는 여기에 붙는다.
4. **벽 체계**: 두께별 종류를 표로 만든다(예: RC 200·250, 조적 150·200, 경량 칸막이 100, 유리 칸막이). 도면에서 같은 두께 = 같은 종류. 벽마다 `종류, 중심선 시작→끝`.
   - 벽은 실과 실을 나누고 **끝은 반드시 다른 벽·기둥·창에 닿는다**(허공에서 끝나는 벽은 판독 오류).
   - 선종류 해석(점선이 경량벽인지 상부선인지)을 여기서 한 번 확정 → 사용자에게 질문 목록(0-1)으로 확인.
5. **개구부**: 문 = 기호마다 `위치(경첩), 폭, 여닫이 방향, 외짝/양개/미닫이/방화셔터`. 창 = 외벽 속 3~4줄. 커튼월 = 멀리언 간격. 문 위는 벽(인방)이 이어진다.
6. **실(Room)**: 실명 글자마다 그 실을 둘러싸는 벽·문·창이 **닫혀야** 한다(Revit 은 실이 안 닫히면 실 태그가 안 붙는다). 닫히지 않으면 벽이 빠진 것.
7. **수직 요소·높이**: 계단·승강기·샤프트, 천장고·층고(단면·실명표 CH). 없으면 가정값 → 질문 목록.
8. **반복·대칭**: 같은 모듈 줄은 첫 칸을 정확히 → 배열 규칙 → **양 끝 칸 따로 확인**(로카우스: AD 줄 끝 문 누락).

## 2. 세우는 순서 (Revit 순서 그대로)
그리드 → 기둥 → 코어 벽 → 외벽 → 칸막이 벽 → 문·창(벽에 꽂고 그 자리만 뚫음, 문 위 벽 유지) → 커튼월 → 바닥(외곽 − 개구부) → 실 닫힘 검사.
- 벽은 판독 노트의 `종류·중심선`으로 생성(두께는 종류표 값). 도면 선 조각을 그대로 채워 쓰지 않는다.
- 판독 노트에 없는 형상은 만들지 않는다 → 돌기·삐침·사선이 원천적으로 안 생긴다.

## 3. 단계별 자기 대조 (보고 전 전부 통과)
| 단계 | 대조 | 도구 |
|---|---|---|
| 기둥 | 도면 기둥 수 = 모델 기둥 수, 그리드 교점 위 | 개수 비교 |
| 벽 | 모델 벽 면 90%+ 가 도면 굵은 선 위 / 지어낸 윤곽 0 | `radar_diff.py`식 선 대조 |
| 문 | 도면 문 호 N = 모델 문 N | `door_audit.py` → DOOR_AUDIT_OK |
| 실 | 실명마다 닫힌 영역 하나(두 실명이 한 영역 = 벽 빠짐) | `room_check.py` → ROOM_CHECK_OK |
| 형상 | 겹침 0, 사선은 도면 사선만, 0.1㎡ 미만 외톨이 0 | wallnet check |
보고 = **만든 것(종류별 개수) / 대조 N/N / 못 한 것(자리·사유)**.

## 5. 웹 근거 (2026-11-10 조사 — "웹으로 검색해서 학습 제대로 해라")
- **벽은 '접합점 사이 선'이다** — Liu et al., *Raster-to-Vector: Revisiting Floorplan Transformation*, ICCV 2017 (https://art-programmer.github.io/floorplan-transformation/paper.pdf):
  - 벽 접합점 4종 I·L·T·X(방향 포함 13종). 벽 = 두 접합점을 잇는 축 정렬 선, 문·창 = 끝점 두 개짜리 선.
  - 제약: ① 접합점 차수 = 붙은 벽 수(허공에서 끝나는 벽 없음) ② 10px 안 중복 벽 금지 ③ 실(침실·욕실·발코니·외곽)은 닫힌 고리 ④ **문·창은 반드시 벽 위**(평행·10px 안 벽이 있어야 존재).
  - 후처리: 같은 직선 위 접합점 좌표를 평균해 정렬(→ 미세 사선·어긋남 제거), **문을 가장 가까운 벽에 맞춰 이동**, 벽 닫힌 다각형 = 실.
  - → 우리 규칙: 벽을 다각형 조각이 아니라 '중심선+접합점'으로 생각, `door_audit.jambs`(문 양 끝 벽 닿음), `room_check`(닫힌 실).
- **Revit 순서** — 레벨·그리드 먼저 → (CAD 참조) → 기둥을 그리드에 → 벽(종류 선택, 위치선 일관) → 바닥 → 문·창 → 실 → 일람표 (Iowa State *Visual Graphic Communication* Ch.10 https://iastate.pressbooks.pub/visualgraphiccomm/chapter/chapter-10-set-grids-levels-dimensions-building-columns/).
- **Revit 벽 접합** — 벽이 만나면 기본 맞댐(butt) 접합, 평면에서 경계선 자동 정리, 마이터·직각 끝 전환 가능 (Autodesk *About Wall Joins* https://help.autodesk.com/cloudhelp/2016/ENU/Revit-Model/files/GUID-6B18982C-1FBA-4E5C-AE30-6FAE4022CE35.htm).
- **Revit 실** — 실이 경계 요소(벽·커튼월·기둥·실 분리선)로 완전히 닫히지 않으면 'Room is not enclosed' 경고. 아주 작은 틈도 원인 (Autodesk *Room Is Not Enclosed* https://help.autodesk.com/cloudhelp/2025/ENU/RevitLT-Troubleshoot/files/GUID-1AEDF540-7CB3-4CAB-885A-ACDF70154312.htm). 트인 공간은 '실 분리선'으로 구분 → 우리 rooms.json 의 `space`.
- **선종류** — 파선 = 숨은선(상부·보이지 않는 것), 가는 일점쇄선 = 중심선·기준선, 해칭 = 절단면 (KS A 0005 제도통칙 정리 https://itwiki.kr/w/제도_통칙). 평면도 점선 뜻은 자료마다 다름(상부장·보·반벽·철거) → **범례가 정본, 없으면 질문**.

## 6. 웹 근거 2차 (2026-11-10 "웹으로 더 검색해서 도면 이해 보강해")
- **선 굵기 3단계 = 무엇인지의 1차 단서** (Studio Matrx *Architectural Lineweights Explained* https://www.studiomatrx.org/students/drawing-fundamentals/architectural-lineweights-explained , ISO 128 선폭 계열):
  | 단계 | 펜 | 뜻 |
  |---|---|---|
  | 1 절단(Cut) | 0.50~0.70mm | 벽·기둥 등 잘린 것 |
  | 2 보임(Seen) | 0.25~0.35mm | 문짝·문 호·가구·안 잘린 모서리 |
  | 3 참조(Reference) | 0.13~0.18mm | 치수·그리드·해치·숨은선 |
  단계마다 약 2배. 숫자보다 **비율**이 기준. "절단면에 가까울수록 굵다."
  - **판독 노트 첫 줄에 그 도면의 선폭 분포표를 만든다**(굵기×밝기별 총 길이). 로카우스 5층 실측: 0.84·0.54pt = 절단(벽·기둥) / 0.36·0.24pt = 보임(문·유리·돌출창) / 0.12pt = 참조(해치·치수·점선, 전체 선 길이의 대부분). → 0.12 선을 벽으로 채우면 안 되고, 0.54 선이 끊긴 곳은 문·개구부 후보.
  - 점선은 관례상 참조 단계(숨은선·상부)인데 로카우스는 0.12 점선 일부가 실제 벽(인테리어 별도공사 칸막이로 추정 — 사용자 확인: "점선인데 벽"). **관례와 다르게 쓰인 선은 사용자에게 한 번 확인하고 판독 노트에 '이 도면에서 점선 = …' 로 고정.**
- **CAD 벽 추출 실무 레시피** (indoor-mapping *Automating Wall and Door Detection in CAD* https://indoor-mapping-wayfinding.pages.dev/automated-floor-plan-parsing-vectorization/wall-door-detection-algorithms/automating-wall-and-door-detection-in-cad/ , USPTO 11392736):
  벽 레이어만 → 중복선 합침(unary_union·linemerge) → **평행 두 줄 짝(간격 0.05~0.5m, 평행 오차 8° 안, 서로 겹침)** → 두 줄 중점 = 중심선 → 끝점 스냅으로 L·T 접합 닫기 → 중심선 끝 사이 틈 0.5~1.3m 이고 **근처(0.3m)에 문 블록/문 호가 있을 때만 문**(가구 틈을 문으로 승격 금지) → 폭 히스토그램으로 문(0.7~1.3m)/창(2.1~3.5m) 구분 → 연결성 검사(외톨이 노드 0).
  - 우리 반려와 일치: 벽 끝 틈만으로 문을 만들면 가짜 문·누락이 같이 생긴다 → 문은 호·문짝 근거 필수(door_audit).
- **약어는 도면마다 다르다** — AD = Area Drain/Access Door(영미), 한국 도면에선 Air Duct 샤프트로 쓰임. PS·EPS·TPS·ST 도 범례·문맥(X표 = 빈 샤프트)으로 확정 (Archtoolbox https://www.archtoolbox.com/architectural-abbreviations). 약어표 없으면 질문 목록에.
- **엘리베이터 승강로 안 기호**(카·균형추·레일)는 벽이 아니다 — 승강로 벽과 승강장 문만 세운다. 로카우스: 균형추 자리에 세로 벽 조각이 생김(승강로 속이라 안 보이지만 판독 오류).

## 7. 엘리베이터 판독 규칙 (2026-11-10 적용)
- 승강로 = 벽 4면 + **승강장 문 한 면**. 카·균형추(카 옆 세로 상자+레일)·기계 기호(X 상자)는 설비 표시라 벽 아님.
- 승강장 면 = 그 면 바로 앞(2.5m 안)에 로비·전실·홀이 있는 면(판독 노트 rooms.json). 그 면의 문 자리는 벽으로 메우고(문 높이 위 벽 포함 — 사용자 "엘베 벽이여"), 문 사이 벽은 남긴다.
- 뒷면·옆면(균형추 쪽) 틈은 메우지 않는다. 카에서 0.55m 안에 80%+ 들어간 0.5㎡ 이하 조각은 기호 → 제거. 로비 쪽으로 0.4m 넘게 나온 얇은 문턱선도 제거.
- 코드: radar_final.py `_front_ok`·`_sym`. 로카우스: 승강로 안 벽 조각 10개·뒤쪽 메움 13개 제거, room_check·door_audit 통과.

## 8. 벽 연결·가짜 문 규칙 (2026-11-10 사용자 "여기 벽이잖아, 왜 저기서 꺾는데, 도면을 이해를 못 한다")
- **굵은 벽 선(절단선)이 끊김 없이 지나가면 그 자리는 벽이다.** 지시선·치수선이 벽을 가로질러도 벽은 안 끊긴다. 개구부 후보의 긴 면 두 줄에 굵은 선이 70%+ 지나가고 문 근거(호·문짝)가 없으면 → 벽. 문은 굵은 선이 **문설주에서 멈추고** 그 사이에 문짝·호가 있을 때만.
- **벽은 직선으로 끝까지 간다.** 도면에 꺾임이 없으면 모델에도 없다. 같은 줄 벽 사이 빈칸·계단은 판독 오류(가짜 문 + 틈 → 꺾인 것처럼 보임).
- **ㄱ자·점 접촉 모서리:** 두 벽이 꼭짓점 하나로만 닿으면 미완성 접합 — 양쪽 벽 두께로 닫히는 바깥 모서리 칸을 메운다(Revit 맞댐 접합).
- **문은 벽에 꽂힌다:** 문 끝에서 0.2m 안 같은 줄 벽까지 문을 붙인다(문 끝~벽 틈 금지).
- **매달린 벽**(제연경계 등)은 아래에서 올라온 벽 자리를 피한다(wallnet `_hang_cut`).
- 관문 추가: `python C:/Users/PSH/dev/plan2max/corner_check.py <solids_clean.json>` → CORNER_CHECK_OK.
- 코드: radar_final.py `_wall_through`·`_fill_corners`·`_fill_point_corners`·`_snap_ends`, radar_solids.py `_snap_op`.

## 9. Revit 공식 도움말로 재확인 (2026-11-10 "웹검색 똑바로 해, 레빗도 다시")
- **문은 호스트 구성요소** — 어떤 벽에든 꽂고, 문을 놓으면 벽에 개구부가 **자동으로** 뚫린다. 문 종류 선택 → 벽 위 위치 지정 (Autodesk Revit 2025 *About Doors* https://help.autodesk.com/view/RVT/2025/ENU/?guid=GUID-BCDC7124-7361-4336-9310-34D6DB175B70). → 문은 '벽 사이 틈'이 아니라 '이어진 벽 위의 한 점'. **벽을 먼저 끝까지 세우고 그 위에 문을 꽂는다.**
- **벽 = 위치선(Location Line) + 종류** — 위치선 6종(벽 중심선·코어 중심선·마감면 내/외·코어면 내/외). 벽 종류(두께)를 바꿔도 위치선은 그대로, 면이 움직인다 (*About Walls* https://help.autodesk.com/cloudhelp/2018/ENU/Revit-Model/files/GUID-550F4B3E-7D49-4A4F-BEC7-4077D5B9FC85.htm). → 벽 한 개 = `종류(두께), 위치선 시작점→끝점`.
- **Chain·Join** — Chain 은 끝점이 이어진 벽을 연속으로 그림. Join Status = Allow 면 벽이 만날 때 **자동 맞댐 접합** (*Place a Wall* https://help.autodesk.com/cloudhelp/2020/ENU/Revit-Model/files/GUID-05BAFEAA-5186-484E-80F4-8D900C454748.htm). → 벽 끝점은 다른 벽의 위치선 위에 정확히 놓인다(L·T).
- **CAD 따라 그리기** — DWG 를 깔고 Pick Lines 로 벽을 따라 그림. 포럼 경고: 선을 통째로 집어 자동 변환하면 문제가 많다 → **참조로 깔고 벽을 새로 그리는 것**이 실무 (*Import Walls* https://help.autodesk.com/view/RVT/2024/ENU/?guid=GUID-0805BFCA-44E1-4DF4-9875-8238C7AB406E).
- **제도 순서(국내 건축 교육)** — 축선 → 벽체선 → 기둥 → 입면선(문 등, 가장 가늘게) → 바닥 줄눈 → 가구 → 치수 → 기호. 축선이 모든 것의 기준 (서울시립대 기초설계 https://openarchive.uosarch.ac.kr/work?id=V29yazo5Njcx).

### 결론 — 지금 파이프라인이 틀린 근본 구조
로카우스는 '선 조각 → 면(다각형) → 합치기·메우기·깎기'로 만들었다. Revit·건축 제도는 **'축선 → 벽 위치선(종류·시작·끝) → 접합 → 문 꽂기'**. 조각을 다듬는 규칙을 아무리 덧대도 틈·돌기·꺾임·가짜 문이 계속 나오는 이유.
**다음 평면 작업(또는 로카우스 재작업)은 벽 위치선 방식으로 다시 짠다:**
1. 굵은 선(절단선) 평행 짝 → 벽 위치선 후보(두께 = 짝 간격을 종류표 값으로 반올림).
2. 같은 줄 위치선 합치기(지시선·문 자리로 끊긴 것 잇기 — 굵은 선이 이어지면 한 벽).
3. 끝점을 만나는 벽 위치선 위로 스냅(L·T·+), 허공에서 끝나는 벽 0.
4. 위치선을 두께로 부풀려 벽 생성(접합부 직각 마감) — 조각 합치기 없음.
5. 문 = 호·문짝 기호마다 가장 가까운 벽 위치선에 꽂고 그 폭만 뚫음(문 위 벽 유지).
6. 관문: door_audit · room_check · corner_check + 위치선 끝점 미접합 0.

## 11. 점선 판독 규칙 — 사용자 지적 1차 13건 (2026-11-10, 로카우스 5층 색 지도)
사용자: "전체적으로 점선을 구분 못 함", "딱 보면 벽체라고 알아야 함, 점선 부분이 벽체가 돼야 문이 연결됨", "문이 있는데 벽으로 막으면 문을 왜 만드냐".
- **R1 굵은 벽 바로 옆(0.3m 안)을 나란히 따라가는 가는 점선 = 그 벽의 마감·상부선 → 별도 벽 아님.** 벽으로 또 감싸지 않는다(코어 둘레, 주방 서측 x30.9, 공조실 남측). 이런 띠가 문·통로를 막는다.
- **R2 홀로 서서 문·기둥·다른 벽을 잇는 점선 = 벽.** 문은 반드시 벽에 연결된다 — 문 옆에 벽이 없으면 그 옆 점선이 벽이다. 기둥을 감싸는 점선 사각 = 기둥 마감 벽.
- **R3 문·창호·통로는 절대 벽으로 막지 않는다.** 벽 띠를 세운 뒤 문·창·통로(엘리베이터 로비 입구 등)와 겹치면 벽이 틀린 것. 제연경계벽(H600)은 천장에만 — 예전 후보 띠가 바닥 벽으로 남지 않게 한다.
- **R4 AD(덕트) 상자 = 굵은 바깥 사각 − 굵은 안쪽 사각.** 가는 X 사각 기준으로 두껍게 칠하지 않는다. 왼쪽 굵은 선이 끊긴 구간 = 점검문. ST 상자 속은 비움(사이 벽·해치 띠만 벽).
- **R5 검은 띠+멀리언 = 창**(벽 지우고 유리). 점선 두 줄 사이 사다리 표시 = 창호(칸막이 유리), 그 양 끝 모서리·연결부는 벽. 문 양 끝 굵은 작은 사각 = 문설주 벽(작다고 지우지 않는다). 점선 이중 사각 = 기둥(사용자 확인; GPT 는 상부 부재로 봤음).
- **일관성**: 같은 종류 선은 도면 전체에서 같은 뜻으로. 어디는 넣고 어디는 빼면 반려.
- 절차: 판독 → **색 지도(`review_map.py`, 격자 포함)를 Downloads 에 PNG 로** → 사용자 스크린샷 지적 → 위치 찾기(템플릿 정합) → 원본 확대 재판독 → 수정 → 같은 자리 잘라 확인 → 승인 후 Max. 사용자가 "이미지"라고 하면 Max 를 만들지 않는다.
- 코드: `_out_radar5f/radar_apply_user.py`(지적 반영), `radar_apply_gpt.py`(GPT 교차검수 수정 목록), `qlines.py`(구역 선 좌표 조회).
- **전체 점검 의무**(사용자 "13개만 보지 말고 전체적으로, 내가 찍은 것 말고도 있다, 도면 보는 걸 학습하란 거야"): 지적받은 자리만 고치지 않는다. 지적에서 뽑은 규칙으로 **색 지도를 12구역(4×3)으로 잘라 전부 직접 읽고**, 같은 유형을 찾아 고친 뒤 보고한다. 로카우스 전체 점검에서 추가로 찾은 것: 굵은 선 근거 없는 벽 조각 5곳(기둥 옆 빈칸·주방 서벽 앞 덧벽·화장실 통로 가로 띠·코어 아래 점선 띠), ELEV#7 승강장 문이 '문 제거 목록' 재적용으로 지워짐, 0.84pt 닫힌 사각 기둥 누락, 점검문이 오른쪽에 있는 AD 상자 속 칠.
- **벽의 근거 = 굵은 선 두 줄(또는 R2 점선).** 근거 선이 없는 벽 조각은 지운다. 판정이 애매하면 `qlines.py <구역> 0.5` 로 굵은 선을 조회한다.

## 12. 사용자 지적 2차 — 1차 규칙 정정 (2026-11-10, 최종 정본. §11 R1 은 이것으로 대체)
사용자: "점선들도 벽체야, 저기에 마감재가 붙는 거라고", "다른 거 주면 또 이렇게 반복하면 내가 만드는 게 빨라, 학습을 해야 한다고".
**다음 도면부터 처음 판독할 때 그대로 적용할 규칙(반복 금지):**
1. **굵은 벽 옆을 나란히 따라가는 점선 = 마감면.** 벽 두께는 마감면(점선)까지다 — 굵은 선~점선 사이를 벽으로 채운다. 단 그 점선이 벽 없는 구간(통로·문 앞·엘리베이터 로비 입구)을 가로지르면 그 구간은 벽 아님(제연경계 상부선 등). 구현: 점선 띠 ∩ (벽을 0.05~0.3m 수직 이동한 합집합) − 문.
2. **홀로 선 점선 두 줄 = 칸막이 벽**(두 줄 사이 채움). 점선 하나 + 기둥/벽 사이 빈칸 = 벽으로 채움. 벽과 벽·기둥 사이에 빈 사각이 남으면 판독 오류.
3. **문은 벽에 꽂힌다 — 문 양옆 굵은 사각(문틀 블록·문설주)은 벽.** 문 폭 = 문설주 사이만.
4. **문 두께 = 문짝 두께(평면 실제 크기)**. 화장실 칸 문은 얇다(30~40mm). 칸막이(30~60mm 점선)는 빼지 말 것 — 얇아서 wallnet 이 꺾임으로 지우므로 nosnap 별도 덩어리로.
5. **창 = 창틀 + 유리.** 도면 검은 사각(기둥틀·끝틀)은 창틀(frame), 그 사이 유리. 창틀을 빼거나 유리를 벽 두께로 부풀리지 않는다. 커튼월은 멀리언(굵은 사각)+유리 한 줄.
6. 색 지도도 실제 크기로 그린다(문·유리 부풀리지 않음, 창틀 표시) — 부풀려 그리면 "문 사이즈 두껍다"로 반려된다.
7. 같은 유형은 도면 전체에 동시에 적용한다(지적 자리만 고치지 않는다).

## 13. 점선 = 벽(마감·경량벽) 웹 근거 + 일반 판독기 (2026-11-10 사용자 3차 "웹 검색해서 학습을 똑바로 해라")
- **Revit 복합벽**: 벽 = 코어(core boundary 사이) + 바깥쪽 마감층. Medium/Fine 상세 수준에서 층 경계선이 평면에 그려진다 → 굵은 코어 선 옆의 가는 선은 **같은 벽의 마감층 경계** (Autodesk *About Compound Walls* https://help.autodesk.com/cloudhelp/2026/ENU/Revit-ArchDesign/files/GUID-7657DF90-6AE2-4543-BFDA-7735A8424B1C.htm). 벽 두께는 마감면까지.
- **점선 벽 = 경량(금속 스터드) 벽** — 미국 도면 관행에서 금속 스터드 벽을 점선으로 그린다 (Noble Desktop *Exploring Interior Wall Types* https://www.nobledesktop.com/learn/blueprint-reading/exploring-interior-wall-types-and-sections-drawing-details). 로카우스: 인테리어 별도공사 경량벽·마감이 점선.
- **문 위 인방/상부벽은 평면 절단면(약 1.2~1.4m) 위라 평면에선 안 보이거나 점선** — 모델에선 문 높이 위에 벽을 세운다 (Noble Desktop *Understanding Floor Plans* https://www.nobledesktop.com/learn/blueprint-reading/understanding-floor-plans-exploring-doors-windows-and-architectural-details). 색 지도에 '문 위 벽' 테두리로 표시.
- **일반 판독기 `radar_dashwalls.py`**(지적 자리 패치 대신): 검은 0.12pt 짧은 토막 3개+ 이 0.2m 안 간격으로 이어지면 점선 줄. (a) 점선 두 줄 0.05~0.35m 간격·0.3m+ 겹침 → 칸막이 벽 (b) 점선과 굵은 선 0.03~0.35m 간격 → 마감면까지 벽. 문 앞뒤 0.4~0.45m(여닫는 자리)·커튼월 안쪽·기둥 둘레·FCU·LCD 는 제외. 로카우스: 점선 359줄 → 칸막이 42·마감 60 구간.
- 마감 띠는 벽 옆 구간만 남기고 **문 앞뒤 0.45m 는 비운다**(문 막음 반려).

## 14. 한국 건축 제도 웹 확인 (2026-11-10 "한국 도면 그리는 것도 학습하라")
- 건축 제도 기준 = **KS F 1501 건축제도 통칙**(일반 제도 KS A 0005 위에 건축 세부). 평면도 = 창틀 위(바닥 1~1.5m)에서 수평으로 자른 투상도. 창호 기호: 원 안 위 = 번호, 아래 = 재료+D(문)/W(창) (기린실내연출 카페 건축제도 정리 https://m.cafe.daum.net/roomdesign/NSIj/32).
- 그리는 순서(국내 교육): 축선(벽 중심선) → 벽체선 → 기둥 → 개구부·입면선(문 등 가장 가늘게) → 재료 표시 → 치수·인출선·명칭 (서울시립대 기초설계 https://openarchive.uosarch.ac.kr/work?id=V29yazo5Njcx).
- 국내 경량칸막이 = C스터드(0.8T)·CH스터드 + 석고보드(9.5·12.5·15T), 세대 칸막이 두께 125~190mm 예 (한국건설기술연구원 경량형강 스터드 규격화 연구 https://www.codil.or.kr/filebank/original/RK/OTKCRK500094/OTKCRK500094.pdf; KCC 석고보드 시방서). → 점선 두 줄 간격 0.1~0.2m = 경량벽 두께로 타당.
- 문틀: 깊이 = 벽 두께에 맞춤(제품 폭 100~150mm 계열), 문짝 35~40mm (영국·유럽 제조사 자료). 모델: 문설주 50 × 벽 두께, 상부틀, 그 위 상부벽. 색 지도에 문설주를 검정으로 표시(사용자 "문틀은?").
- **확인 못 함**: KS F 1501 원문의 선 굵기·문틀·마감선 표현 규정(유료 표준 원문). 웹 자료로는 세부 기호를 확정할 수 없음 → 도면 자체의 범례·반복 패턴을 1순위 근거로.

## 15. 사용자 지적 4차 (2026-11-10) — 다음 도면부터 첫 판독에 적용
- **점선이 꺾여 벽 쪽으로 들어가는 자리 = 뚫리는 곳(개구부).** 굵은 벽 선이 끊기고 점선만 그 앞을 지나가면 그 점선은 상부(인방) 표시 → 바닥 벽 금지. §12-1 마감 규칙은 '굵은 선이 실제로 있는 구간'에만.
