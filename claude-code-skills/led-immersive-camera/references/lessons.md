## 함정
- MAXScript 괄호 블록 안에서 fileIn 으로 정의된 전역 함수를 부르면 컴파일 시점에 지역 undefined 로 잡힌다. 블록 밖에서 fileIn 하고 `::함수명` 으로 부른다.
- 사용자가 Max 를 열어 둔 상태에서 테스트는 `3dsmaxbatch.exe` 로 따로 돌린다(약 80초). 사용자 씬을 건드리지 않는다.
