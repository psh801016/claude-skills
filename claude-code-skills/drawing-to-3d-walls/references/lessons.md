## 2026-11-09 — 무카 CAD(cowsdelete.com/cad) 분석 → "이걸 내꺼에 녹여"
- 사용자: "이걸로 모델링 가능한거 같은데 내용 철저하게 분석 그리고 이걸 내꺼에 녹여". 소스 24개 모듈·AI 가이드 문자열 전부 읽음 → 결론: 기계 부품 2·3면도→3D 는 되지만 건축 평면도→벽체 3D 는 못 함(ELEV 만).
- 들여온 것: `scripts/photo_grid.py`(격자+표식+mm/px) + `test_photo_grid.py`, E-1 '좌표 읽기 전에 격자' 단계, 투영 겹침 최소 2회, 핵심 치수 우선·5면 자가검사 규칙(플레이북 §11). 분석 정본: `AUSURA/AI-Sessions/wiki/reference/mucca-cad-cowsdelete-analysis-2026-11-09.md`.

## 2026-11-09 — 휴플로우 무료 리습 2개 분석 → plan2elev.py
- HUEFLOW_ELEV2.lsp(HF2): 외곽 폴리라인 변마다 길이×천장고 사각형을 이어 그리고 폭·천장고·총폭 치수 + 꺾임 ▽(천장고 4.5%). 개구부 없음. HF_AREA.lsp v5.1(HFA): 닫힌 폴리라인마다 "㎡ / PY"(1PY=3.305785㎡, 글자 = 최소 폭/15·≥50mm) + 선·MTEXT 합계표(TABLE 객체는 버그로 포기), OSMODE·CMDECHO 복구 에러 핸들러.
- 우리 plan.json 엔 개구부가 있어 문·창까지 뚫는 `scripts/plan2elev.py`(+test) 로 재구현. 리습 원본은 받아 읽기만 했고 저장소에 넣지 않음(출처 휴플로우, 무단 재배포 금지 표기).
