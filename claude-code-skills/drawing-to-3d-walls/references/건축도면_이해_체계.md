# 건축 도면 이해 체계 (학습 정리 · 2026-06-30)

> 핵심 깨달음: 도면은 "그림"이 아니라 **표준 규칙으로 분류된 구조화 정보**다.
> 픽셀로 추측하면 안 되고, 그 구조(레이어·선문법·기호·세트)를 "읽어야" 한다.

## 1. 도면은 '세트'로 이해한다 (평면도 단독은 불완전)
- 구성: **배치도 → 평면도 → 입면도 → 단면도 → 상세도 → 창호도/일람표 → 구조도**
- 읽는 순서: 배치 → 평면 → 입면 → 단면
- 평면도 = 바닥 +1.2m에서 수평 절단해 내려다본 것
- ⚠️ **평면도엔 높이·창대고가 없다** → 문/창 "형태"는 입면도·단면도·창호일람표가 있어야 완성된다.
  (창호일람표: WD/D-1/W-1 번호별 마감치수·재질·유리·철물 사양)

## 2. 선의 문법 (KS F 1501 건축제도통칙)
| 선 | 의미 | 벽인가 |
|---|---|---|
| **굵은 실선** | 단면선/외형선 (벽·기둥·바닥 절단면) | ✅ 벽 |
| 가는 실선 | 치수선·치수보조선·인출선·해치 | ❌ |
| 일점쇄선(―·―) | 중심선·**통심선(주열 grid)** | ❌ |
| 이점쇄선(―··―) | 가상선(상부 보·천장 윤곽) | ❌ |
| 파선(- - -) | 숨은선(위층/상부 구조) | ❌ |
- 굵은 복선 = RC 내력벽(외벽), 가는 단선 = 경량 칸막이(비내력)
- 욕실 등 방수구간 = 해치(빗금)

## 3. 기호 어휘 (고정된 시각 문법)
- **주열/통심선 버블**: X1,X2…/Y1,Y2… 원형 기호 = 기둥 중심 그리드 (벽 아님, 도면 끝까지 가는 긴 일점쇄선)
- **방위표 N** = 북쪽(보통 위쪽)
- **문**: 벽 사이 갭 + swing arc(여닫이)/직선(미닫이), 번호 D-1. "900"표기=실개폐 800
- **창**: 벽 중간의 평행선, 번호 W-1
- **위생기구**: 변기·세면대 심볼 (이 도면에선 핑크)
- **계단**: 디딤판 평행선 + UP/DN + 화살표
- **단면 표시 화살표**: 어디를 자른 단면도인지
- 실명·실번호 텍스트, DN(하강)/UP(상승)

## 4. ★ 레이어 표준 — 기계가 도면을 "이해"하는 핵심
- 한국: **KS F 1542 (CAD 레이어 원칙과 기준, 2010 KS제정)** = 건설CALS 전자도면 표준
- 미국: **AIA Layer Guidelines / National CAD Standard (NCS)** — `분야-주요-부가` 구조
- 제대로 된 CAD 도면은 모든 요소가 **레이어로 이미 분류**됨:
  - 벽 `A-WALL` / 문 `A-DOOR` / 창 `A-GLAZ`(`A-WIND`) / 치수 `A-ANNO-DIMS` / 텍스트 `A-ANNO-TEXT` / 가구 `A-FURN` / 위생 `P-SANR` / 그리드 `A-GRID` / 계단 `A-FLOR-STRS`
- **레이어명 = 요소의 정체.** 레이어만 읽으면 "벽인지 치수인지" 추측 0.
- 🔴 **PDF는 레이어를 평탄화(flatten)해 다 날린다** → 우리가 픽셀로 헤맨 근본 원인.
- ✅ **DWG/DXF는 레이어 보존** → 받으면 "이해"가 거의 공짜 (ezdxf로 레이어별 추출).

## 5. 의미 모델 (BIM/IFC) — 최상위 이해
- IFC: 벽=`IfcWall`, 문=`IfcDoor`, 창=`IfcWindow` — 선이 아니라 **객체(의미)**.
- 국토부 2025 BIM 설계 의무화 흐름.

## → 내가 도면을 이해/처리하는 올바른 경로
1. **(최선) 원본 DWG 확보** → 레이어로 완벽·결정적 이해. PDF로 추측하는 건 정보를 버리고 복원하려는 짓.
2. **(이미지/평탄PDF만)** 손규칙이 아니라 **학습된 도면인식 모델**이 이해 엔진:
   - DeepFloorplan / U-Net multi-task (room-boundary-guided attention) / DeepLabV3+ → 벽·문·창·실 의미분할
   - 텍스트-그래픽 분리(OCR)로 주석 제거
3. **항상 세트로**: 입면·단면·창호일람과 함께 읽어야 문/창 형태·높이 완성.
