## 날짜순 연혁 (2026 부산 사이버보안 콘퍼런스, 14개사 45판)
- **10-22** ASURA님 지시: 요청서 '디자인 수령' O 만 내 몫(드림·넷코아·국제식물 제외). 후렉스·켈지 '별도 요청' 업체(아이티윈 외 4사)는 담당자 확인 뒤. 산출물은 `발주\원본\족자봉\` 한 폴더. "그냥 CMYK 변환이 아니라 RGB 색에 맞춰서" → Japan Color 색 맞춤 절(우리아이티 파랑 ΔE 16.5·신화 주황 6.5 가 계기). "글씨 잘리는건 알아서 잘 배치해" → 글줄 다시 배치 절. 판 밖에 숨은 내용 지적(제이콥 정면 띠 28.2m·2,800개). 색 작업 중 일러 강제 종료로 저장 안 한 Untitled 가 날아감 → run_ai.ps1 ABORT 가드. 함정 1~14 는 이날 실측.
- **10-23** ASURA님 지적: 시트 바탕 연회색(K25) — 흰 판이 흰 시트와 구분 안 됨. 반투명·합성 효과 많은 원본(프라이빗 3,109/7,900개·이글루 빛줄기)은 그림으로. 상·하단 70mm 안쪽 내용은 같은 비율로 줄여 넣고 가장자리 2mm 띠 rasterize 로 채움(safeFit). 동료 요청 "현수막, 패트 구분되게 크게, 색깔도 다르게"(→ 10-26 에 행사 옵션으로 격하). 발주 시트 라벨 타이포 정본 참조만(기존 라벨 '지금이 맞다').
- **10-26** ASURA님: 재질 60pt·색 구분은 부산 동료 요청이라 기본값 아님(`BIG_MAT`). 같은 디자인은 한 번 그리고 `qty`(안랩 켈지). `oneMat` 라벨 두 줄.
- **10-27** "해상도 깨지는거 있는지 확인 잘해" → 래스터효과 300ppi 고정(굿모닝 빛 고리 글로우), `res_audit.py`. 굿모닝 재전송은 장식 점 배치만 바뀜. 함정 15(화면 색 ≠ CMYK 숫자, verify 오탐).
- **10-28** 이글루 재빌드: `textFonts.getByName` 이 미설치 Pretendard 를 돌려줘 가늘게 찍힘 → 설치 목록에서 이름으로. 늘린 가장자리 줄무늬(제이콥 우측·앤앤에스피·우리아이티·시큐어레터 우측2) → ASURA님 "임의로 늘리면 안 된다, 안 되면 파일을 달라고 해야 한다" → `check_stretch.py` STRETCH_OK 게이트, 단색 가장자리만 허용. 저해상도(신화 삼각형·이글루 배경 19ppi)는 업체에 파일 요청.
