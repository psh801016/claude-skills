# 간판 자동 제작 (일러스트레이터 틀 채우기)

ASURA님은 **"간판"** 이라고만 해도 이 스킬을 부른다. 두 방식이 있다 — 먼저 고른다.

| 상황 | 방식 |
|---|---|
| 글자·로고가 바뀌는 간판 (부스간판·옆간판·현수막·명패) — 대부분 이것 | **A. 부스간판 세트** |
| 사진이 카드마다 바뀜 (사원증·명찰) | **B. 변수 패널** (유튜브 영상 방식) |

## 지켜야 할 것 (ASURA님 지시)

- **★ 이 스킬은 말 안 해도 작업마다 고친다 (2026-10-21 "말 안 해도 해라, 이렇게 계속 만들 거야").**
  작업이 끝나면 새로 알게 된 것(함정·절차·수치)을 이 문서와 `scripts/` 에 반영하고, `py -3 scripts/test_tools.py` 통과 뒤
  `~/.agents/sync.ps1` 로 다른 AI 에 전파한다. 행사 전용 코드는 `examples/<행사>/`, 다시 쓸 기능은 `scripts/` 로 올린다.
- **일러를 돌리기 전에 먼저 묻는다** — 일러가 문서를 열고 닫으면 ASURA님 작업 화면이 바뀐다("화면 방해하지 마라" 3회).
  준비(엑셀·로고·스크립트·문법검사)는 일러 없이 끝내고, 허락받으면 한 번에 몰아서. ASURA님이 연 문서는 닫거나 저장하지 않는다.
  스크립트는 결과 파일이 이미 열려 있으면 손대지 않고 멈추게 짠다. 오래 걸리면(1.6GB 파일 3~5분) 백그라운드로 돌리고 상태를 알린다.
- **쉬운 한국어로**, 표로. 해결 방법을 물으면 누를 곳·입력값이 있는 번호 단계로. 일러 쓰라는 말 대신 "제가 할까요?" 를 같이.
- **받은 자료는 전부 연다**: 엑셀(지시 줄·비고·메모·붙은 그림), 요청서 PPT 전 페이지, 배치도, 3D, 참고 .ai 의 대지 전부.
  작업 전·후 "요청 → 적용 여부" 표를 보고한다. 적용 안 한 건 ❌ 와 이유.
- **출력 규칙**: 한 줄 최대 10장(출력소 한계) · 간판 위 **검정 번호 라벨** · **CMYK** · 크기는 **옥타 발주 규격**
  (정본: AUSURA `wiki/reference/octanorm-booth-order-specs.md` — 3m=2930, 2.5m=2435, 옆간판 2435x750, 날개 450x6460 둥글게 양면).
- **납품 파일은 작업 소스 폴더에, 최종 이름으로** (부산: `원본/부스간판.ai`. `_자동생성` 같은 꼬리 붙이지 말 것 — ASURA님이 지움).
  같은 이름 원본이 있으면 덮어쓰기 전에 묻고, 덮을 때는 작업기록 폴더에 사본을 남긴다(X: 는 휴지통 없음).
  고칠 때마다 결과 파일을 작업기록 폴더에 `백업_<이름>_<날짜>_<무엇>전.ai` 로 먼저 복사한다.

## A. 부스간판 세트 — 이 순서로

실증: 부산 사이버보안 콘퍼런스 2026 (정면 24 + 옆간판 8 + 날개 29, 2026-10-15~21). 그 행사 스크립트 전부가 `examples/busan_2026/` 에 있다.

### 0. 자료 인벤토리 (일러 없이)
- **요청서 엑셀**: `py -3 -c` 로 모든 칸·병합·메모 + `ws._images` 그림 추출. 요청서가 **PPT 로도** 온다(부산 10-21 "간판·날개·행사명 켈지 발주 요청서": 부스별 간판 수량·인포데스크·켈지 수량 표, 날개 구간표, 간판 수정 문의) — `python-pptx` 로 표·글·그림 전부 뽑는다.
- **배치도 2종 이상이면 번호가 서로 다를 수 있다**(부산: 파란 배치도 08 안랩 vs 요청서 08·09 안랩, 팔로알토·윈스 자리 바뀜). 다르면 표로 보여 주고 어느 쪽인지 묻는다. 부산 확정 = 파란 배치도.
- **로고 폴더**: 이름표 붙인 한 장(contact sheet)으로 눈으로 대조. 폴더 번호 ≠ 부스번호. 메시지에 적힌 폴더와 실제 위치가 다를 수 있다(시스코 로고가 우리아이티 폴더에).
- **로고 해상도 표**: `로고 px ÷ (상자 폭 mm × 축척 ÷ 25.4)` = 실물 dpi. 30 미만 깨짐, 60 미만 흐림 → "받아야 할 원본" 체크리스트로 보고.

### 1. 장수 정하기 — 배치도·3D 로
| 무엇 | 규칙 (부산 실측) |
|---|---|
| 정면 간판 | 부스마다 1장. **두 칸 통합부스**는 같은 정면 간판 2장(08 안랩, "가운데 열어주기" = 칸막이만 뺌) |
| 옆간판 | 배치도 **빨간 선(오픈된 쪽)** 마다 1장. 빨간 선만 뽑아 부스별 표로 보고(`r>180, g·b<70`) |
| 날개(기둥) | **간판이 이어진 줄마다 간판 n장 → 날개 n+1개** (통합부스 가운데 기둥 포함). 오픈 면 안쪽 끝은 벽에 붙어 날개 없음. 3D 를 구역별로 확대해 밝은 회색 굵은 기둥을 직접 센다. 부산 29 = 4+10+5+5+5 |
| 데스크 켈지 | 인포데스크 앞판. 인포데스크마다 1매(요청서 표의 '행사명 켈지'). 데스크 크기가 둘이면 켈지도 두 종. **이름은 '데스크 켈지'** — '데스크 띠지'라고 쓰지 말 것(ASURA님 10-23 직접 고침) |
- 장수 표를 먼저 보고하고 확인받는다(부산: 처음에 오픈 면 끝 +6 을 더해 35개로 틀렸다 → "갯수 잘못 파악").

### 2. 엑셀 → CSV (일러 없이)
```bash
py -3 scripts/excel_to_csv.py "요청서.xlsx" --ju --logos "로고폴더" --cmyk     # 기본
py -3 scripts/excel_to_csv.py "요청서.xlsx" --qty A1=2,A12=3                     # 통합부스 → 간판 2·3장
```
- 머리글은 '국문'·'영문'이 같이 있는 줄. 부스번호가 비면 연번을 `01` 형식으로 쓰고 알린다.
- `--ju` ㈜→(주). `--cmyk` 로고 여백 자르고 CMYK TIFF(Japan Color 2001 Coated).
- 오타로 보이는 건 고치지 말고 묻는다(로고 표기가 기준인 경우가 많다). 나중에 추가된 줄은 맨 뒤에.
- 비고에 그 간판만 다른 디자인(예: 번호 도형 연두색)이면 변형 틀(`틀_연두`)을 하나 더.
- 로고 원본이 .ai 로 오면 `examples/busan_2026/ai_logos.py` 방식(pymupdf 로 CMYK 6000px TIFF, 한 페이지에 로고 여럿이면 CROP).

### 3. 틀 만들기 (예시안에서, 행사마다 한 번) — 일러
| 이름 | 무엇 |
|---|---|
| `틀` (그룹) | 간판 1장 + 그 위 번호 라벨을 묶은 그룹. 변형: `틀_로고2`(로고 둘) · `틀_2사`(두 회사 반반) · `틀_연두` · `틀_옆`(옆간판) |
| `부스번호`·`국문`·`영문`… (글자) | CSV 머리글과 같은 이름. 같은 이름 여러 개면 전부 채운다(배지 + 위 라벨) |
| `로고`·`로고2` (칠·선 없는 사각형) | 로고를 비율 유지·가운데로 넣고 파일에 포함 |
| `영역` (칠·선 없는 사각형) | 이 안 글자는 폭을 넘으면 축소, 절반 넘게 줄면 두 줄 |
- 예시안 간판이 클리핑 그룹이면 바깥 묶음 그룹(간판 + 라벨)을 `틀` 로. 틀은 작업기록 폴더의 `<행사>_틀.ai` 에(원본 불변).
- 예시안이 RGB 면 틀 파일을 `doc-color-cmyk` 로 바꿔 둔다(따로 한 번 실행).
- **두 회사형**(`틀_2사`): 반쪽마다 로고 + 국문 + 영문. 합본 로고 한 장을 통째로 넣지 말 것("로고도 아니고").
  가운데 구분은 세로 막대가 기본인데, 협업·공동참가 표기로 **X** 를 요청받기도 한다(부산 12번 시스코 × 우리아이티, 10-21) → `examples/busan_2026/divider_to_x.jsx`(막대 자리 가운데 8mm·1.5pt·K60 선 두 개). 요청서 PPT 의 '간판 수정' 쪽을 꼭 본다.
- 세로로 긴 로고(원형 심볼)는 26mm 상자에 막혀 작다 → 로고 상자를 30~34mm 로 높게 잡는다(부산 드림 34mm 로 키움).
- **옆간판 틀 = 정면 틀 '잘라 당기기'** — `scripts/sign_tools.jsx` `stSqueeze(w, {cut1, cut2, width, logo, area, tagScale})`.
  늘이지 않고 두 세로선에서 오른쪽 꼭짓점만 당겨 모서리·제목 홈·배지 모양이 그대로. cut 선은 홈·글자를 피해
  (부산 92·238mm, 폭 293→243.5, 로고 39.5~112.5, 글자 126.7~203.5, 왼쪽 작은 문구 75%). **견본 1~2장을 그림으로 먼저 보여 준다**.

### 4. 채우기 — 일러
- 결과는 **매번 틀 파일에서 새로**: 틀 열기 → 결과 이름으로 저장 → `fillTemplate`(`scripts/fill_template.jsx`) → 틀 지우기 → 저장.
- 크기가 같으면 틀이 달라도 이어 붙여 10장씩 한 줄, 크기가 다른 간판만 줄을 바꾼다.
- 옆간판·통합부스 추가 장은 정면 간판의 로고 그림·글자를 **그대로 복제**해 채운다(손 수정 보존, `examples/busan_2026/build32.jsx`).

### 5. 번호·순서 — 일러
- 번호는 확정 배치도대로 배지 + 위 라벨 둘 다(`examples/busan_2026/renumber.jsx`: 이름·지금 번호를 모두 확인한 뒤에만 바꿈).
- **번호를 바꾸면 놓는 순서도 번호순으로** — `stReorder(res, ["국제식물검역인증원"])`: 크기별 줄, 10장씩, 같은 번호(통합부스)는 나란히,
  존이 다른 부스(공공협력존)는 맨 끝. 안 하면 "순서대로 놔야 하는 거 아녀?" (부산 10-21).

### 6. 발주 정리 — 묶음 제목·날개·켈지 — 일러
- **묶음 제목** `stTitle()`: 2025 참고판 이름 그대로 — `조립부스간판` / `기본부스간판 옆날개` / `기업부스날개`,
  아래 줄에 `크기 / 현수막 / 마감` 과 `각 1EA · 총 nEA`. 글꼴은 간판 번호 라벨 글꼴. 제목 자리만큼 아래 줄을 내린다.
- **기업부스날개**: 디자인은 ASURA님이 만든 파일(부산 `B구역부스.ai` 1번 대지 = 한 면 450x3230)을
  `py -3 scripts/render_artboard_tif.py <ai> --page 1 --real-width 450 --dpi 120 --scale 10 -o 날개_한면_cmyk.tif` 로 뽑아
  `stTwoFaceWing()` 으로 넣는다(아래 한 면 + 위 180도 = 450x6460, 현수막 한 장을 반 접어 기둥을 감쌈). 디자인 1개 + 수량만 적는다.
  벡터로 복제하면 반투명 물결·스크린 입자가 빠진다(3회 실패). 글자를 고쳐야 하면 ASURA님이 일러에서 직접 복사(Ctrl+C → Ctrl+F)하는 게 확실하다.
- **데스크 켈지**(인포데스크 앞판, 요청서엔 '행사명 켈지'): 요청서 수량대로. 크기·디자인을 받아서 만든다(부산 950x200mm 켈지 29EA, 안랩은 로고 켈지 별도). 제목은 '데스크 켈지 / 크기 / 켈지 / 수량'.

### 7. 확인 (반드시, 보고 전에)
- 텍스트 덤프: 장마다 번호(라벨·배지)·국문·영문·로고 개수 → 요청서와 한 줄씩 대조. 고친 뒤에는 **바뀐 장만 바뀌었는지 전후 대조**하고 그때만 저장.
- CMYK: 모든 `RasterItem.imageColorSpace` RGB 0.
- **확대 그림**: 일러 PNG 내보내기는 투명 배경이라 검정 글씨·겹침 모드가 안 보인다 → 저장 파일을 **pymupdf 로 흰 바탕 렌더**해 본다.
  날개처럼 다른 파일에서 온 건 참고판과 나란히 붙여 비교한다.
- 보고: 결과 경로 · 요청 적용표 · 장수 표 · 못 한 것 · 백업 경로.

### 7-1. 다른 파일의 간판을 세트에 넣기 (부산 10-23: B구역부스.ai 체험부스 간판 2장)
- 원본은 살아 있는 오브젝트로 넣는다: 그 파일을 먼저 열어 `activate()` → `unlockAll`·`showAll` → 대지마다 `selectObjectsOnActiveArtboard()` → 한 묶음 → **대지 크기 클리핑**(대지 밖 배경 잘림) → 레이어로 복제(`examples/busan_2026/add_exp.jsx`).
  이 방식은 투명·겹침까지 그대로였다(B구역 대지 렌더와 나란히 비교로 확인). 날개 때 빠진 건 조각을 위치로 골라 마스크를 놓친 탓.
- 기존 줄과 섞지 말고 아래 새 줄 + 원래 파일의 제목 이름('체험부스 간판') 그대로. 클리핑 맨 위 묶음이라 출력 단계에서 '다른 출력물'로 자동으로 굳는다.
- 날개처럼 디자인이 같은 건 수량만 더한다(ASURA님 "날개는 동일하니 갯수 추가"). 재질 변경 요청(예: 현수막 → 켈지)은 설명 글자만 바꾼다. 데스크 앞판 이름은 '데스크 켈지'.

### 8. 출력 파일 만들기 — 컨펌 끝난 뒤 (`원본/` → `출력/<이름>_출.ai`)
원본은 오브젝트가 살아 있는 작업 파일, 출력은 **실물 크기로 굳혀 가볍게 만든 발주용** 파일이다(ASURA님 10-23 설명).
출력 폴더 기존 파일 규칙(콘솔가림막_출·카페테리아_출 실측): **대지는 원본과 같은 1/10 그대로 · 출력물은 실물 150ppi 그림 · 글자 0개(글자깨기) · 같은 이름 `_출.jpg`**.
- 굳히는 범위는 **간판 테두리(클리핑) 안만**. 위 검정 번호 라벨은 출력물에 안 들어가게 그림 밖에 두되, **출력 파일에 남긴다**(설치하는 분 확인용). 라벨·제목·설명 글자는 글자깨기.
- 방법(부산 `examples/busan_2026/`): ① `out_prep.jsx` 원본에서 간판(+띠지 등 다른 클리핑 출력물) 테두리 위치를 대지 기준 pt 로 기록, 날개는 150ppi 위·아래 두 장(위는 파이썬에서 미리 180도 → 이음매 없음)
  ② `render_signs.py` 일러 없이 pymupdf 로 그 영역만 실물 150ppi CMYK TIFF(dpi 1500 = 150×10) ③ `build_out.jsx` 원본 → `출력/…_출.ai` 로 다른 이름 저장 후 테두리 안을 그림으로 교체, 글자깨기, 검사, `_출.jpg`.
- 일러 '오브젝트 → 래스터화'는 쓰지 않는다(CMYK 래스터화 13GB 멈춤 이력, 32장이면 더 무겁다). pymupdf 렌더는 투명·겹침까지 그대로였다.
- 확인: 대지 크기 같음 · 그림 수(간판+띠지+날개) · RGB 0 · 글자 0 · 원본과 같은 배율로 그려 차이 그림(가장자리 번짐 말고 덩어리 차이가 없어야) · 확대 비교.
- **그룹(ASURA님 10-23)**: 간판은 한 장씩 그룹(그림 + 위 라벨) 그대로, **그 위에 한 줄(최대 10장)씩 한 그룹**으로 다시 묶는다. 정면 줄·옆간판 줄·체험부스 줄 각각. 날개·데스크 켈지는 줄 그룹에 넣지 않는다.
- **저장은 Illustrator CS6 형식**(인쇄업체가 열 수 있게, ASURA님 10-23): `IllustratorSaveOptions` — `compatibility = Compatibility.ILLUSTRATOR16`(CS6), `pdfCompatible = true`, `embedICCProfile = false`, `compressed = true`. 기본 '2020' 저장은 출력용으로 안 된다.
- 출력 파일을 ASURA님이 손본 뒤(예: 이름 고침)면 다시 만들지 말고 그 파일 위에서 그룹·저장만 한다 — 다시 만들면 손 수정이 날아간다. 고친 내용이 원본에도 있는지 확인하고, 없으면 알린다(부산: 출력에서만 '데스크 켈지'로 고침).
- 무게: 부산 32장 = 원본 1.6GB → 출력 1.18GB (TIFF 640MB, PDF 호환 사본이 같이 들어가 커진다). 더 줄이려면 'PDF 호환 파일 만들기' 끄기 — 미리보기·검사가 안 되니 묻고.

### 9. 나중에 고칠 때 (손 수정이 들어간 뒤)
다시 채우지 않는다(손 수정이 날아간다). 바꿀 것만 바꾼다 — `examples/busan_2026/`:
`swap_logos.jsx`(로고만) · `enlarge_dream.jsx`(로고 크기) · `fix_wit_nnsp.jsx`(한 장을 두 회사형으로) · `divider_to_x.jsx`(구분 막대 → X) · `renumber.jsx` · `reorder.jsx` · `wing_tif.jsx`.
바꿀 간판은 국문 이름으로 찾고, 바뀐 장 외에는 내용이 같을 때만 저장한다. 결과 파일이 열려 있으면 스크립트가 멈춘다 → 닫아 달라고 한다.

### A 함정 (전부 실측)
**일러·파일**
1. 캔버스(5779mm) 밖으로 대지를 늘리면 `AOoC` + 그 실행 변경이 통째로 되돌아간다. 대지 크기는 마스크 크기(`bounds()`)로 잰다 — `visibleBounds` 는 마스크 밖 배경까지 재서 넘쳤다.
2. 일러 안에서 그림을 CMYK 로 바꾸지 말 것(`Colors8` 안 먹음, `doc.rasterize` 13GB 응답 없음). 로고는 파이썬에서 CMYK TIFF, 문서는 `doc-color-cmyk`.
3. RGB 문서에 CMYK 로고를 넣으면 RGB 로 바뀐다.
4. 벡터 로고를 place→embed 하면 깨진다(심볼 조각·글자 두 겹). 다른 파일 디자인을 벡터 복제하면 반투명·스크린 겹침이 빠진다 → pymupdf CMYK TIFF.
5. 결과 파일이 ASURA님 일러에 열린 채로 새로 저장하면, 그 창을 저장할 때 새 파일이 덮어써진다.
6. 긴 경로에 saveAs → `Error 8700`. 짧은 경로에.
7. 배경이 embed 그림이면 장마다 복제돼 파일이 커진다(32장 1.6GB). 네트워크 드라이브(X:)라 열고 저장하는 데 몇 분.
8. **큰 문서의 `doc.pageItems` 전체를 하나씩 재지 말 것** — 조각 수만 개면 26GB·응답 없음(부산, 강제 종료). `setActiveArtboardIndex` + `selectObjectsOnActiveArtboard()` 로 맨 위 묶음만. 이 선택 명령은 **앞에 떠 있는 문서에만** 먹는다 → `activate()` 먼저, 다른 문서는 나중에 연다.
9. `selectObjectsOnActiveArtboard()` 는 잠긴 객체를 못 고른다. 대지 밖까지 깔린 배경은 대지 크기 클리핑 마스크를 씌워야 한다.
10. 다른 문서의 특정 객체 앞으로 `duplicate(obj, PLACEBEFORE)` → `PARM`. 레이어로 복제한 뒤 `move`.
11. `placedItems.add → embed()` 결과가 그룹으로 감싸일 때가 있다. 같은 객체인지는 `===` 로 못 가린다(조회마다 참조가 다름) → 이름(=파일명)이나 이름표로.
12-1. ASURA님이 손보면서 `자동생성` 묶음을 풀고 레이어 이름을 바꾼다(10-23). 간판은 이름이 아니라 모양으로 찾는다 — `stFindSigns(doc)`(클리핑 간판 + 라벨 묶음 / 맨 위 클리핑 = 다른 출력물). 간판을 그림으로 바꾼 뒤에는 클리핑이 없어 이걸로 못 세니, 처음 찾은 묶음 목록으로 검사한다(1차 0/32 오판).
12-2. 일러 실행기(.ps1)를 TEMP 에 두면 정리돼 사라진다(10-23) → `scripts/run_jsx.ps1` 를 작업 폴더에 두고 `.jsx` 를 BOM 사본으로 만들어 돌린다.
12. 손 복붙 때 생기던 "위 라벨 A1 / 박스 A7" 번호 불일치는 같은 칸 이름으로 묶으면 안 생긴다.

**ExtendScript(ES3) 문법** — `py -3 scripts/test_tools.py` 가 잡는다
13. `Array.indexOf` 없음 → 'is not a function'. 반복문으로.
14. 겹친 삼항식 `a ? 0 : b ? 1 : 2` 를 틀리게 계산했다(-37.5 → 2). if 문으로.
15. 한 줄 코드 중간에 `//` 주석 → 그 뒤 `}` 까지 주석이 돼 'catch/finally without try'.
16. 한글 경로가 든 .jsx 는 UTF-8 **BOM** 으로 저장해 `$ai.DoJavaScriptFile()` 로 돌린다.

## B. 변수 패널 — 사진 카드 (영상 방식)

출처: 디자이너맘 「이것도 가능하다고? 일러스트레이터 이미지 자동배치」
(https://www.youtube.com/watch?v=NR_hPJnVPlM). 영상 방식은 그대로 따르되,
손이 많이 가던 두 군데를 스크립트로 바꿨다.

| 영상에서 손으로 하던 것 | 이 스킬 |
|---|---|
| 사진마다 `속성 > 보안 > 개체 이름` 경로를 복사해 엑셀에 붙임 | `make_csv.py` 가 폴더에서 이름으로 찾아 절대경로 기입 |
| 엑셀에 `'@사진` (작은따옴표) 입력 | CSV 를 직접 쓰므로 필요 없음 |
| 제작자 카페의 배치 스크립트 | `layout_datasets.jsx` (자체 작성) |

### B-1. CSV 만들기 — 에이전트가 한다

```bash
# 명단이 있을 때 (명단.csv 의 '이름' 칸 = 사진 파일명)
py -3 scripts/make_csv.py "<사진폴더>" --list "명단.csv" -o "<사진폴더>/list_ai.csv"

# 명단 없이 사진만 있을 때 (파일명이 곧 이름)
py -3 scripts/make_csv.py "<사진폴더>"
```

- 결과 머리글 예: `부서,이름,@사진`. **`@` 가 붙은 칸 = 이미지 변수**, 나머지는 텍스트 변수다.
- 명단에 있는데 사진이 없으면 이름을 찍고 **exit 1**. 그 칸은 비워 둔 채 저장되니 반드시 채운 뒤 넘긴다.
- 첫 사진과 가로세로비가 다른 사진이 있으면 경고한다(아래 '함정' 2번).
- 옵션: `--key 이름` (사진을 찾을 기준 칸), `--image-col 사진` (변수 이름).
- 명단이 엑셀(.xlsx)이면 **CSV UTF-8** 로 저장한 뒤 넘긴다.

### B-2. 일러스트레이터에서 할 일 — ASURA님께 단계로 안내한다

메뉴 이름은 영상과 같은 영문판 기준이다.

1. 카드 디자인 1장을 연다. 사진 자리에는 사각형을 하나 둔다.
2. `Window > Variables` 패널을 연다.
3. **텍스트**: 선택 도구로 부서 글자를 고른다. 패널 메뉴(≡)에서 `Make Text Dynamic`를 누른다.
   변수 이름을 두 번 클릭해 **CSV 머리글과 똑같이**(`부서`) 고친다. 이름도 같은 방법으로 `이름`을 붙인다.
4. **사진**: 사각형을 선택한다. 툴바 맨 아래 그리기 모드를 `Draw Inside`(내부 그리기)로 바꾼다.
   `File > Place`로 사진 한 장을 넣고 틀 크기에 맞게 드래그한다.
5. 그 사진을 선택한 채 패널 메뉴에서 `Make Linked File Dynamic`를 누른다.
   변수 이름을 `사진`으로 고친다. CSV 의 `@사진` 에서 `@` 를 뺀 이름이다.
6. 패널 메뉴에서 `Load Variable Library…` → `list_ai.csv` 를 고른다. 덮어쓸지 묻는 창에는 `Yes`를 누른다.
7. 카드 전체를 선택하고 `Ctrl+G` 로 묶는다. 그룹 하나만 선택된 상태로 둔다.
8. `File > Scripts > Other Script…` → `scripts/layout_datasets.jsx` 를 실행한다.
   원본이 1번이 되고, 나머지가 오른쪽·아래로 격자 배치된다. 열 수는 √개수를 올림한 값이다(12장이면 4열).

장별 파일 저장(대지 분리·PDF 저장)은 영상에서도 '이전 강의'로 넘긴 부분이라 이 스킬 범위 밖이다.

### B 함정 — 실호출로 확인한 것

1. **CSV 는 UTF-8 이어야 한다.** CP949·UTF-16 은 `The dataset file is invalid` 로 거부된다.
   한글 윈도우 엑셀의 기본 `CSV (쉼표로 분리)` 가 CP949 다. 엑셀로 고쳤으면 **`CSV UTF-8`** 로 다시 저장한다.
   `make_csv.py` 는 UTF-8(BOM)로 쓴다. 엑셀로 열어도 한글이 깨지지 않고, 변수 이름에 BOM 이 붙지도 않는다.
2. **사진 비율을 통일한다.** 일러는 새 사진의 *대각선 길이*만 첫 사진과 맞춘다.
   3:4 틀에 정사각·세로로 긴 사진이 들어오면 옆이 비고, 가로로 긴 사진은 잘린다.
   증명사진은 미리 같은 비율로 잘라 둔다. `make_csv.py` 경고가 뜨면 그 사진들이 대상이다.
3. **변수 이름 = CSV 머리글**이다(이미지는 `@` 를 뺀 이름). 하나라도 다르면 그 칸이 안 바뀐다.
4. **경로는 절대경로.** 사진 폴더를 옮기면 CSV 를 다시 만든다.
5. 배치 후 **원본 카드만 변수에 연결된 상태**로 남는다. 패널에서 데이터셋을 바꾸면 1번 카드만 바뀐다.
   복제본은 일반 오브젝트라 개별 수정해도 된다.
